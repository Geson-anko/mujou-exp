Codex や Fable に相談するときは、お互いに敬意と尊敬をもって進める（ユーザー、2026-11-23）。

**Why:** 相談相手は道具ではなく、別の視点をくれる共同研究者として扱う。Fable の時間相関の SIGReg の調査（memory/agents/fable/temporal-sigreg.md）を受けて、検証と Codex への相談に進む際にユーザーが添えた。

**How to apply:** 依頼の文面は、丁寧に、背景と目的を共有する形で書く（命令口調にしない）。相手の主張を確かめるときは、疑ってかかるのではなく「一緒に確かめる」姿勢をとる。反論を受けたら、まず受け止めて考え直し、採らない場合は理由を添える。成果を引くときは、誰の考えかを明記する（例:「Fable の考案」「Codex の指摘」）。ユーザーへの報告でも、相談相手を「さん」づけなどで敬意をもって呼んでよい。関連: [[feedback-questions-at-end]]
