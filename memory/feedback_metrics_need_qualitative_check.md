予測の良さの数値（rollout{n} など）を完了の条件や成果に使う前に、チェックポイントからデコードした画像で見た目と合うかを確かめる。合う指標だけを条件にする。

**Why:** 2026-11-01、潜在空間の rollout10 < 1 を M11 の達成として報告した。ユーザーから「ランダムな出力や overshoot と区別できているか」と問われ、調べると、予測は平均へ縮んでいるだけで動力学ではなかった。ユーザーの方針は「条件は定性評価と相関していればよい」「再構成はメインの学習中ではなく、チェックポイントから BP で最速に学ぶ単純な実装でよい」。

**How to apply:**
- 予測の指標は、動力学を知らない基準と並べる。基準は、写すだけ・平均・縮めた写し（shrink{n}）・デコードしない平均の画像（pix_mean{n}）
- `exp/video/decode.py` で画像に戻し、見た目を報告に添える
- 「1 未満」のような絶対の閾値だけで達成と言わない
