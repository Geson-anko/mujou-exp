# 線形の幅の内容のガード v3 の設計メモ（2026-11-26）

役割: v2（観測の再構成の忠実さ）が V-h4b（実データ）で外れた後の作り直しの設計。V19 の値は見ていない。v3 の値も 1 つも計算していない。計画への登録は `exp/vision/plans/jepa.md` の「線形の幅の内容のガード v3（2026-11-26、V19 の値を見る前）」。README への記録は次の段。Codex さんの批判は [../codex/guard-v3-critique.md](../codex/guard-v3-critique.md)。

## 1. 出発点: 診断（README「線形の幅のガードの作り直しの有効性」）

1. MLP の読み出しが訓練の 512 区間を覚えた。同じ分布の訓練の外の区間で、どの符号でも最小二乗に負けた（`pca` 0.609 対 0.737、平均 12.8 秒で −1.66 対 0.387）。最小二乗は MLP の族の極限に含まれるので、族の最良が負けることはない。負けたのは「学んだ読み出しが族の最良に届く」という命題 1 の前提が崩れたからである
2. $E^d$ を水準の読み出しの差で測ると、誤差は $\approx 2(1-\rho)\sum\lVert e\rVert^2$ で、`pca` の MLP で $2 \times 0.10 \times 0.37 = 0.074$、変化の分散の割合 0.0725 と同じ大きさ。全ての符号で $E^d \le 0$
3. 合成（V-h4a）は、訓練が 1 本の連続した系列で、符号が場面を見分けず、変化の大半が白い雑音だったので、1・2 を再現できなかった

## 2. 直しの理論を自分で確かめた点

### (a) 選択

- 確かめた: ホールドアウトの選択の不等式 $R(\hat g_{\hat m}) \le \min_m R(\hat g_m) + 2\delta$（$\delta = \max_m \lvert \hat R_{\mathrm{val}} - R \rvert$）。検証の区間が当てはめと独立なら、各候補の $\hat R_{\mathrm{val}}$ は不偏で、$\delta$ は候補の数の対数と検証の区間の数で決まる。だから、選んだ読み出しは最小二乗より $2\delta$ を超えて悪くならず、診断 1 を直接に防ぐ
- 命題 1 の閉じ方: ノルムの球の線形の族は $\lVert P \rVert \le 1$ の線形の $P$ との合成で閉じる（$\lVert BP \rVert_F \le \lVert B \rVert_F$）。MLP は最初の層が $WP$。射影と直交変換は白色化した座標でノルム 1 以下。だから族ごとの最良の命題は厳密に残る
- 早期終了は族ではなく推定量なので、閉じ方の議論は族の最良まで。命題 1' は「選んだ読み出しの誤りは、最良の候補の、和集合の族の最良からの届かなさ $\varepsilon_c$ と $2\delta$ の和を超えない」と言い直した（初稿は族ごとの最良を基準にしていて誤りだった。Codex さんの反例）。$\varepsilon_c$ は観測できないので、V-h5a4・V-h5b4 で、記録用の 64 区間（当てはめにも選択にも使わない）で選んだ読み出しが最小二乗に負けないことを確かめる
- 検証の区間は、訓練の動画の、訓練の区間・記録用の 64 区間・互いに重ならない 128 区間（seed 3301）。初稿では間隔を置かなかったが、Codex さんの指摘（隣の区間の場面の相関）で、訓練と記録用の区間から 256 stack の間隔を置いた（h-block）。51.2 秒の間隔だと、訓練の 512 区間（重なりを許す）が 479350 フレームの約 42% を覆うので、置ける場所が約 11%（$e^{-512 \cdot 2048/479350}$）に減る。256 stack なら約 16%（$e^{-576 \cdot 1536/479350}$、約 7.5 万の開始の位置）で、128 区間は引ける見込み（推測。引けなければ `interval_draws` がエラーで止まる）。それでも相関は残るので、検証の誤差は楽観的でありうる（限界）
- 格子を小さくした理由: 候補を増やすほど $\delta$（候補の数の対数で増える）が増え、選択の入れ替わりも増える。幅 {256, 1024}・早期終了 20 時点・ridge 4 つの 44 個にした。重みの減衰は入れない（AdamW の減衰はノルムの球の族と 1 対 1 に対応しない。ridge と幅と早期終了で容量を制御する）

### (b) 変化の読み出し

- 確かめた: $(c'_t, c'_{t-1}) = (h \oplus h)(c_t, c_{t-1})$、$\lVert h \oplus h \rVert = \lVert h \rVert$。だから組の入力でも閉じ方は同じ
- 確かめた: 線形の $g$ の差 $B^\top(c_t - c_{t-1})$ は無制約の組の線形の族に入る（係数のノルムは $\sqrt2\lVert B\rVert_F$）。幅 $h$ の MLP の差には幅 $2h$ の組の MLP が要り、格子を超える。そこで、水準で選んだ読み出しの差そのものを変化の候補に入れた（Codex さんの案）
- 直接の読み出しの誤差は自分の残差で、水準の誤差の自己相関の項は現れない
- 懸念（推測）: Zurich の $E^{d,\mathrm{lin}}$ は `pca` で 0.041 と小さい。$\psi^d$ の区間が広くなり、「解像度が足りない」が増えうる。保守的な側の誤りなので登録は変えず、V-h5b3 の `rot` 対 `base` で確かめる

### (c) 合成をそろえる

- そろえる対象（データだけで決まる量と物差しの値）: 区間の数・長さ・中央の半分・重なりの規則（実データと同じ関数で引く）、訓練の系列の長さ 479350、$r = 0.113$（訓練の中）、符号が持つ内容の割合 0.74（`pca` の 64 区間での最小二乗。物差しの値）
- 場面 $s$（符号に入る）と細部 $n$（入らない、$s$ と独立）を、二乗指数の共分散（$\ell = 60$ 秒）の滑らかな過程にした。OU にすると変位の相関が常に負（$-(1-\phi)/2$）で窓を壊すので使わない。二乗指数なら連続する変位の相関は $\approx 1 - 3\Delta^2/(2\ell^2)$ で、$\Delta < \ell/\sqrt3 \approx 35$ 秒で 1/2 を超える
- 白色化した符号の中で、$s$（16 次元、速さ約 $1/\ell$）の変位の二乗は、陽性の 1 次の円（周期 30 秒、2 次元）の約 5%（$16 \times 0.017^2 / (2 \times 0.21^2)$）。核の窓をほとんど変えない
- 割合の閉じた式（`uv run python` で解いた）: 陰性 $g$ 0.1466・$n$ 0.1034、陽性 $g$ 0.1608・$n$ 0.0892（$\varepsilon$ 0.01）。陰性の母集団の $E^d$ は約 0.088、陽性は約 0.016
- 陰性の $f$ の時定数を V-h4a の 0.3 秒から 3 秒にした。0.3 秒のままだと、符号が持つ変化の内容が実データ（$E^{d,\mathrm{lin}}$ 0.04）よりずっと大きくなり、変化の大半が符号に無い速い内容である、という実データの構造（3）を作れない。3 秒の OU も変位の相関は負なので、「混合」に窓が無いことは変わらない
- 較正の閉じた式: 水準 $\sigma^2 \approx 0.493$。変化は、$d^f$ が $(1,-1)$ の向きにあり、その向きの $u = f + n$ の分散が $2(1 + \sigma^2 - \phi)$ なので、説明される割合が $(1-\phi)/(1+\sigma^2-\phi)$。$\psi^d = -\psi_*$ で $\sigma^2 \approx 0.00237$
- V-h5a0 の差の機序（初稿の (ii)）は、合成で再現できる見込みが薄い（Codex さん: 滑らかな $n$ の偽の予測は差で打ち消し合う。$E^d$ を 0 にするには lag 1 の相関 0.952 以下が要る）。閉じた式で値の決まる解析の対照 V-h5a0-d（雑音つきの符号で、水準の差の予測の $E^d$ が負、組の読み出しの $E^d$ が正）に分けた。区間の記憶は、$n$ の座標の $E$ が訓練の中で正・検証で負であることで機序ごと確かめる
- 判定は対比 $D = E_a - 2^{-\psi_*}E_b$ の区間にした（$E_b > 0$ で境界は $\psi$ と同値。$E_a$ の点推定が 0 以下で上端まで $-\infty$ になる v2 の欠陥を直す）。V-h5a4・V-h5b4 も同じ対比での非劣性にした
- V-h5a0（v2 の規則が合成でも外れる）を置いたのは、V-h4a が「通る」ことしか示せず、v2 の欠陥を落とせなかった反省から。合成が外れ方を再現できなければ、v3 の合成の合格は証拠にならない。再現しなかったときに割合を変えて探さない

## 3. $\sigma$ の対ごとの扱い

v3 では符号ごとに選ぶ候補が違いうる。`base`・`rot` が線形を選ぶと $\sigma_{\mathrm{rot}} = 0$ になり、MLP を選んだ符号の seed の揺れが区間から抜ける。だから $\sigma_{ab} = \max(\sigma_{\mathrm{rot}}, s_{ab})$ にした（判定の量を $D$ にしたので、$D_s$ の揺れで求める）。選択の入れ替わりの揺れはどちらにも入らないので、限界として書き、次点との差を記録する。

## 4. 値を見た後であること

V-h4b の全ての値（とくに最小二乗の単調さ）を見た後の作り直しである。規則は診断の理論から導いたもので、全ての符号に同じ規則を当て、Zurich に触れず、MLP の候補を残して並べ直しを罰さない。確証は V19。README には次の段で「値を見た後の直し」として書く。
