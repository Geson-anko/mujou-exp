## 1 往復目: Codex さんの答えの要点

1. 第一候補は (a)「空間マスクの予測が、当てやすいように標的 z 自体を変える」。標的にも勾配が流れるので、条件付き分散の大きい成分（位置に固有で、見える部分から当てられない内容）を落とすと誤差が下がる。(b) 射影はそれを強め、(c) N=128・D=1024 の SIGReg はそれを許しやすい。ただし有限標本の問題を直しても、SIGReg は入力の情報を守らない
   - 見分ける実験（checkpoint で測れる）: 各 checkpoint の h に固定したランダム射影（トークンあたり 64 次元）を複数当て、学習した P と比べる（エンコーダの寄与と射影の寄与を分ける）。凍結した z を、生の可視パッチ・同じマスク・同じ容量の予測器で当て直し、標的の分散に対する残差と、隠した位置の画素を z から戻す誤差を並べる。(c) は held-in の大標本で共分散スペクトルと S の N 依存を測る
   - 「最終出力に直接勾配がかかるのは最大 320 次元」から「残りの成分は保たれる」とは言えない（共有する上流の重みが動く）
   - (e) 拡張なし・(f) 4×4 は、M17 と V18 で view・射影・解像度・データが違うので M17 の比較は直接の証拠にならない。(f) は学習前の h_flat が 0.109 を出すので容量はある。調べるなら単一因子の対照
   - 「意味に寄せた」は強すぎる。言えるのは、静止 Imagenette のクラスが h_mean から読みやすくなったことまで
   - 動力学は「コピーに対する上積みが消えた」まで。z の dyn_1 は 0.186〜0.209 → 0.044〜0.069、copy_1 も 0.199〜0.223 → 0.039〜0.067 に下がっている。比だけで予測誤差が増えたとは読めない
   - SIGReg の問い 3: n=128 で A > B の読みは支持。ただし spaced にも隣の相関 0.027〜0.047 が残る。val の pred_iid の一致は「実現した窓の周辺分布で値を説明できる」ことしか示さず、定常な長期相関の揺らぎか場面による分布の変化かは分けられない。val と同じ長さ・採り方の窓を複数並べると val の例外さが分かる。n=1024 spaced の pred の発散は `autocov` の 1/(G−l) で長いラグの推定が c_l > v になり、閉形式の指数項が増幅するのが疑わしい
2. 目的: 重複しない未来の z を現在の低次元 z だけから予測し（最初は δ=1 秒、線形の F_δ）、現在の入力の歪みを制約する。min E‖F_δ(z_t) − z_{t+δ}‖²/d s.t. E d_x(x_t, g(z_t)) ≤ ε、Cov(z_t) = I。再構成だけ足すと z を縮めてデコーダで拡大する解があるので尺度の拘束も要る。等方ガウスを厳密に満たしても遅い状態だけを符号化する解は残るので、入力の保持は歪みで指定するのが筋（M13 の小さい玉が実例）
   - 時間方向の view の直接一致は、白色化の下でラグ相関を最大化するので持続する背景だけでも有利。時間マスクは「過去だけを文脈・未来だけを標的」なら同じ方向。途中を隠すと補間、標的に過去を入れると近道が残る
3. 掃引は先に試す価値がある（短い run と長い run の step 6000 で 0.326 対 0.450、学習率の予定が効いている）。r=0.25 固定で lr ∈ {1e-5, 1e-4} × λ ∈ {0.5, 0.8}、同じ seed・標本列・長い予定の形。総損失は λ 間で比べず pred と S を別々に追う。救えたとするのは固定 λ で低 lr が同程度の pred・S まで進み probe の改善が残り 2 seed で規則 5 を満たすとき。十分に学んだ腕でも pred が下がるにつれ span と zurich の両方で悪化すれば目的の不整合。低 lr が初期の近くに留まれば判定保留

## 2 往復目: こちらから返したことと答え

- こちら: λ を上げても (a) の解の族は大域的な最小のまま残り、変わるのはそこへ向かう速さだけでは。lr 1e-5 は初期の近くに留まって probe がよく見えるだけでは。掃引は「目的の不整合の確認」として安く回すが救える見込みは低い、と書きたい
- Codex さん: 「救える見込みは低い」には賛成。ただし「λ は速さしか変えない」は強すぎる。候補の解どうしで S が違えば、λ 0.5 → 0.8 で S の相対重みが 1 → 4 になり、順位が変わり得る（局所情報を残す符号の pred が少し悪くても S が十分よければ選ばれる）。完全にガウス化できる情報の乏しい解は残る。低 lr が救うとすれば、AdamW が別の経路を通って同程度の pred・S で局所情報を読み出せる符号に着く場合だが、V18 にその観測はまだない
- こちら: Cov(z)=I なら SIGReg でなく共分散の等式制約（ALM の乗数）で足りるか
- Codex さん: まず共分散の等式で十分（平均は 0 に固定するか F に切片）。SIGReg の高次の役割は、白色でも非ガウスな符号（二値の動画 ID など）を区別すること。ただし連続なガウスの背景因子は通るので入力保持の根拠にはならない。ストリーム全体の統計に対する乗数は PC-ALM の層間残差とは別の状態で、統計を持つノードが要る。歪みの不等式には非負の乗数。バッチごとの ‖Ĉ − I‖² の平均は母集団の罰に推定分散が加わる。単一ストリームでは統計の時間窓も設計の一部
- こちら: ε をどう決めるか
- Codex さん: 「許容できる歪み」から決める。導けるのは「歪み予算の中で予測誤差が最小」までで、情報量を目的に入れていないので「最小の情報」までは導けない。初回は同じ正規化で color の歪み − δ_r。同じ d・同じデコーダの再構成のみの腕で締められる範囲を確かめる。h_flat の 0.109 は 16384 次元なので d=64 の ε の参照にしない
- こちら: i.i.d. な時間ペアなら、入力にほぼ依存しない遅いドリフトの近道は無いのでは
- Codex さん: 残る。ペアの両端は動画 ID や照明を共有する。画面から動画を区別できれば ID を ±1 に写すだけで分散 1、F=I で誤差 0。i.i.d. 化が切るのはペア間の依存だけ。診断は、同じ動画の中で標的の時刻をシャッフルした対照と、未見の動画での重ならないラグのコピー比較
- 書き直し: Imagenette は「h_mean の最終 44.7〜46.4%、初期比 +4.1〜6.2 ポイント。静止 Imagenette のクラスが少し読みやすくなった。WT の局所情報を意味と引き換えに捨てた証拠にはならない」。動力学は「隣の stack の間で z の変化が小さくなり、学習した線形予測器のコピーに対する上積みが消えた」。copyw_1 は 4 本の最終値 0.079〜0.145 で、比べる stack は 7/8 フレームを共有するので、示すのはそのラグでの滑らかさ
