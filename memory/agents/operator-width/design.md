## 1. 量

### 1.1 定義

白色化した PCA64 の座標 $w$（既存の幅と同じ `midpoint.Whitener`。参照の組で当て、$c_\epsilon = 10^{-6}$）で、刻み $\Delta$ ごとに次を求める。

$$
R_{\mathrm{copy}}(\Delta) = \frac{\sum_t \lVert \hat w_{t+\Delta} - w_{t+\Delta} \rVert^2}{\sum_t \lVert w_t - w_{t+\Delta} \rVert^2},
\qquad
R_{\mathrm{clim}}(\Delta) = \frac{\sum_t \lVert \hat w_{t+\Delta} - w_{t+\Delta} \rVert^2}{\sum_t \lVert \bar w - w_{t+\Delta} \rVert^2}
$$

- 和は、Zurich の**共通の中心**（幅の $p$ と同じ約 14100 個。全ての刻みで同じ母集団にする。C1）でとる
- $\bar w$ は訓練の組の平均（白色化した座標ではほぼ 0）
- 分子は共通で、$R_{\mathrm{copy}} / R_{\mathrm{clim}} = \sum\lVert \bar w - w_{t+\Delta}\rVert^2 / \sum \lVert w_t - w_{t+\Delta}\rVert^2 = V / D(\Delta)$ は、モデルによらない符号の性質である（定常なら $1 / (2(1 - r(\Delta)))$。$r$ は自己相関）
- 予測器の入力は $(w_t, w_{t-\Delta})$。モデルは刻みごとに直接学ぶ（主）。0.1 秒のモデルを繰り返す rollout は副（§2.4）

### 1.2 既存の量との関係

- 等速の外挿 $\hat w = 2w_t - w_{t-\Delta}$ の $R_{\mathrm{copy}}$ は、$\sum\lVert a - b\rVert^2 / \sum\lVert b\rVert^2 = 4\sum\nu_t / \sum\lVert b \rVert^2$ である。定常では $\sum \lVert b \rVert^2 \approx \sum \delta_t$ なので、**$R_{\mathrm{vel}} \approx 4 G_{\mathrm{mid}}$** になる。プールした $G_{\mathrm{mid}}$ の境 1/4 は、ちょうど $R_{\mathrm{vel}} = 1$（外挿と copy が同点）に当たる。線形の幅は、$R$ の曲線の「固定した 1 つのモデル（等速）」の行として読める
- 計画（plans/jepa.md、V19 の判定の 5「予測の対照」）は、copy・等速・倍率 1 つの線形・学習した線形・V19 の予測器の誤差を、$E\lVert b\rVert^2$（copy の誤差）で割って並べる、と既に書いている。**新しい主の評価は、この 5 を全ての刻みに広げ、主に上げたもの**である

## 2. 理論: なぜ線形の族で足りる場面が広いのか（作用素の考察）

### 2.1 時間発展を群で書く

時間発展が 1 パラメータの（半）群 $g(\Delta)$ で $w_{t+\Delta} = g(\Delta) w_t$、$g(a + b) = g(a) g(b)$ と書けるとする。線形で連続なら $g(\Delta) = \exp(\Delta A)$ である（Koopman 作用素の有限次元の近似。DMD はこれをデータから当てる）。$A$ の種類で次の階層ができる。

| 族 | $A$ | 例 |
| -- | -- | -- |
| copy | $A = 0$ | 止まっている |
| 等速 | 2 点から速度を作る（状態 $(w, \dot w)$ に冪零の $A = \begin{psmallmatrix}0 & I\\ 0 & 0\end{psmallmatrix}$） | テイラーの 1 次 |
| 回転 | 歪対称 $A$（白色化した座標で定常なら、決定論的な線形の流れは直交になる） | 位相で表された周期運動 |
| 一般の線形 | 減衰・成長・回転の組み合わせ | 減衰振動 |
| 非線形 | — | 振幅で周期が変わる振動など |

### 2.2 2 点の対称な形で、等速と回転が 1 つの式になる

$w_t = \exp(tA) w_0$ なら、どんな $A$ でも

$$
w_{t+\Delta} + w_{t-\Delta} = 2\cosh(\Delta A)\, w_t
$$

が厳密に成り立つ。だから予測器 $\hat w_{t+\Delta} = 2C w_t - w_{t-\Delta}$（$C = \cosh(\Delta A)$）は、全ての線形の流れで誤差 0 である。$C = I$ が等速の外挿で、これは $\ddot w = 0$ の流れで厳密になる（速度 $v$ が軌跡ごとに違ってもよい）。より一般に、$\ddot w = K w$ の流れで $C = \cosh(\Delta\sqrt K)$ が厳密になる。

入力が $(w_t, w_{t-\Delta})$ の線形モデル $\hat w = M_1 w_t + M_2 w_{t-\Delta} + b$ は、copy（$M_1 = I$）・等速（$2I, -I$）・前向きの作用素 $\exp(\Delta A)$（$M_2 = 0$）・対称な形（$2C, -I$）を、全て特別な場合として含む。**だから線形モデルの族は回転と $\exp(\Delta A)$ を含む。**

### 2.3 回転の合成での真値（導いた）

周期 $T$（$\omega = 2\pi/T$）の平面の回転では、三つ組の $\rho_t = \cos\omega\Delta$ で、次が成り立つ。

- 等速の外挿: $R_{\mathrm{vel}} = \lVert b - a\rVert^2 / \lVert b\rVert^2 = 4\sin^2(\omega\Delta/2) = 2(1 - \cos\omega\Delta)$。$R_{\mathrm{vel}} < 1 \iff \Delta < T/6$（いまの幅と一致）
- 線形モデル（$2\cos(\omega\Delta) w_t - w_{t-\Delta}$、または $\exp(\Delta A) w_t$）: 全ての $\Delta$ で $R_{\mathrm{lin}} = 0$（$\Delta$ が $T$ の整数倍で分母が 0 になる点を除く）

したがって「等速の幅は狭いが $R_{\mathrm{lin}}$ は低い」符号は、動きを回転（位相）として表していると読める。位相 $\theta$ を $(\cos k\theta, \sin k\theta)_{k=1..K}$ で表した符号も線形の流れ（周波数 $\omega, \dots, K\omega$）なので、$R_{\mathrm{lin}} = 0$ のまま、等速の幅は $T/(6K)$ に縮む。

### 2.4 半群の整合性（副の rollout）

- 前向きの線形モデル $M(\Delta)$ が群なら $M(2\Delta) = M(\Delta)^2$。対称な形では、倍角の式 $C(2\Delta) = 2C(\Delta)^2 - I$（一般に $C(n\Delta) = T_n(C(\Delta))$、チェビシェフ多項式）
- 検定は行列の距離ではなく予測で行う。**刻みごとに直接学んだモデルの $R$ と、0.1 秒のモデルを $n$ 回繰り返した rollout の $R$ の差**（半群の不足）を出す。2 点入力の rollout は、状態 $(w_t, w_{t-0.1})$ の伴侶行列を回す（`linear_dyn.rollout` は 1 点入力なので広げる）
- 注意 1: 定常 OU の前向きの最良の線形 $e^{-\Delta/\tau} w_t$ は、厳密に半群である。だから半群の整合性は「$w$ の中で線形でマルコフか」を測り、予測しやすさは測らない
- 注意 2: フレームの雑音（分散の比 $\nu$）があると、最小二乗の係数は減衰する（回帰の希釈）。例えば回転と雑音では、$c^* = \cos(\omega\Delta)/(1 + \sigma^2)$（導いた、プール）。真の流れが群でも、雑音のもとで当てた係数は倍角の式を満たさない。だから半群の不足は記述にとどめ、判定には使わない

## 3. 既定の推奨を理論で確かめた結果

### 3.1 線形モデルは $R_{\mathrm{lin}} \le 1$ を訓練の分布の上で保証するか

保証する（導いた）。族が copy を含むので、訓練の組の上の最小二乗の誤差は copy 以下である。族は平均の予測（$M = 0, b = \bar w$）も含む。だから訓練の組では $R_{\mathrm{lin}} \le \min(1, V/D)$ になる。ただし Zurich（分布がずれる）と、早期終了の検証の区間の外では、保証はない。そこで次の 2 つを記録する。

- 訓練の組の値、訓練の動画の検証の区間の値、Zurich の値の 3 つ
- Zurich で $R_{\mathrm{lin}} > 1$ になった刻み。これは分布のずれの印として書く

MLP は「線形 + MLP の残差」の形にする。残差の出力層を 0 で初期化し、step 0 の値（= 線形の最小二乗）を早期終了の候補に入れる。こうすると、検証の区間で MLP が線形より悪くなることはない（族の包含を学習の手続きでも保つ）。

### 3.2 時間の平均のずるで R は下がるか（式で確かめた）。**刻みによって逆になる**

1 次元の定常ガウス過程（自己相関 $r_1 = r(\Delta)$、$r_2 = r(2\Delta)$）では、2 点入力の最良の線形予測の誤差の割合が、閉じた形で書ける。

$$
\mathrm{FVU} = \frac{1 - 2r_1^2 + 2r_1^2 r_2 - r_2^2}{1 - r_1^2},\qquad R_{\mathrm{clim}} = \mathrm{FVU},\qquad R_{\mathrm{copy}} = \frac{\mathrm{FVU}}{2(1 - r_1)}
$$

（ガウス過程なので、線形の予測が条件付き期待値そのものである。MLP も母集団ではこれを超えない。）白色化した座標で方向が独立なら、プールの $R$ は方向ごとの分子と分母の和の比である。

- **OU**（$r = e^{-\Delta/\tau}$、$r_2 = r_1^2$）: $\mathrm{FVU} = 1 - r^2$、$R_{\mathrm{copy}} = (1 + r)/2$。$R_{\mathrm{copy}}$ は $\Delta$ について**減る**（0.1τ で 0.952、τ で 0.684、∞ で 1/2）。遅くする（τ を大きくする）と、全ての刻みで $R_{\mathrm{copy}}$ は**上がる**（悪くなる）。$R_{\mathrm{clim}}$ は下がる
- **OU（τ = 1）を幅 W の箱で時間の平均にしたもの**（自己共分散の数値積分。Riemann 和 400×400）:

| Δ/τ | 0.1 | 0.5 | 1 | 2 | 4 | 8 |
| -- | -- | -- | -- | -- | -- | -- |
| W = 0（OU） $R_{\mathrm{copy}}$ | 0.952 | 0.803 | 0.684 | 0.568 | 0.509 | 0.500 |
| W = 1 | 0.187 | 0.656 | 0.757 | 0.600 | 0.514 | 0.500 |
| W = 4 | 0.124 | 0.433 | 0.590 | 0.672 | 0.580 | 0.501 |
| W = 0 $R_{\mathrm{clim}}$ | 0.181 | 0.632 | 0.865 | 0.982 | 1.000 | 1.000 |
| W = 4 | 0.000 | 0.030 | 0.140 | 0.483 | 0.974 | 1.000 |

読み:

- $\Delta < W$ では、時間の平均は軌跡を滑らかにするので、$R_{\mathrm{copy}}$ を大きく下げる（等速の幅が伸びるのと同じ仕組み）
- $\Delta \approx W$〜$2W$ では、$R_{\mathrm{copy}}$ を**上げる**。copy が良くなりすぎるからである
- $R_{\mathrm{clim}}$ は全ての刻みで下がる（遅いほど良く見える。Fable さんの定理の類似）

だから「遅くすると $R$ も下がる」は、$R_{\mathrm{clim}}$ では刻みごとに正しく、$R_{\mathrm{copy}}$ では短い刻みでだけ正しい。ただし log Δ の平均（§3.5）は、0.1〜25.6 秒の短い側を多く含むので、時間の平均でたいてい下がる（推測。$W$ と $\tau$ の比による）。**どちらでも、内容のガードとの前線で読む必要は残る。**

### 3.3 copy で割ることの穴: 雑音の注入で $R_{\mathrm{copy}}$ が下がる（改めた点）

フレームごとに独立な方向（白い雑音）は、最良の予測が平均なので、全ての刻みで $\mathrm{FVU} = 1$、$R_{\mathrm{copy}} = 1/2$ になる（$r_1 = r_2 = 0$）。だから、$R_{\mathrm{copy}} > 1/2$ の内容（例えば長い刻みの OU）を持つ符号に雑音の方向を混ぜると、プールの $R_{\mathrm{copy}}$ は下がる。

- 例: OU（τ = 1）の Δ = 1 で $R_{\mathrm{copy}} = 0.684$。64 方向の半分を白い雑音に置き換えると $(0.865 + 1)/(1.264 + 2) = 0.571$ になる。$R_{\mathrm{clim}}$ は 0.865 → 0.933 に上がる
- 白色化した PCA64 は、全ての方向を同じ重みにする。だから、符号の実効の次元が 64 より小さいと、数値の雑音の方向が単位の分散まで引き上げられ、この注入が勝手に起きる
- 内容のガードはこのずるを捕まえない。内容は保たれているからである

二つのずるは、二つの分母で逆向きに出る。

| ずる | $R_{\mathrm{copy}}$ | $R_{\mathrm{clim}}$ |
| -- | -- | -- |
| 遅くする（時間の平均） | 短い刻みで下がり、中ほどで上がる | 全ての刻みで下がる |
| 予測できない方向を混ぜる | 1/2 へ寄る（たいてい下がる） | 1 へ寄る（上がる） |
| 予測そのものが良くなる（同じ符号で誤差が減る） | 下がる | 下がる |

分子が共通なので、本物の改善は両方を下げる。

**改めた推奨**: 主の曲線は $R_{\mathrm{copy}}$（ユーザーの決定どおり）とする。ただし $R_{\mathrm{clim}}$ を必ず並べる。「符号 a の予測が b より良い」と言えるのは、主の比 $\log(R_{\mathrm{copy},a}/R_{\mathrm{copy},b})$ と $\log(R_{\mathrm{clim},a}/R_{\mathrm{clim},b})$ の区間が、どちらも同じ向きに 0 を超えるときだけにする。そのうえで、内容のガード v3 の前線を通ることを求める。食い違えば、どちらのずるの形かを書く。あわせて、符号の実効の次元（参照の組の固有値の分布、例えば participation ratio）を記録する。

### 3.4 尺度の不変性と定数の符号

- $R$ は比なので、符号の全体の倍率によらない。白色化すると、符号への可逆な線形変換によらなくなる（$W z' = Q W z$、$Q$ は直交）。線形モデルの族はこの変換について同変なので、**$R_{\mathrm{lin}}$ は厳密に不変**である（ridge を除く）。MLP は Adam が座標ごとなので近似的にしか不変でない。V-h4 と同じく、`pca` と、`pca` に無作為な直交変換をかけた `rot` の対で揺れを測る
- 白色化しないと、分散の大きい方向が支配する。PCA の上位の方向は遅いので、偏る（`linear_dyn` の docstring の `dyn_h` と `dynw_h` の違いと同じ）
- **定数の符号**: copy の誤差が 0 で、$R = 0/0$ になる。参照の組の $V$ が閾値（例えば $c_\epsilon$ の床で引き上げられた方向が過半）を下回る符号、または共通の中心で $\sum\lVert w_t - w_{t+\Delta}\rVert^2 = 0$ の刻みは「測れない」とし、数を出さない（幅の $\delta_t = 0$ の扱いとは違う。プールの比なので、個々の 0 は自然に和に入る）。崩壊の指標（K1〜K3・`token_r2`）で先に落とす

### 3.5 主の 1 つの数

$\overline{\log R} = \frac{1}{\log(25.6/0.1)}\int_{\log 0.1}^{\log 25.6} \log R_{\mathrm{copy}}(\Delta)\, d\log\Delta$（log Δ について台形）。半オクターブの格子（0.1 × $2^{k/2}$、$k = 0..16$ の 17 点）で計算できる。$\overline{\log R_{\mathrm{clim}}}$ も同じ形で並べる。

- 0.8 秒未満は、8 枚の stack の重なりで滑らかになる（Fable さんの結論 6）。そのため、符号器の手柄が混ざる。主の数は 0.8〜25.6 秒（$k = 6..16$）でも出し、両方を書く（どちらを主にするかはユーザーの判断。推奨は 0.8〜25.6 秒で、幅の主の範囲と揃える）
- 曲線は 0.1〜25.6 秒の 0.1 秒刻み（256 点）を線形モデルだけで出す（記述）。MLP は半オクターブの 17 点だけにする

## 4. 測り方（推奨の 1 つ）

1. **データ**: 訓練は Zurich 以外の動画、検証は訓練の動画の別の区間（訓練の区間と重ならない。Zurich とは独立）、評価は Zurich の共通の中心とする。**いまの `width_guard.train_intervals`（512 stack = 51.2 秒の区間）は使えない。** Δ = 25.6 秒の三つ組は区間の中に 52 秒ぶん要るので、中心が 1 点しか残らない。区間を 1024 stack 以上にするか、128 秒のブロックの規則（幅の `in`）を訓練の動画に当てて作り直す。訓練と検証の三つ組も、刻みをまたいで共通の中心にそろえる
2. **モデル**（全ての符号で同じ形・同じ容量・同じ学習規則）:
   - 線形: $\hat w = M_1 w_t + M_2 w_{t-\Delta} + b$。モーメントからの閉じた形（ridge。$\alpha$ は `linear_dyn.ALPHA_SCALES` から検証の区間で選ぶ）。V-h4b の教訓（訓練の組での過学習）から、選択は必ず検証の区間で行う
   - MLP: 線形の最小二乗の解 + 残差 MLP（入力 128 → 512 → 512 → 64、GELU、出力層を 0 で初期化）。Adam、batch 256。検証の区間の $R$ で早期終了する（step 0 を候補に含める）。seed は 3 つ
   - 記録の行: copy（$R = 1$）、等速（$R_{\mathrm{vel}}$）、平均（$V/D$）、倍率 1 つの線形、対称な形 $2C w_t - w_{t-\Delta}$ で $C$ を歪対称の流れに制限したもの（回転だけ）、V19 の予測器（V19 の行だけ）
3. **区間**: 128 秒のブロックごとに、分子・copy の分母・平均の分母を、刻みとモデルごとの和として残す。幅と同じ抽出（`block_counts`、2000 回、seed 101）で、$\log R$ とその対の比の区間を作る。MLP の seed の揺れは、`pca` 対 `rot` から $\sigma_{\mathrm{seed}}$ を取り、内容のガード v2 と同じ形で足す
4. **判定の言葉**: §3.3 の 2 つの分母の一致 + 内容のガード v3 の前線 + 崩壊の指標。言えるのは「Zurich の 1 本の動画の中での、その checkpoint の比べ」まで（幅と同じ）

## 5. 合成の確かめ（真値が閉じた形で出るもの）

一般の神託として、自己共分散 $\Gamma(\cdot)$ が既知の定常ガウスのベクトル過程では、2 点入力の最良の線形予測の誤差が

$$
\Gamma(0) - \begin{bmatrix}\Gamma(\Delta) & \Gamma(2\Delta)\end{bmatrix}\begin{bmatrix}\Gamma(0) & \Gamma(\Delta)\\ \Gamma(\Delta)^\top & \Gamma(0)\end{bmatrix}^{-1}\begin{bmatrix}\Gamma(\Delta) & \Gamma(2\Delta)\end{bmatrix}^\top
$$

（向きの規約は実装で合わせる）で厳密に出る。§3.2 の 1 次元の式は、この特別な場合である。

| 合成 | 真値 | 何を確かめるか |
| -- | -- | -- |
| S1 回転（周期 T。`synth_series.rotation`） | $R_{\mathrm{lin}} = 0$、$R_{\mathrm{vel}} = 2(1 - \cos\omega\Delta)$ | 族が回転を含むこと。等速の幅 T/6 との対比 |
| S2 位相の高調波（`chebyshev`、K 次まで） | $R_{\mathrm{lin}} = 0$、等速の幅 T/(6K) | 「並べ直した」符号を線形の族が罰さない |
| S3 確率的な減衰回転（複素 OU、$\dot w = (-\lambda + \omega J) w + $ 雑音） | $R_{\mathrm{lin}} = \dfrac{1 - e^{-2\lambda\Delta}}{2(1 - e^{-\lambda\Delta}\cos\omega\Delta)}$ | 減衰と回転。$\lambda \to 0$ で 0、$\omega = 0$ で OU の $(1 + r)/2$ になる。値の例: $\lambda = 0.1, \omega = 1$ の Δ = 1 で 0.177、Δ = 3 で 0.130 |
| S4 OU | $R_{\mathrm{copy}} = (1 + r)/2$、$R_{\mathrm{clim}} = 1 - r^2$ | 平均への回帰の床。MLP が線形を超えないこと（陰性の対照。ガウスなので最良は線形） |
| S5 時間の平均のずる（OU を箱で平均） | §3.2 の表（自己共分散の積分から、上の神託で厳密に） | 二つの分母が逆向きに動くこと。前線のガードの必要 |
| S6 白い雑音の注入 | $R_{\mathrm{copy}} \to 1/2$、$R_{\mathrm{clim}} \to 1$ の混合の式 | §3.3 の二つの分母の規則が注入を捕まえること |
| S7 つないだ回転（`chained_rotation`、ブロックごとに周期が違う） | 一つの $C$ を当てると、ブロックの重み $\pi_b$ で $c^* = \sum_b \pi_b\cos\omega_b\Delta$、誤差はブロックごとに $4(\cos\omega_b\Delta - c^*)^2 \lVert w\rVert^2$（等方性の仮定のもと、導いた） | 大域の線形モデルの限界。2 点入力の線形の族は $\cos\omega_b\Delta$ を区別できない |
| S8 振幅で周期が変わる回転（$\omega = \omega(r)$、$r$ はブロックごとに乱数） | 2 点で $r$ と位相が決まるので最良は 0。線形は S7 と同じ形で $> 0$ | MLP の陽性の対照（非線形でだけ勝てる） |
| S9 `rot`（S1〜S4 に無作為な直交変換） | 線形は元と同じ値 | 不変性と MLP の揺れ |

訓練の組は、実データと同じく「相関の強い区間の集まり」の構造にそろえる。V-h4a は 1 本の長い系列で回したため、実データの過学習を捕まえられなかった（README の「止めた理由と、直す方向」の 3）。

## 6. ずるとガード（まとめ）

- **遅くする**: §3.2。内容のガード v3 との前線で読む。$R_{\mathrm{clim}}$ は遅さを単調に褒めるので、前線は必須である
- **予測できない方向を混ぜる / 白色化で雑音を持ち上げる**: §3.3。二つの分母の一致の規則と、実効の次元の記録で対処する
- **内容の無い時計**（入力によらない振動を符号に入れる）: 線形で完全に予測でき、$R$ を下げる。内容のガードが、その方向の内容が 0 であることで捕まえる。ただし内容を全て持ったうえで時計を足した符号は、PCA64 の枠を時計が取る分だけ内容のガードの $E$ が下がるかどうかにかかる（未確認）。方向ごとの記述として、予測できる部分空間（線形モデルの $R$ を方向ごとに分けたもの）を記録する
- **過適合**: 訓練・検証・評価の分離、検証の区間での早期終了と ridge の選択、全ての符号で同じ容量。パラメータ数は、線形が刻みごとに 128×64 + 64 = 8256、MLP の残差が約 34 万。訓練の三つ組は約 13 万（相関が強く、実効はもっと少ない）。数は記録する
- **内容のガード v2 は V-h4b で外れている**。v3 が登録されて有効性が確かめられるまで、$R$ の比べは「内容の比べは未確立」とだけ書ける

## 7. 実装の置き場所と規模

- `exp/lib/dynpred.py`（新規。または `linear_dyn.py` を 2 点入力に広げる）: 2 点入力の線形モデルのモーメントと閉じた解、残差 MLP の学習（`torch.func.vmap` で刻み × seed を 1 GPU で並列）、ブロック和、rollout（伴侶行列）。mujou にもこの実験にも依存しないので lib に置く
- `exp/lib/synth_series.py`: S3（複素 OU）、S8、自己共分散からの神託（§5 の式）を足す
- `exp/vision/dyn_eval.py`（新規）: 訓練の動画の区間（§4 の 1 の作り直し）と Zurich の符号化、行の書き出し。`width_eval` の `WidthSets`・共通の中心・`block_counts`・抽出を再利用する。符号化は `content_eval` のもの（訓練の区間）と `geom_eval.encode_places`（Zurich）を使う
- `exp/vision/results/v18c/judge_dyn.py`（新規）: 区間と §3.3 の規則での判定
- 計算量（見積もり、推測）:
  - 線形の 256 刻みは、刻みごとに 128×128 のモーメント。約 13 万の行 × 256 刻みで、GPU で数分、float64 の CPU で数十分
  - MLP の 17 刻み × 3 seed = 51 本を vmap で並列にすると、符号あたり 10〜20 分
  - 符号化は V-h4b の実績（1 符号 約 9 分。MLP の学習を含む）から 10 分前後。区間を長くした分は増える
  - 18 符号を std-00〜03 の 4090 で回すと、1〜2 時間
  - テストは合成の神託（S1〜S9）と、閉じた解の勾配が 0 になることで書く
- 実装の規模: lib が 300〜400 行、vision の評価が 300 行前後、判定が 200 行前後、テストが 300 行前後（推測）
