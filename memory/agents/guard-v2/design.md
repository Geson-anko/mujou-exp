# 線形の幅のガードの作り直し（guard-v2）の設計メモ（2026-11-26）

役割: 拡散のデコーダのガードが V-h2 で外れた後の、ガードの作り直しの設計。V19 の値は見ていない。新しいガードの値も 1 つも計算していない。計画への登録は `exp/vision/plans/jepa.md` の「線形の幅のガードの作り直し（2026-11-26、V19 の値を見る前）」。README への記録は次の段。

経緯: 第 1 案（読み出しの時刻の判別で分解能 $\tau_{\mathrm{res}}$ を測り、幅を $\tau_{\mathrm{res}}$ から先で数える）を書き、Codex さんに批判してもらった（[../codex/guard-v2-critique.md](../codex/guard-v2-critique.md)）。第 1 案は反例で崩れたので、観測の再構成の第 2 版に替え、2 回目の批判で第 3 版に直して登録した。第 1 案の要点と崩れた理由は 6 節に残す。

## 1. 見立ての確かめ

依頼の見立て「幅は速い内容を捨てればいくらでも伸ばせるので、幅と保たれた情報の両方で読む（前線）」は正しい。Fable さんの定理（定常で有界な符号では $G_{\mathrm{mid}} \ge s/2$）から、幅には遅さが要る。時間の 2 次の統計だけでは、「速い内容を捨てて遅くした」と「同じ内容をまっすぐな座標に並べ直した」を分けられない。V-h2 の時間の平均の族で $\bar\Delta_1$ が 0.8 → 1.92 秒と伸びたのは、この定理のとおりである。

改めた点は、情報の軸の選び方である。

- **時刻の同定・判別（候補 (b)、旧ガードも同じ形）は、情報の保持を測らない。** 最近傍の同定は「残った内容が時刻を見分けるか」を問う。遅い内容が残っていれば、速い内容を全て捨てても見分けられる。Codex さんの反例: 的 $e_t = (s_t, f_t)$ を周期 30 秒と 0.9 秒の単位円の回転とする。9 フレームの過去の箱形平均は $f_t$ を完全に消す。$s_t$ には可逆な回転と縮尺がかかるだけなので、線形の読み出しは位相の遅れを補って $(s_t, 0)$ を返す。候補のノルムは一定なので、cosine の順位は $s_t^\top s_{t\pm\delta}$ だけで決まり、全ての刻みで判別は 1 になる。一方、幅は伸びる。旧ガードの「天井が当て推量」の問題とは別に、同定という問いの形そのものに穴があった
- **候補 (a)（速い内容を線形に読み出せる割合）の弱点は、線形であることにある。** 符号を非線形に並べ直すと、内容を全て保っていても、線形の読み出しは読めない（Codex さんの例: 位相 $\theta_t$ の符号から、位相の $k$ 次と $k+1$ 次の円成分だけでできた的は、可逆に戻せるのに、$k \ge 2$ で母集団の線形の読み出しは直交性で 0 になる）。だから読み出しは非線形にする
- 依頼の候補 (c)（デコーダの条件を全次元に）は採らない。生成の雑音は残り、C8（幅を測っていない方向で当てる）が戻る

## 2〜5. 登録した設計（第 3 版）

登録した本文は、計画の「線形の幅のガードの作り直し（2026-11-26、V19 の値を見る前）」にある。要点:

- 内容の軸: 同じ時刻の符号（白色化した PCA64）から、その時刻の 32×32 の観測を MLP（Zurich 以外の訓練の組で学ぶ、3 seed）で戻したときの、説明された分散の割合 $E$（現在の内容）と、0.1 秒の変化 $d_t = y_t - y_{t-1}$ を $g(c_t) - g(c_{t-1})$ で戻したときの $E^d$（変化の内容）
- 比べ: 幅の比（いまの登録のまま、0.8 秒以上）が $+\Delta_*$ を超え、内容の比 $\psi = \log_2(E_a/E_b)$・$\psi^d$ の下端が $-\psi_*$（0.1 オクターブ）を超えるときだけ「観測の内容を落とさずに、幅が実用上広い」。比べる相手の $E_b$・$E^d_b$ の下端が 0 を超えることを条件にする
- 理論: 同じ時刻の関数（射影）は、閉じた読み出しの族の最良の誤差を下げない（厳密）。時間の平均には普遍な命題が無い（反例）ので、ガードが「ずる」とするのは「同じ時刻の観測の内容を落として幅を稼ぐ操作」と定義し、`pca` の時間の平均がそれに当たるかは V-h4b1 で確かめる
- V-h4a（合成の陽性の対照: 位相の 1 次の符号と、4・5 次の符号。陰性の対照: 遅い回転と速い OU の混合から OU を捨てる・平均する。余裕の較正: ガウスの雑音で $\psi = -\psi_*$ ちょうどの損失）、V-h4b（実データ: 時間の平均の族が「内容を落とした」になる、射影の族の単調さ、`pca` とその回転の誤検出、物差しが比べられる条件を満たす）

### 第 2 版から第 3 版への直し（Codex さんの 2 回目の批判）

第 2 版は、説明されない分散の比 $\log_2(U_a/U_b)$ を余裕 0.1 オクターブで比べ、観測は 32×32 の現在の画面だけ、時間の平均は「消えた成分が $y_t$ を予測していた分だけ $U$ を上げる」（命題 2）としていた。

1. 命題 2 は誤り（過去の平均は過去から現在を予測する情報を取り込める。無理回転では平均が可逆な線形変換にとどまる）。→ 普遍な命題をやめ、ずるの定義を操作的にした
2. 32×32 の全画面の誤差は、画面の一部の速い動きを見落とす。→ 変化の内容 $E^d$ を足した。32×32 より細かい内容は測らないと書いた
3. 説明されない分散の比は、相手が弱いほど余裕が緩む（$U_b > 0.93$ なら定数の読み出しも通る）。→ 説明された分散の比にし、比べられる条件を足した。読み出しの seed の揺れ $\sigma_{\mathrm{seed}}$ を区間に足した。既知の損失を余裕のちょうど上に置く較正（V-h4a3）を足した
4. 陽性の対照（$y = \cos(Kz + b)$）は、窓の差が保証されず、近似誤差と切り分けられない。→ 位相の 1 次と 4・5 次の符号（互いに戻せ、窓が閉じた形）に替え、観測に既知の雑音を足して最良の誤差をそろえた。射影の族は実データで幅が伸びなかったので、陰性の対照の確かめは合成（V-h4a2、幅が伸びることも要求）に移した
5. V19: 再帰なら履歴とウォームアップをそろえる、C25 は残す、言える範囲を限る。→ 採った

## 6. 第 1 案（退けた）と、退けた理由

第 1 案: 最小二乗で読み出した Inception の特徴が、本物を $t \pm \delta$ の候補より近いと判別できる割合の $\min(A^-, A^+)$ が 3/4 以上続く最小の $\delta$ を分解能 $\tau_{\mathrm{res}}$ とし、幅を $\tau_{\mathrm{res}}$ から先で数え（0.8 秒の下限の置き換え）、比べは幅と分解能の両方で行う。定理 1 として「過去の箱形平均は窓の反転で不変なので、可逆な過程なら $A^-(w) \le 1/2$」を置いた。

退けた理由（Codex さんの指摘。どれも同意した）:

1. 判別は情報の保持を測らない（1 節の反例。速い内容を全て消しても、全ての刻みで判別は 1）
2. 定理 1 は、順序のある stack の符号では成り立たない。stack の符号 $c_u$ 自体が窓の中の順序を持つので、$c_u$ の平均は窓の反転で不変ではない（例: 独立なフレーム $X_t$ で $c_t = (X_t, X_{t-1})$ なら、最小二乗の予測と $X_t$・$X_{t-w}$ の共分散の比は $(w+1) : 1$ で、$A^-(w) \to 1$）。成り立つのは `mean8` のようにフレームそのものを平均した符号だけである
3. 下限を $\tau_{\mathrm{res}}$ で切ると、測る対象が符号ごとに変わる。$\min(A^-, A^+) = 3/4$ でも、同じ錨で両方に勝つ割合は 1/2 まで下がりうる。遠い刻みの谷 1 つで $\tau_{\mathrm{res}}$ が跳び、再出現が主の窓に昇格する
4. 分解能の非劣性の余裕に $\Delta_*$ を借りる根拠が無い

0.8 秒未満の幅を比べに使うことは、第 2 案では決めない。忠実さの軸で、stack の中の平均（`mean8` の形）が内容を落とすことは捕まえられるはずだが、stack の重なりそのものによる窓は、どの符号にも共通の入力の性質なので、それを符号の手柄として比べてよいかは別の問いである。V-h4 の後、V19 の値を見る前にユーザーに示して決める。
