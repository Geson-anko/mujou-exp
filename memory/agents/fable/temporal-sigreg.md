# 時間相関のある単一ストリームのための SIGReg（調査と考案、2026-11-23）

V19（BP・ストリーム・標準の SIGReg）で何を測るかと、V20（時間相関の SIGReg）の設計に使うための報告である。コードは書いていない。数値は、下の閉じた式を使い捨てのスクリプトで計算したもので、スクリプトはリポジトリに無い（付録に式の実装を載せた。使うときは `tests/` のオラクルとして書き直す）。

書いてあることの確かさは 3 段階に分ける。

- **確かめた**: 式を導き、モンテカルロか、ゲインを 1 つ学ぶオンラインの模擬で数値が合った
- **導いた**: 式は導いたが、数値の確かめは平均場の積分か 1 次の展開まで
- **推測**: 実データや M17 の結果への当てはめ。V19 で確かめる対象

## 0. 要点

1. ストリームの SIGReg の偏りは、統計量の値より**勾配の固定点**に出る。いまの標本とバッファの行との相関の平均を $\bar r$ とすると、1 次元では $\bar r > 1 - 2^{-3/2} = 0.646$ で尺度 0（崩壊）が安定になる。AR(1) と一様な FIFO では、相関時間 $\tau$ が窓 $T_w$ の約 1.05 倍を超える成分が消える（確かめた）
2. $D$ 次元でランダムな方向に射影すると、この選別は $D$ 倍に強まる。成分 $e$ の分散は 1 次で $s_e^2 \approx 1 - D(\bar r_e - \bar r_{\mathrm{avg}})$ になる。$D$ = 1024 では、相関の平均が全体より 0.001 大きいだけの成分が消える（導いた。$D$ = 64 の平均場の積分と合う）。つまり標準の SIGReg と FIFO は、窓より遅い成分を捨て、速い成分（雑音）だけを残す
3. 偏りの源は 2 つに分かれる。(a) いまの標本と、それと相関するバッファの行を同じ統計量に入れること。(b) 窓が相関時間より短いこと。(a) は「いまの標本を、相関が消えるだけ古い行とだけ比べる」（時間差つきの交差適合）で消える。(b) は、表現そのものではなく**イノベーション**（1 つ前から予測できない残差）を検定の標本にすると、要る窓が表現の相関時間ではなく残差の相関時間になる
4. イノベーションを使う案は、勾配を対の両端（$z_t$ と $z_{t-\delta}$）に流すときだけ偏らない。$z_t$ だけに流すと、遅い成分はやはり消える（確かめた）
5. 推奨は、手法 3（自己回帰の残差の SIGReg、対の勾配）を V20 の本命、手法 1（遅らせたストリームを並べたミニバッチ）を上限の参照、手法 2（時間差つきの FIFO）を最小の変更、手法 4（時間差つきのモーメント整合）を対照とする順である。ただし $D$ = 1024 のデータポイントにスライスの検定をかけること自体が弱い（上の 2）。これはユーザーの判断が要る（5 節）

## 1. 問題の定式化

### 1.1 記号

- $z_t \in \mathbb{R}^D$: 時刻 $t$ のデータポイントの表現。フレームの間隔は $\Delta$（1/30 秒）
- 射影 $x = a^\top z$。SIGReg は $S = N \int \lvert \hat\varphi(u) - e^{-u^2/2} \rvert^2 e^{-u^2/2}\, du$ を方向 $a$ で平均する
- FIFO は $N - 1$ 行で、$k$ フレームに 1 行入れる。窓の幅は $T_w = (N-1) k \Delta$。いまの標本と $j$ 番目の行の相関を $\rho_j$、その平均を $\bar r = \frac{1}{N-1} \sum_j \rho_j$ とする
- $\tau$: 表現の相関時間。$\tau_\theta$: エンコーダが変わる時間（同じ入力の $z$ が変わる時間）

### 1.2 核の形

$\int \cos(u(x-y)) e^{-u^2/2} du = \sqrt{2\pi}\, e^{-(x-y)^2/2}$ なので、Epps–Pulley はガウス核の MMD の V 統計量である。

$$\frac{S}{N} = \frac{1}{N^2} \sum_{i,j} k(x_i - x_j) - \frac{2}{N} \sum_i \kappa(x_i) + \sqrt{2\pi/3},\quad k(v) = \sqrt{2\pi}\, e^{-v^2/2},\quad \kappa(x) = \sqrt{\pi}\, e^{-x^2/4}$$

いまの標本にかかる勾配は $\partial S / \partial x = \frac{2}{N} \sum_j k'(x - x_j) - 2\kappa'(x)$ である。第 1 項はバッファの各行からの斥力（幅 1 のガウス核）、第 2 項は原点への引力になる。対角の項 $k(0)$ は定数で、勾配に寄与しない。

### 1.3 値の偏り（確かめた）

射影が定常なガウス過程で、周辺が $N(0,1)$、対の相関が $\rho_{ij}$ のとき

$$E\,S = S_0 + \frac{1}{N} \sum_{i \ne j} G(\rho_{ij}),\quad G(\rho) = \sqrt{\frac{2\pi}{3 - 2\rho}} - \sqrt{\frac{2\pi}{3}},\quad S_0 = G(1) = 1.059,\quad G'(0) = 0.482$$

m17.md の「定義」の 1 次の式 $S_0 + f'(0)(N-1)\bar r$ を、すべての次数で書いたものである。連続した $N$ 行の FIFO と AR(1)（$\rho_l = e^{-l k \Delta / \tau}$）では $E\,S = S_0 + \sum_{l=1}^{N-1} 2(1 - l/N)\, G(\rho_l)$ になる。$N$ = 256 の値は次のとおり（`exp/lib/sigreg.py` と同じ 17 点の台形則のモンテカルロは、閉じた式より 0〜5% 大きい）。

| $\tau / (k\Delta)$ | 0 | 1 | 10 | 100 | 1000 | $\infty$ |
| --: | --: | --: | --: | --: | --: | --: |
| $E\,S$ | 1.06 | 1.71 | 13.3 | 96.2 | 227 | 271（$= N S_0$） |

周辺が正しくても、値は相関だけで 1.06 から 271 まで動く。小さい相関では $E\,S \approx S_0 + 0.96\, \tau / (k\Delta)$ である。一方、周辺の分散が $1 + \eta$ にずれたときの信号は $0.12\, N \eta^2$ で、$N$ = 256、$\eta$ = 0.1 なら 0.31 しかない。値は、分布のずれより相関を測っている。

### 1.4 勾配の固定点（1 次元、確かめた）

値の偏りより大事なのは、勾配がどこで止まるかである。エンコーダの尺度を $s$ とし（$x = s u$、$u$ は分散 1）、バッファの行も同じ $s$ で作られたとする。いまの標本だけに勾配を流すと、$s$ の期待される勾配が 0 になる条件は

$$\frac{1}{N} \sum_{j=1}^{N-1} (1 - \rho_j) \left( 2 s^2 (1 - \rho_j) + 1 \right)^{-3/2} = (s^2 + 2)^{-3/2}$$

である（ガウスの積分と Stein の恒等式から。付録の `pred_gu`）。この式から次が出る。

- **i.i.d.**（$\rho_j = 0$）: $s^2 = (2c - 1)/(2 - c)$、$c = (1 - 1/N)^{2/3}$。$N$ = 256 で 0.992、$N$ = 16 で 0.879、$N$ = 8 で 0.764。V 統計量の $1/N$ の偏りで、対の和を $1/(N(N-1))$ で割る U 統計量にすれば $s^2 = 1$ になる
- **$s = 0$ の安定性**: $s \to 0$ で $\dot s \propto s \left[ (1 - \bar r)\frac{N-1}{N} - 2^{-3/2} \right]$。$\bar r > 1 - 2^{-3/2} = 0.646$ なら崩壊が安定になる
- **等しい相関 $r$**: $s^2 = (1 - 2q^{2/3}) / (q^{2/3} - 2q)$、$q = 1 - r$。小さい $r$ では $s^2 \approx 1 - r^2/3$ で、$r$ = 0.3 で 0.94、0.5 で 0.70、0.6 で 0.33、0.646 で 0
- **割合 $p$ の行がいまの標本と同じ（$\rho = 1$）で、残りが独立**: $s^2 \approx 1 - 2p$、$p$ = 0.646 で 0
- **AR(1) と一様な FIFO**（$N$ = 4096）:

| $T_w / \tau$ | 100 | 30 | 10 | 5 | 2 | 1.2 | 1.05 | 1.0 | 0.9 以下 |
| --: | --: | --: | --: | --: | --: | --: | --: | --: | --: |
| $\bar r$ | 0.010 | 0.033 | 0.100 | 0.199 | 0.432 | 0.582 | 0.619 | 0.632 | 0.659 以上 |
| $s^2$ | 0.995 | 0.982 | 0.945 | 0.881 | 0.628 | 0.266 | 0.125 | 0.068 | 0 |

オンラインの模擬（AR(1) のストリーム、$N$ = 256 の FIFO に古いゲインの出力を貯め、SGD でゲインを 1 つ学ぶ、8 本の平均）は、$T_w/\tau$ = 2 で $s^2$ = 0.631（予測 0.622）、0.5 で 0、i.i.d. で 0.997（予測 0.992）だった。

非常に遅い成分（$T_w/\tau \lesssim 0.12$）では、$s^2 \approx 20$〜$40$ に不安定な固定点が現れ、その外側では尺度が発散する。崩壊と発散の双安定になる。

模擬で気づいた点が 1 つある。学習率と勾配の大きさの積に相関時間のステップ数を掛けたものが 1 に近いと、期待値では崩壊する設定で尺度が発散した。勾配の雑音が相関時間のあいだ同じ向きを保つためである。optimizer の時定数は、表現の相関時間より十分長くなければならない。

### 1.5 $D$ 次元のスライスでは選別が $D$ 倍になる（導いた）

$z = \operatorname{diag}(s) u$ で、成分 $u_e$ は独立な定常ガウス過程、成分 $e$ のいまの標本とバッファの相関の平均を $\bar r_e$ とする。ランダムな単位方向 $a$ の射影では、斥力と引力の非線形の部分が $v_a = \sum_k a_k^2 s_k^2$ のような全成分の平均だけで決まる。そのため成分 $e$ の尺度の動きは $s_e$ について線形になり、成分どうしが競合する。$s_k^2 = 1 + \eta_k$ と小さい相関で 1 次まで展開すると、$E[a_e^2 a_k^2] / E[a_e^2] = (1 + 2\delta_{ek}) / (D+2)$ から

$$\frac{d \log s_e}{dt} \propto -\frac{D}{D+2} (\bar r_e - \bar r_{\mathrm{avg}}) - \frac{1}{D+2} \left( \eta_e + \tfrac{D}{2} \bar\eta \right) \;\Rightarrow\; s_e^2 \approx 1 - D\, (\bar r_e - \bar r_{\mathrm{avg}})$$

になる。等方へ戻す力は $1/D$ の大きさしかなく、相関による選別は $D$ によらない。$D$ = 64 の平均場の積分（スライス 300 本）は次のとおりで、1 次の式と合う。

| 半分の成分の $r$ | 0.002 | 0.01 | 0.05 |
| --: | --: | --: | --: |
| 相関のある半分の $s^2$ | 0.93 | 0.60 | 0.002 |
| 白色の半分の $s^2$ | 1.07 | 1.40 | 2.03 |
| 差（1 次の予測 $-Dr$） | −0.14（−0.13） | −0.81（−0.64） | −2.0（−3.2、飽和） |

相関時間の違う成分を混ぜると（$D$ = 256、$\tau / T_w \in \{0, 0.003, 0.01, 0.03, 0.1, 0.3\}$ を等分）、$\tau / T_w \ge 0.03$（$\bar r \ge 0.022$）の成分はすべて 0 になり、残りが 1.6〜2.3 に膨らんだ（トレースは保たれる）。AR(1) では、遅い成分の $1 - \rho_j$ がどのラグでも速い成分より小さい。重みがどうであっても遅い成分の伸びが速い成分を上回ることはなく、最も速い成分だけが残る。

これは「スライスの検定は、高次元では個々の方向の分散をほとんど見ない」ことの現れである。高次元のデータの低次元の射影はほとんどがガウスに近く見える（Diaconis & Freedman 1984）。スライスが主に拘束するのは $\operatorname{tr} \Sigma / D$ で、スペクトルの形への力は $1/D$ である。i.i.d. では反対向きの力が無いので問題にならないが、ストリームでは相関による選別がこれに勝つ。

### 1.6 窓・相関時間・表現の古さ

- **相関時間**: 上から、成分 $e$ が残る条件は $D\, \bar r_e \ll 1$（スライスの検定）である。AR(1) では $\bar r_e \approx \tau_e / T_w$ なので $T_w \gg D \tau_e$ が要る。$D$ = 1024、$\tau$ = 1 秒でも 17 分、$\tau$ = 1 分なら 17 時間になる。m17.md の白色化した相関は 51 秒で 0.038、方向ごとの最大は 54.6 分で 0.62 だった。$N$ = 256、$k$ = 6（$T_w$ = 51 秒）はこの条件から大きく外れる
- **古さ**: バッファの行は入れたときのエンコーダのものである。尺度が一様に縮むとき、古い行は大きいままなので、統計量が縮みに気づくのは $T_w$ だけ遅れる。固定点の式は $T_w \ll \tau_\theta$ を前提にしている
- **合わせると**: $D \tau \ll T_w \ll \tau_\theta$ が要る。遅い方向（分〜時間）についてこれを満たす窓は無い。「長い窓で i.i.d. に近づける」方針は、$D$ = 1024 では成り立たない
- **chunk（$c$ = 10）**: 連続した 10 個の stack を 1 つの batch として SIGReg に入れると、batch の中の対は $\rho \approx 1$ で勾配も両側に流れる。1.4 の「割合 $p$」が $p \approx c/N$ だけ増える。V19 で chunk を使うなら、batch の中の対を統計量から外す（バッファとの対だけを使う）腕を対照に置く

### 1.7 M17 との関係（推測）

M17 のデータポイントの SIGReg（$N$ = 256、$k$ = 6）で stack の中のトークンの広がりが縮んだことは、上の機構と矛盾しない。遅い方向から順に分散が消え、残る方向に分散が集まるはずである。ただし m17.md の「最初の 1 分の縮みの原因」は重みの変化に原因を求めており、この機構で説明できるかは確かめていない。V19 で、方向ごとの $\bar r_e$ と分散の変化を並べて確かめる（4.2 節）。

## 2. 文献調査の要点

### 2.1 従属データの下での正規性の検定

- Epps (1987), "Testing that a stationary time series is Gaussian", Ann. Statist. 15。経験特性関数の実部と虚部のベクトルを、長期共分散（スペクトル密度の 0 での値）の逆行列で規格化した 2 次形式で検定する。相関は帰無仮説の側に入れ、分散を補正する。Lobato & Velasco (2004) は歪度と尖度を長期分散で規格化し、Bai & Ng (2005) も同じ系統である。Psaradakis & Vávra (2020) はブートストラップで臨界値を作る。実装は R の `nortsTest`（<https://journal.r-project.org/articles/RJ-2024-008/>、arXiv:2009.10481）にまとまっている
  - 読み: これらはどれも「統計量の帰無分布」を直す。値を較正するには使えるが、損失として最小化するときの固定点は直さない（手法 5）
- Hong (1999), JASA 94, "Hypothesis testing in time series via the empirical characteristic function: a generalized spectral density approach"。対の結合特性関数 $\operatorname{cov}(e^{iuX_t}, e^{ivX_{t-j}})$ のスペクトルで、あらゆる対の系列依存を検定する。イノベーションの白色性を特性関数で確かめる道具になる
- 残差に基づく検定: AR・ARMA・GARCH の残差の経験特性関数や経験分布で、イノベーションの分布を検定する（Klar, Lindner & Meintanis 2012, CSDA, <https://www.sciencedirect.com/science/article/pii/S0167947310002409>。AR-ARCH のガウスのイノベーションは arXiv:1211.1204）。パラメータの推定が帰無分布に入るので、臨界値はブートストラップで作ることが多い。「相関のある系列では、周辺ではなく残差を検定する」という古典的な答えである
- Burg の最大エントロピーの定理（Cover & Thomas の定理 12.6.1、Choi & Cover 1984）: ラグ $p$ までの自己共分散を固定したとき、エントロピー率が最大の定常過程はガウスの AR($p$) である。LeJEPA の目標 $N(0, I)$（共分散を固定したときの最大エントロピー）を時間方向に延ばすと、ガウスの AR(1)（OU 過程）になる

### 2.2 従属データの下での MMD と確率近似

- Chwialkowski, Sejdinovic & Gretton (2014), "A wild bootstrap for degenerate kernel tests", arXiv:1408.5404。弱い従属の下では MMD の V 統計量の帰無分布が変わる。離れたラグで独立に近づくことを仮定する
- Chérief-Abdellatif & Alquier (2022), Bernoulli 28, arXiv:1912.05737。MMD を最小にする推定は、ラグ $s$ の依存の係数の和が有限なら i.i.d. と同じ $n^{-1/2}$ で一致し、SGD の解析もある。「目的が標本について線形な期待値で書ければ、従属は分散を増やすだけで固定点を動かさない」ことの裏付けになる
- マルコフ連鎖の標本の SGD: 定数のステップでは漸近の偏りが残り（arXiv:2210.00953）、収束は混合時間の対数の因子だけ遅くなる（arXiv:2003.10973）。Nagaraj ら (2020), arXiv:2006.08916 は、混合時間ごとに 1 標本だけ使う SGD（data drop）と、リプレイが偏りを減らすことを示した（番号は記憶による。要確認）。時間差を置く案の根拠になる

### 2.3 LeJEPA とその後

- LeJEPA（Balestriero & LeCun 2025, arXiv:2511.08544）: SIGReg の勾配の偏りは $O(1/N)$ と書かれている。1.4 の $s^2 = (2c-1)/(2-c)$ がその具体的な形である
- LeWorldModel（arXiv:2603.19312）: 軌跡の batch（128 本 × 4 ステップ）に SIGReg をかける。付録の擬似コードは時刻ごとに batch の上で統計量を取る。軌跡の中の時間相関は論じていない。「多様さの低いデータでは SIGReg が弱まる」と限界に書いている
- Klindt, LeCun & Balestriero (2026), "When Does LeJEPA Learn a World Model?", arXiv:2605.26379。潜在変数が $z' = \rho z + \sqrt{1 - \rho^2}\, \eta$（OU の遷移）で動く世界では、時間の整合と周辺のガウス化を満たす最適な表現は $h(z) = Qz$ に限られ、そこでは $h(z') \mid h(z) \sim N(\rho h(z), (1 - \rho^2) I)$ になる。**正しい表現のイノベーションは等方なガウスである**。手法 3 の帰無仮説の裏付けになる。同じ論文は、実際の軌跡（非ガウス、異方、時間に従属）では回復が崩れることも報告している。正則化を従属な標本から推定する問題は扱っていない
- 周辺の記事と検索の要約だけで確かめたもの（本文は読んでいない）: Sub-JEPA（arXiv:2605.09241、ランダムな部分空間ごとの SIGReg。1.5 の $1/D$ の弱さに関係する可能性がある）、Phys-JEPA（arXiv:2606.16076、残差の成分にだけ SIGReg）、AnisoWM（arXiv:2609.37441、対角の共分散を学ぶ）、MotionJEPA（arXiv:2609.23881、遅い特徴への偏りと時間方向の崩壊を扱う）、"Drive vs. Decay"（arXiv:2610.02344、線形の JEPA の崩壊点のまわりの安定性）
- 「SIGReg を時間相関のある標本にかけたときの偏り」を解析した文献は見つからなかった

### 2.4 単一ストリームの自己教師あり学習

- Carreira ら (2024), "Learning from One Continuous Video Stream", arXiv:2312.00598。連続したフレームの相関が学習を難しくする。画素の予測と optimizer の選び方で対処する
- Han ら (2025), "Learning from Streaming Video with Orthogonal Gradients", arXiv:2504.01961。Walking Tours の 1 本を順に見せると DoRA や VideoMAE が劣化する。勾配を直交化して batch の相関を除く
- Martinović, Knobel & Asano (2026), "I Have a Stream", arXiv:2609.40333。95 時間の街歩きの動画（WT++）。劣化の主因は batch の**中**の類似で、batch の間の類似ではないとする（ImageNet を事前に並べ替えたストリームは i.i.d. と同じ性能）。対照学習と蒸留は順の入力で崩れ、MAE は標本ごとの損失なので耐える。1.4 の「いまの標本と同じ統計量に入る標本との相関が効く」と同じ向きの観察である
- Purushwalkam ら (2022), arXiv:2203.12710。冗長さが最小になるようにリプレイのバッファを保つ（MinRed）。相関を除く方向の対処で、手法 1・2 に近い

### 2.5 時間の構造を使う表現学習

- Slow Feature Analysis（Wiskott & Sejnowski 2002）: 平均 0・分散 1・無相関の拘束の下で時間変化を最小にする。崩壊を防ぐのは 2 次のモーメントの拘束である。オンライン版の IncSFA（Kompella ら 2012, arXiv:1112.2113）は、白色化を逐次の PCA で推定する
- 時間構造による非線形 ICA の同定: 自己相関の違いで成分を分ける 2 次の方法（AMUSE、SOBI）、TCL・PCL（Hyvärinen & Morioka、arXiv:1605.06336 ほか）、イノベーションの独立性を使う IIA（Morioka ら 2021）、SlowVAE（Klindt ら 2021, arXiv:2007.10930）。時間の相関が「手がかり」になる理論的な根拠はここにある。成分ごとの自己相関が違えば、回転の不定性が消える。ただし TCL・PCL は識別（負例に当たるもの）を使うので、そのままは使えない

## 3. 考案した手法

設計の原理は 3 つである。

- **P1（時間差つきの交差適合）**: 母集団の MMD$^2$ の勾配は $2 E[\nabla h(x)\, \partial x / \partial\theta]$、$h(x) = E_{x'} k(x - x') - \kappa(x)$ である。$h$ をいまの標本と独立な標本から作れば、勾配は $N$ にも $D$ にもよらず不偏になる。ストリームでは「相関が消えるだけ古い標本」がそれに当たる
- **P2（イノベーション）**: 検定の標本を、過去から予測できない残差にする。帰無仮説の下で残差は i.i.d. なので、検定の前提がそのまま成り立つ
- **P3（対の勾配）**: 残差は 2 つの時刻の表現の関数なので、勾配は両方に流す

### 手法 1: 遅らせたストリームのミニバッチ（参照）

- **目的の式**: 同じストリームを $g, 2g, \dots, (B-1)g$ 秒遅らせた写しを並べ、$B$ 個の stack をいまのエンコーダで符号化する。U 統計量の SIGReg をこの $B$ 個にかける

  $$S_U = \frac{1}{M} \sum_m \left[ \frac{1}{B(B-1)} \sum_{b \ne b'} k(x_b - x_{b'}) - \frac{2}{B} \sum_b \kappa(x_b) \right],\quad x_b = a_m^\top z_{t - bg}$$

- **帰無仮説**: 周辺が $N(0, I)$ で、ラグ $g$ 以上の対は独立
- **自明な解**: 母集団の MMD$^2$ は、ガウス核が特性的なので、周辺が $N(0, I)$ のときだけ 0 になる（Cramér–Wold）。定数・位置だけの関数は周辺が 1 点なので正の値を取る。stack の中で一定な解は共分散の rank が $d$ で、等方でないので正の値を取る。ここまでは標準の SIGReg と同じである（スライスの力が $1/D$ である弱さも同じ）
- **相関が 0 のとき**: 標準の SIGReg の U 統計量版そのもの
- **定常ガウス過程での偏り**: 1.4 の式で $\rho_j = \rho(\lvert b - b' \rvert g)$、$D$ 次元では $s_e^2 \approx 1 - D(\bar r_e - \bar r_{\mathrm{avg}})$。$g \gtrsim \tau \ln D$ で消える
- **計算量**: 順伝播と逆伝播が $B$ 倍。入力を $(B-1)g$ 秒ぶん保つ（動画のファイルを遅らせて読めばよい）
- **PC-ALM**: $B$ 本のストリームの batch と同じ。SIGReg のノードは batch の $z$ を受けて各標本に credit を返すだけで、局所的である
- **オラクル**: 遅れの相関を 0 にした合成ストリームで $s^2 = 1$（U）、V 統計量なら $(2c-1)/(2-c)$
- **弱点**: 計算が $B$ 倍。遅い方向（$\tau$ が分〜時間）には $g$ が時間の単位になる。古さは無い。「相関を除く」案で、相関を手がかりにはしない

### 手法 2: 時間差つきの FIFO（最小の変更）

- **目的の式**: FIFO に、いまより $g$ 秒以上古い $z$ だけを入れる（遅延の列を通してから入れる）。いまの標本の損失は

  $$\ell(z_t) = \frac{1}{M} \sum_m \left[ \frac{2}{N_b} \sum_{j} k(a_m^\top z_t - a_m^\top \tilde z_j) - 2\kappa(a_m^\top z_t) \right]$$

  で、$\tilde z_j$ は年齢が $[g, g + T_w]$ の行（勾配は流さない）、$N_b$ は行の数である。`exp/lib/sigreg.py` の `sigreg_from_sums` との違いは、遅延と、対の項の正規化（$1/N$ ではなく $1/N_b$）だけである
- **帰無仮説**: 手法 1 と同じ
- **自明な解**: $E\, \ell$ の勾配は P1 により母集団の MMD$^2$ の勾配である。排除は手法 1 と同じ
- **相関が 0 のとき**: $g = 0$ で標準の SIGReg（U の正規化）
- **偏り**: 1 次元、$N$ = 256、V の正規化（i.i.d. の値は 0.992）では、$g = \tau$ で $s^2$ = 0.97（$T_w = 2\tau$）と 0.93（$T_w = 0.5\tau$）、$g = 2\tau$ で 0.985、$g = 3\tau$ で 0.991（後の 2 つはどちらの $T_w$ でも同じ。確かめた。模擬では $g = 3\tau$、$T_w = 2\tau$ で 1.006）。$D$ 次元では $D\, \bar r_e(g) \ll 1$、つまり $g \gtrsim \tau_e \ln(D \tau_e / T_w)$ が要る
- **計算量**: いまと同じ。遅延の列に $g$ 秒ぶんの $z$（$g$ = 60 秒で 7 MB）
- **PC-ALM**: いまの SIGReg のノードのまま。遅延と窓は秒で定義する
- **オラクル**: 1.4 の式で $\rho_j = \rho(g + j k \Delta)$ とした $s^2$。$g = 0$ で 1.4 の表に戻る
- **弱点**: 行は $g + T_w$ まで古い。$g + T_w \ll \tau_\theta$ と $g \gg \tau \ln D$ の両方は、遅い方向では満たせない。その方向は消える。V19 の測定（4.2 節の 1 と 5）で、どの方向まで保てるかが決まる

### 手法 3: 自己回帰の残差の SIGReg（本命）

- **目的の式**: ストリームと、それを $\delta$ 秒遅らせた写しの 2 本を符号化する（$B$ = 2）。座標ごとに、過去の標本の指数平均（時定数 $T_{\mathrm{est}}$ 秒）で平均 $\hat\mu_i$、分散 $\hat v_i$、ラグ $\delta$ の共分散 $\hat c_i$ を持ち、$\hat r_i = \hat c_i / \hat v_i$ とする。残差を

  $$\varepsilon_{t,i} = \frac{(z_{t,i} - \hat\mu_i) - \hat r_i\, (z_{t-\delta,i} - \hat\mu_i)}{\sqrt{1 - \hat r_i^2}}$$

  と置き、$\varepsilon_t \in \mathbb{R}^D$ に手法 2 の形の SIGReg をかける。FIFO には過去の $\varepsilon$ を $\delta$ 秒以上の間隔で入れ、いまの $\varepsilon_t$ とは $\delta$ 秒以上離す。勾配は $z_t$ と $z_{t-\delta}$ の両方に流す
- **帰無仮説**: 各座標が、ラグ $\delta$ で AR(1) の定常ガウス過程で、分散 1、自己相関 $r_i$ は自由（複合仮説）。イノベーションは座標の間でも時刻の間でも独立。Burg の定理から、これは「分散とラグ $\delta$ の自己相関を固定したときにエントロピー率が最大の過程」である。Klindt ら (2026) の OU の世界では、正しい表現がこの帰無仮説を満たす
- **自明な解の排除**: $\hat r_i$ が座標の自己相関に一致するとき $\operatorname{Var}(\varepsilon_i) = v_i (1 - 2 \hat r_i \rho_i + \hat r_i^2) / (1 - \hat r_i^2) = v_i$ なので、$\varepsilon \sim N(0, I)$ は $v_i = 1$ を要求する。分母に使うのは目標の分散 1 から決まる $1 - \hat r_i^2$ で、実際の残差の分散ではない。そのため尺度が拘束される（行列の形では、$\operatorname{Var}(\varepsilon) = I$ は $C_0 - I = A (C_0 - I) A^\top$ と同値で、$A$ のスペクトル半径が 1 未満なら $C_0 = I$ だけが解になる）
  - 定数・位置だけの関数: $v_i = 0$ で $\varepsilon$ が 1 点になり、正の値を取る。$s \to 0$ は 1.4 と同じ理由で不安定である（残差どうしの相関が 0 なので $\bar r = 0$）
  - 平均のまわりの小さな白色の揺れ $z = m + \sigma\eta$: 中心化しているので $\hat r = 0$、$\operatorname{Var}(\varepsilon) = \sigma^2$ となり、$\sigma^2 = 1$ が要る。中心化しない統計を使うと、$\lvert m_i \rvert = 1$ と無限小の雑音が検定を通る。中心化は必須である
  - stack の中で一定: $\varepsilon$ の共分散の rank が $d$ になり、等方でない（スライスの力は $1/D$）
  - 通るが健全でない解: 各座標が分散 1 の白色雑音（$r_i = 0$）。標準の SIGReg の I と同じで、この正則化は遅さを要求も禁止もしない。どちらになるかは予測の項が決める
- **相関が 0 のとき**: $\hat r_i = 0$ で $\varepsilon = z - \hat\mu$ になり、中心化した標準の SIGReg に戻る
- **定常ガウス過程での偏り**（確かめた。$N$ = 256、$\delta$ = 0.5 秒、V の正規化の値。0.989 は i.i.d. の値 0.992 と、根を探す格子の刻み ±0.005 の中で同じ。U なら 1）:

| 座標の過程 | 対の勾配 | $z_t$ だけの勾配 | $z_t$ だけ、時間差 5 秒 |
| -- | --: | --: | --: |
| OU、$\tau$ = 1 秒 | 0.989 | 0.974 | 0.989 |
| OU、$\tau$ = 10 秒 | 0.989 | 0.842 | 0.895 |
| OU、$\tau$ = 100 秒 | 0.989 | 0.103 | 0.139 |
| OU、$\tau$ = 1000 秒以上 | 0.989 | 0 | 0 |

対の勾配なら、相関時間がどれだけ長くても、窓が 128 秒でも偏らない。$z_t$ だけに流すと遅い成分が消える。尺度を変える向き $\partial z_t / \partial s \propto z_t$ が、バッファにある過去の残差と相関するためである（$z_t = \sum_m r^m \varepsilon_{t - m\delta}$）。対の勾配では、向きが $\varepsilon_t$ そのものになり、過去の残差と無相関になる

AR(1) でない座標（$\tau$ = 1 秒と 1000 秒の OU の和など）では、残差に遅い部分が残る。残差どうしの相関の平均は 0.001〜0.05 だった。1 次元の尺度は 0.989 のままだが、$D$ 次元では 1.5 の選別（$D\, \bar r^{\varepsilon}_e$）を受ける。残差の相関が $1/D$ を下回るかは、V19 で測る（4.2 節の 4）。

- **計算量**: エンコーダが 2 倍（$B$ = 2）。統計は $O(D)$、SIGReg はいまと同じ。入力を $\delta$ 秒ぶん保つ
- **PC-ALM**: 2 本のストリーム（片方は $\delta$ 秒遅れ）の batch。SIGReg のノードは 2 つの $z$ から $\varepsilon$ を作り、両方に credit を返す。ノードをまたぐ逆伝播は無い。$\delta$・$T_{\mathrm{est}}$・FIFO の間隔はどれも秒で定義し、指数平均は経過秒で進める
- **オラクル**: (a) 合成の OU（任意の $\tau$）でゲインの 2 乗が 1（U）。(b) $z_t$ だけの勾配では上の表の値。(c) $\operatorname{Var}(\varepsilon_i) = v_i$ の恒等式。(d) $\hat r$ を固定の $\varphi$ に替えたときの下の表
- **相関が手がかりになる点**: 学ぶ統計 $\hat r_i$ から座標ごとの時定数 $\tau_i = -\delta / \ln \hat r_i$ が読める。座標ごとに別の自己相関を許すので、遅い成分と速い成分が座標に分かれる解が帰無仮説に入る。自己相関の違う成分は 2 次の統計で同定できる（SOBI）ので、座標の回転の不定性も減る
- **弱点**:
  - $B$ = 2 が要る。リアルタイムの予算の半分を使う
  - $\hat\mu, \hat v, \hat r$ は過去の標本の関数で、いまの対を含まない。勾配を止めているのではなく、交差適合である。ただし母集団の目的は「$r$ も同時に最適化した目的」とは違う。帰無仮説での固定点は同じ
  - $T_{\mathrm{est}}$ より遅い座標では、$\hat v_i$ が窓の中の分散になる。その座標は「窓の中の分散が 1」に拘束され、長い時間の分散は 1 より大きくなる。崩壊はしない
  - 対角の $\hat r$ は、座標が動力学の固有方向であることを仮定する。行列 $\hat A = \hat C_\delta \hat C_0^{-1}$ にすれば仮定は消えるが、$D^2$ 個の量の推定が要り、`gauss_kl.py` と同じ推定の問題が戻る
  - $\hat r_i \to 1$ で分母が 0 に近づき、小さな雑音が増幅される。$\delta$ を大きく取れば遠ざかる

**手法 3′（固定の $\varphi$）**: $\hat r_i$ を固定の $\varphi = e^{-\delta / \tau_z}$ に替えると、推定する量が無くなり、帰無仮説は「等方な OU、時定数 $\tau_z$ 秒」の単純仮説になる。ただし表現の時間の尺度を決めてしまう。$\tau_z$ = 1 秒、$\delta$ = 0.5 秒、窓 128 秒、対の勾配での固定点は次のとおり（確かめた）。

| 座標の $\tau$（秒） | 白色 | 0.1 | 1 | 3 | 10 | 100 | 1000 |
| --: | --: | --: | --: | --: | --: | --: | --: |
| $s^2$ | 0.46 | 0.46 | 0.99 | 1.83 | 2.88 | 1.59 | 0（双安定） |
| 無限の窓での値 $\frac{1 - \varphi^2}{1 - 2\varphi\rho_\delta + \varphi^2}$ | 0.46 | 0.47 | 1.00 | 1.85 | 2.95 | 3.93 | 4.07 |

目標より速い成分は縮むが消えない。遅い成分は窓の幅までは増幅され、窓より遅い成分は消える。尺度は $[(1-\varphi)/(1+\varphi), (1+\varphi)/(1-\varphi)]$ の外に出ない。$\tau_z$ の近くを通す帯域の事前分布として働くので、本命にはしない。

### 手法 4: 時間差つきのモーメント整合（対照）

- **目的の式**: $L = \tfrac12 \lVert \mu \rVert^2 + \tfrac14 \lVert \Sigma - I \rVert_F^2$。いまの標本への勾配を、$g$ 秒以上古い標本の指数平均（時定数 $T_w$ 秒）$\hat\mu, \hat C$ で作る

  $$\frac{\partial \ell}{\partial z_t} = \hat\mu + (\hat C - I)(z_t - \hat\mu)$$

- **目標**: 平均 0、共分散 $I$（2 次のモーメントまで。ガウス性は検定しない）
- **自明な解**: $L$ の最小は $\mu = 0$、$\Sigma = I$ だけである。定数は $L = D/4$、stack の中で一定は rank $d$ で $L \ge (D - d)/4$。$s \to 0$ では勾配が $-z$ になり、崩壊は相関によらず不安定である（SIGReg のような閾値が無い）
- **相関が 0 のとき**: 標準の SIGReg には戻らない。SIGReg を 2 次のモーメントまでで打ち切ったものに当たる。1.5 から、$D$ = 1024 のスライスの検定が見ているのもほぼ 2 次までである
- **偏り**: 1 次元で $s^2 = 1 / (1 + 2 \bar r_2)$、$\bar r_2$ はいまの標本と窓の行の相関の 2 乗の平均。模擬は $\tau$ = 128 フレームで 0.695（予測 0.672）、512 で 0.468（0.442）、時間差 $3\tau$ で 1.01（0.999）。$D$ 次元で全成分の相関が等しいときは $s^2 = 1 / (1 + (D+1) \bar r_2)$（Isserlis の定理から。$D$ = 8、$\rho$ = 0.5 のモンテカルロで期待値 2.25 を確かめた）。相関の 2 乗で効くので、条件は $D\, \bar r_2 \ll 1$、時間差は $g \gtrsim \tfrac12 \tau \ln D$ で足りる。個々の方向を戻す力は $O(1)$ で、$1/D$ に薄まらない
- **計算量**: $\hat C$ は $D^2$ = 100 万個の数で、1 フレームに rank 1 の更新と行列とベクトルの積が 1 回。窓を何時間にしてもメモリは増えない
- **PC-ALM**: 状態を持つ 1 つのノード。時定数は秒
- **オラクル**: 上の 2 つの式
- **弱点**: ガウス性を要求しない（離散的な符号も通る）。`gauss_kl.py` と違い逆行列を使わないので $\hat P$ の偏りは無いが、$\hat C$ は $T_w$ まで古い

### 手法 5: HAC で較正した Epps の統計量（診断。損失にはしない）

- **式**: $Q = N\, (\hat g - g_0)^\top \hat\Omega^{-1} (\hat g - g_0)$。$\hat g$ は数点の $u$ での $(\cos u x, \sin u x)$ の平均、$\hat\Omega$ はその長期共分散の推定（Epps 1987）
- **使い道**: held-out のストリームで、周辺が $N(0, 1)$ からどれだけ離れているかを、相関の分を除いて測る。V19 の評価の指標にする
- **損失にしない理由**: $\hat\Omega$ は表現に依存する。表現を遅くすれば長期分散が増えて $Q$ が下がるので、「できるだけ遅くする」が最適解に入る。$\hat\Omega$ の勾配を止めれば避けられるが、それは導出の無い手当てである

## 4. 推奨

### 4.1 順位と理由

1. **手法 3**（残差の SIGReg、対の勾配）: 帰無仮説の下で標本が i.i.d. になる唯一の案で、要る窓が表現の相関時間によらない。OU の世界では正しい表現が帰無仮説を満たす（Klindt ら 2026）。相関を構造として使う。賭けの中身は「健全な表現の残差がどれだけ白色か」で、V19 で先に測れる
2. **手法 1**（遅らせたストリーム）: 仮説「原因は標本の従属である」をいちばん直接に試す。古さが無いので、結果の解釈が単純である。$B$ 倍の計算が要るので、上限の参照として 1 本回す
3. **手法 2**（時間差つきの FIFO）: 変更が最小で、計算も増えない。ただし 1.5 と 1.6 から、$D$ = 1024 では遅い方向を保てないと予測する。手法 1 との差が「古さ」の効果になる
4. **手法 4**（モーメント整合）: 崩壊の閾値が無く、オラクルが正確なので、対照として置く。手法 3 がうまくいかないときの退避先でもある
5. **手法 5**: 診断としてだけ使う

### 4.2 V19 で測る量

学習の前（V18 のエンコーダ）と、V19 の各 checkpoint で測る。

1. **方向ごとの $\bar r_e$**: いまの標本と FIFO の各行の相関を、白色化した表現の固有方向ごとに平均する。$D\, (\bar r_e - \bar r_{\mathrm{avg}})$ の分布と、$> 1$ になる方向の分散の割合を出す。予測は、その方向の分散が $1 - D\, \Delta \bar r_e$ に向かい、遅い方向から先に消えることである。並べ替えた対照では起きない
2. **統計量の分解**: 同じ標本で、すべての対の $S$ と、ラグ $g$ 以上の対だけの U 統計量を計算する。差が相関による項（1.3）で、後者が分布のずれの推定になる。手法 5 の $Q$ も並べる
3. **勾配の比較**: いまの標本への SIGReg の勾配を、ストリームの FIFO と、データ全体からランダムに取った stack をいまのエンコーダで符号化したバッファとで比べる。余弦、動径の成分（$z \cdot g$。負なら縮む向き）、遅い固有方向への射影を見る。1.4 と 1.5 の機構を直接に確かめる測定である
4. **残差の白色性**: 座標ごとに $\hat r_i(\delta)$ を当て、$\delta \in \{0.1, 0.5, 2\}$ 秒で残差 $\varepsilon$ の自己相関を測る。$D\, \bar r^\varepsilon_e$ の分布が手法 3 の成否を決める。あわせて、座標ごとの時定数 $\tau_i$ の分布、ラグ $2\delta$ の偏自己相関（AR(1) からのずれ）、ラグ共分散の非対角の大きさ（対角の $\hat r$ で足りるか）を出す
5. **エンコーダの変化の時間 $\tau_\theta$**: 同じ入力の $z$ が、checkpoint の間でどれだけ変わるか（M17 の `drift`）。$g + T_w$ と比べる
6. **腕の組**: {順のストリーム、並べ替え} × {FIFO、i.i.d. のバッファ} の 4 本。標本の従属の効果と、予測の勾配が相関することの効果（optimizer の側の問題。Han ら 2025）を分ける

### 4.3 手法を見分ける最小の実験

合成のストリームで、CPU で数分の実験である。$D$ = 64、30 Hz、成分は独立な OU で $\tau \in \{0, 0.3, 3, 30, 300\}$ 秒を等分する。対角のゲイン（あるいは線形の写像）を $B$ = 1（手法 1 は $B$ = 8、手法 3 は $B$ = 2）の SGD で学び、損失は正則化だけにする。定常での群ごとの分散を、次の理論値と比べる。

| 腕 | 予測 |
| -- | -- |
| 標準の SIGReg と FIFO | $s_e^2 \approx 1 - D(\bar r_e - \bar r_{\mathrm{avg}})$。$D \bar r_e > 1$ の群は 0、残りが膨らむ |
| 手法 1、手法 2（$g$ を振る） | $D\, \bar r_e(g) \ll 1$ の群だけ 1 |
| 手法 3 | すべての群で 1。$z_t$ だけの勾配にすると遅い群が 0 |
| 手法 4 | $1 / (1 + (D+1) \bar r_2)$ の形。時間差で 1 |

optimizer の時定数は、最長の $\tau$ より長く取る（1.4 の最後）。これが通ったら、実データで手法 1 → 手法 3 の順に回す。

## 5. 未解決の点とユーザーが決める点

### ユーザーが決める点

1. **SIGReg をかける次元**: 1.5 から、$D$ = 1024 のスライスの検定は、個々の方向を $1/D$ の力でしか拘束しない。データポイント（$D \approx 1024$）のまま進めるか、次元を下げるか、2 次のモーメントを行列で扱う（手法 4）かは、どの手法を選ぶかより大きな分かれ目である。V18（i.i.d.）でも、予測の項との釣り合いに同じ弱さが出るはずである
2. **$B$ = 2 と入力の保持を認めるか**: 手法 3 は遅らせた写しの符号化（対の勾配）が要る。手法 1 は過去の入力を読み直す。「単一ストリーム」の範囲に入れてよいか
3. **U 統計量の正規化**: `exp/lib/sigreg.py` の対の項を $1/N$ から $1/(N-1)$ の形に直すか。小さい $N$（$N$ = 8 で $s^2$ = 0.76）で効く。V18 から揃えるほうが比べやすい
4. **時定数**: $\delta$（候補 0.5 秒。stack の幅 0.8 秒より短いと 2 つの stack がフレームを共有する。共有を避けるなら 1 秒以上）、$T_{\mathrm{est}}$、$g$。4.2 節の 4 と 5 の結果から決める
5. **平均の拘束**: 手法 3 は中心化するので、平均を 0 に拘束しない。崩壊の排除には要らないが、LeJEPA の目標に揃えるなら $\tfrac12 \lVert \hat\mu \rVert^2$ を足す
6. **固定の $\varphi$ か、当てた $\hat r$ か**: 手法 3′ は推定が無く単純だが、時間の尺度を決めてしまう

### 未解決の点

- 解析はすべて、正則化の項だけ、ガウス、尺度の向きだけのものである。予測の項との釣り合い、回転、非ガウスの解は扱っていない。M17 の $\lambda$ の窓の議論（H と I と Cw の比較）は、手法 3 の残差の目標に合わせて作り直す必要がある
- 手法 3 の目標 $\varepsilon \sim N(0, I_D)$ は、stack の中のトークンの残差が互いに独立であることを要求する。マスクした予測が使うトークンの間の相関とぶつかる点は、標準のデータポイントの SIGReg と変わらない
- 1.5 の式は、独立な成分と対角のゲインで導いた。成分が混ざる一般の線形の写像と、非線形のエンコーダでは確かめていない
- M17 の縮みがこの機構で説明できるか（1.7）
- AR(1) でない実際の表現で、残差の相関が $1/D$ を下回るか。下回らないときは、AR($p$) に延ばすか、手法 4 に退くかを決める
- FIFO にしたあとの式は 1.4 のとおりだが、M17 のランダムな置き換えのバッファ（年齢が幾何分布）には当てはめ直していない
- 2.3 節の後半の文献と Nagaraj ら (2020) の番号は、本文を読んで確かめていない

## 付録: 式の実装（オラクルの元）

```python
import numpy as np
S2P = np.sqrt(2 * np.pi)

def expected_sigreg(rho_lags, n):  # 1.3: FIFO of n consecutive rows, rho_lags[l-1] = rho(l)
    G = lambda r: np.sqrt(2 * np.pi / (3 - 2 * r)) - np.sqrt(2 * np.pi / 3)
    l = np.arange(1, n)
    return G(1.0) + np.sum(2 * (1 - l / n) * G(rho_lags))

def pred_gu(s, rho, n):  # 1.4: E[dS/dx_now * u]; > 0 means the scale shrinks
    s2 = s * s           # rho[j]: correlation of the current sample with buffer row j
    return 2 * S2P * s * (-np.sum((1 - rho) * (2 * s2 * (1 - rho) + 1) ** -1.5) / n
                          + (s2 + 2) ** -1.5)

def egp(s, sv2, cvv, cpv, cpvj, n):  # general Gaussian form (methods 2, 3)
    # at s = 1: sv2 = Var(v), cvv[j] = Cov(v, v_j), cpv = Cov(p, v), cpvj[j] = Cov(p, v_j),
    # where v is the tested sample and p = dv/ds. Semi-gradient: p = u_t / den;
    # pair gradient: p = v / s (then cpv = sv2, cpvj = cvv).
    sd2 = 2 * sv2 - 2 * cvv
    return (-(2 * S2P / n) * np.sum((cpv - cpvj) * s * (1 + s * s * sd2) ** -1.5)
            + np.sqrt(np.pi) * cpv * s * (1 + s * s * sv2 / 2) ** -1.5)
```

残差 $v_t = s\,(u_t - \varphi u_{t-\delta}) / \sqrt{1 - \varphi^2}$ では、$s = 1$ で $\operatorname{Var}(v) = (1 - 2\varphi\rho_\delta + \varphi^2)/(1 - \varphi^2)$、$\operatorname{Cov}(v_t, v_{t-j}) = [\rho_j (1 + \varphi^2) - \varphi(\rho_{j-\delta} + \rho_{j+\delta})]/(1 - \varphi^2)$、$z_t$ だけの勾配では $\operatorname{Cov}(p, v) = (1 - \varphi\rho_\delta)/(1 - \varphi^2)$、$\operatorname{Cov}(p, v_{t-j}) = (\rho_j - \varphi\rho_{j+\delta})/(1 - \varphi^2)$ である。
