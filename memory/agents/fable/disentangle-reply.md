# Codex さんの批判への返答と、直した設計（2026-11-25）

対象は、自分の設計 [disentangle.md](disentangle.md) と、Codex さんの批判 [../codex/disentangle-critique.md](../codex/disentangle-critique.md) である。役割は設計だけで、コード・README・plans には触れていない。GPU は使っていない。実動画・checkpoint での値は、まだ 1 つも測っていない。

確かさは 3 段で書く。**確かめた**は、閉じた式の値を数値計算で追ったもの（CPU の numpy だけ。スクリプトは使い捨てで、リポジトリには置いていない）。**導いた**は定義から式で出したもの。**推測**はそれ以外である。

## 0. 結論

1. **Codex さんの主な結論を受け入れる。** $H@q$ を disentanglement の主の指標にする案は取り下げる。JEPA の検証項目（K1〜K3・局所性・自己同定）を減らす根拠にもならない。自分の設計の 0 節の 2「主に測る数は 1 つで足りる」と、7 節の「読む数を 3 組に減らせる見込み」も取り下げる
2. Codex さんの反例は、1 つの恒等式にまとまる（導いた・確かめた、1 節）。定常な符号では、白色化した符号の時間のパワースペクトル $\mu$ について
   $$G_{\mathrm{ext}}(\Delta) = \frac{2\,E_\mu[(1 - \cos\omega\Delta)^2]}{E_\mu[1 - \cos\omega\Delta]}, \qquad H@q = \tfrac12 \log_2\!\Big(4 - 2q - \frac{2\,\mathrm{Var}_\mu[\cos\omega\Delta_q]}{q}\Big)$$
   が成り立つ。つまり、**共通のラグで読む値は「符号が遅いか」を測り、刻みを合わせた値は「符号の時間尺度が 1 つにそろっているか」を測る。** どちらも $\mu$ だけの関数で、「足し算が意味を持つか」は測っていない。遅い内容（場面）と速い内容（動き）の両方を持つ符号ほど、$H@q$ は下がる。これは主の指標から外す理由として、Codex さんの 3 点より強い
3. 同じ恒等式は、平行移動の四つ組（Codex さんの $R_{a \to b}$）にも当てはまる。分布を保つ 1 パラメータの変換に沿った 2 階差分は、どれも「その変換についての符号のスペクトルが低い側に寄っているか」を測る。画素を上回っても、細かい内容を捨てた結果と区別できない（導いた、3.2 節）
4. 反論は 2 つある。(a) 「disentanglement は原理的に確かめられない」は、因子が軸に分かれるという意味に限った結論である。ユーザーの定義（線形な空間に落ちる、足しても意味がある）は別の性質で、分けて伝える（2.1 節）。(b) 共通の物理ラグを主に読む案は、遅い符号が有利になる抜け道を戻す。ラグを 1 つ選ばず、$(s(\Delta), s(2\Delta))$ の曲線を下限の線と並べて読む（2.2 節）
5. ユーザーの問い「VAE や他の手法と比べられる 1 つの数はあるか」への、いまの答えは **「ラベルもデコーダも使わない 1 つの数では、無い」** である。出せるのは、時間のスペクトルの記述と、情報の幅の記述を並べた小さな表までである（4 節・5 節）

## 1. 反例を 1 つにまとめる恒等式

三つ組 $(z_{t-\Delta}, z_t, z_{t+\Delta})$ を白色化した座標で取り、$s(\Delta) = D(\Delta)/(2V) = 1 - \bar\rho(\Delta)$ と書く。定常なら $\bar\rho(\Delta) = E_\mu[\cos\omega\Delta]$ で、$\mu$ は方向について平均したスペクトルの確率測度である。$c = \cos\omega\Delta$ と置くと $\bar\rho(2\Delta) = E_\mu[2c^2 - 1]$ なので、

$$s(2\Delta) = 2 - 2E_\mu[c^2] = 2s(2 - s) - 2\,\mathrm{Var}_\mu[c]$$

$$G_{\mathrm{ext}}(\Delta) = 4 - \frac{s(2\Delta)}{s(\Delta)} = 2s(\Delta) + \frac{2\,\mathrm{Var}_\mu[c]}{s(\Delta)} = \frac{2\,E_\mu[(1 - c)^2]}{E_\mu[1 - c]}$$

となる（導いた。7 個の周波数を乱数で置いたスペクトルで、3 つのラグとも 3 つの式が 12 桁以上一致することを確かめた）。中点は $G_{\mathrm{mid}} = G_{\mathrm{ext}}/4$ である。ここから次が出る。

- **下限**: $\mathrm{Var} \ge 0$ なので $G_{\mathrm{ext}}(\Delta) \ge 2s(\Delta)$、$G_{\mathrm{mid}} \ge s/2$。Codex さんの上限 $H@q \le \tfrac12\log_2(4 - 2q)$ と同じ式である。等速外挿が copy に勝てる（$G_{\mathrm{ext}} < 1$）のは、符号が全体の変動の半分も動かないラグ（$s < 1/2$）に限られる。定常で有界な符号は、局所的にしか真っすぐになれない
- **共通のラグで読むと遅さになる**: $\omega\Delta$ が小さい範囲で $G_{\mathrm{ext}} \approx \Delta^2 E_\mu[\omega^4]/E_\mu[\omega^2]$。値を小さくするには、速い成分を捨てればよい
- **刻みを合わせると帯の狭さになる**: $s = q$ に固定すると、残るのは $\mathrm{Var}_\mu[\cos\omega\Delta_q]$ だけである。1 つの周波数なら 0 で上限、時間尺度が散るほど下がる

Codex さんの反例は、どれもこの式の例になる（値は全て再計算して一致した。確かめた）。

| 反例（批判の節） | 値 | この式での読み |
| -- | -- | -- |
| 1 つの周波数の回転 | 0.9037 | $\mathrm{Var} = 0$ |
| 動く帯の割合 $p = 1, 0.5, 0.25$（1.1 の反論 1） | 0.904・0.792・0.500 | 静止した成分は $\omega = 0$ の質量で、$\mathrm{Var}$ を増やす |
| OU と滑らかな山の半々、$s = 1, 3, 10, 30$（1.1 の反論 3） | 0.504・0.353・0.299・0.293 | 2 つの時間尺度が離れるほど $\mathrm{Var}$ が増える |
| 周波数 1 と 2 の混合、高い側の割合 0.9999・0.5・0.0001（1.4） | 0.90367・0.86783・0.90361 | 両端は 1 つの帯、中間は 2 つの帯 |
| チェビシェフ展開、$m = 1000$（1.2） | 0.90356 | 64 成分の周波数が 6% の幅に収まり、ほぼ 1 つの帯 |
| 白い入力の 8 枚の移動平均（1.2） | 0.5 | $s(d) = \min(d/8, 1)$ |

自分の設計の 3.3 節は「遅くするだけでは値は上がらない」と書いた。これは、全方向が 1 つの倍率で伸び縮みする場合にしか成り立たない。それ以外では、刻み合わせは時間尺度の散らばりへの罰になる。良い表現は場面のようなゆっくりした内容と、動きのような速い内容の両方を持つはずなので、$H@q$ は表現の豊かさと逆の向きに動きうる。主の指標にはできない。

### 2.1 反論 (a): 「原理的に確かめられない」の範囲

Codex さんの 4 節は「ユーザーの言う disentanglement は、2 次の統計だけでは原理的に確かめられない」とまとめている。この結論は、因子が分かれていること（Locatello らの意味）については正しい。ただしユーザーの定義は「複雑な分布が線形な空間に落ちる」「足しても意味がある」「切り分けやすい」で、因子の軸への分離とは別の性質である。ユーザーに伝えるときは 2 つを分ける。

- **因子の分離**: 人のラベルか、因子として認める介入が無ければ測れない。この点は Codex さんと同じ
- **線形化（足し算が意味を持つ）**: 正解がデータの中にある足し算（時間の中点・外挿、平行移動の合成）に限れば測れる。ただし 1 節のとおり、その値はスペクトルで決まり、情報を捨てても良くなる。「測れるが、単独では良さの証拠にならない」が正確な言い方である

ユーザーの問いへ「測れない」と返すと、後者まで否定したように読める。

### 2.2 反論 (b): 共通の物理ラグを主に読む案

Codex さんの修正案は、共通の物理ラグでの $s(\Delta)$ と、外挿と copy の誤差の比を主に読む。1 節の式では、この比は $\Delta^2 E_\mu[\omega^4]/E_\mu[\omega^2]$ に近く、速い成分を捨てた符号ほど良い。自分が刻み合わせを入れた理由がこれで、抜け道が元に戻る。入力の動きでの層別は、全ての符号に共通の条件をそろえるだけで、符号が何を捨てたかの差は消さない。

2 つの読み方は、同じ曲線の別の切り口である。ラグも $q$ も 1 つに選ばず、次のように読む。

- 横軸に $s(\Delta)$、縦軸に $G_{\mathrm{ext}}(\Delta)$ を取り、0.8 秒以上の全てのラグの点を符号ごとに結ぶ。下限の線 $G_{\mathrm{ext}} = 2s$ を一緒に引く
- 共通のラグでの比べは、同じラグの点どうしを見ることにあたる。遅い符号は左に寄るので、「誤差の比が小さいのは、動いていないから」が図で分かる
- 刻み合わせは、同じ横の位置で縦を比べることにあたる。下限からの距離 $G_{\mathrm{ext}} - 2s = 2\mathrm{Var}_\mu[c]/s$ が、時間尺度の散らばりである

これは記述で、合否にはしない。この点は Codex さんの 3 節の 1 と同じである。

### 2.3 補足: 尺度の混合を方向ごとに分ける案（副。採るかは未定）

反論 3（独立な遅い成分を足すと値が下がる）は、方向について平均を取ることから来る。白色化した座標で $E[(z_{t+\Delta_0} - z_t)(z_{t+\Delta_0} - z_t)^\top]$ の固有ベクトル（slow feature analysis の方向）を取り、方向ごとに $s_i(\Delta)$ を読めば、遅い成分を足しても他の方向の値は下がらない（導いた。方向が独立な成分に一致する場合）。全次元がフルランクなら、可逆な線形変換で変わらない。

ただし、$k \times k$ の基底を当てはめるので、参照の組で求めて Zurich で読む必要がある。また、1 つの量の展開は全ての方向が真っすぐなので、この版でも捕まらない。読む数も増える。採る理由は弱いので、探索の記録にとどめる。

## 3. 足し算の直観に近い試験についての見立て

### 3.1 2 領域の移植の混合差分

Claude の反論（画素が厳密に 0 で満点）と、Codex さんの修正（局所性・分離の対照に回す）に同意する。

### 3.2 `wide` の平行移動の四つ組 $R_{a \to b}$

採点の形（同じ三つ組で 2 階差分を直接採点する、分母は copy の誤差、応答の量を並べる、開始のオフセットを変える、共通に見える領域と端を分ける）は受け入れる。$a = b$ では、自分の $H_{\mathrm{tr}}$ を正しく採点し直したものにあたる（$R_{a \to a}$ は平行移動についての $G_{\mathrm{ext}}$）。

そのうえで、期待できることを先に絞る。1 節の恒等式は、時間の代わりに移動量を置いても成り立つ（データの分布が平行移動でほぼ変わらない範囲で。位置の埋め込みと端があるので、近似である）。したがって $R_{a \to a} \approx 2E_{\mu_{\mathrm{tr}}}[(1 - \cos\kappa a)^2]/E_{\mu_{\mathrm{tr}}}[1 - \cos\kappa a]$ で、$\mu_{\mathrm{tr}}$ は符号の応答の空間周波数のスペクトルである。**画素を上回る符号は、細かい模様への応答を落とした符号である。** 平行移動に不変な符号はその極限で、Codex さんが採点の外に置く条件にあたる。不変と低域通過の間に境目は無いので、応答の量の閾値をどこに置いても、「足し算が転用できる」と「細部を捨てた」は分けられない（導いた。近似の範囲は推測）。

採るなら、主張は「平行移動への応答のスペクトル」の記述にとどめる。使える動画は 3 本だけである。優先度は時間の版より低い。

### 3.3 別の場面どうしの足し算（ユーザーの例に最も近いもの）

ユーザーの例は「別の画像を足す」である。デコーダなしで測れる形は 1 つ考えられる（推測。未検証）。別の場面の符号 2 つの平均が、本物の符号の集まりの中に入るかを、白色化した座標での近傍の距離で見る。集合が凸であることは可逆なアフィン変換で変わらない。

ただし、これも単独では使えない。SIGReg は $z$ をガウスに寄せ、VAE の KL も同じ向きに働くので、目的が直接この量を良くする。ガウスの雑音だけの符号も満点になる。意味を持つのは「符号が入力の情報を保っている」ことと組になった場合だけで、その情報の量を、ラベルもデコーダも使わずにモデルをまたいで測る方法が無い。行き着く先は 4 節と同じである。

## 4. 残る本当の難所: 情報の幅を、モデルをまたいで測る

1 節・3 節のどの試験も、「値が良いのは、情報を捨てたからではない」ことを別に示す必要がある。JEPA の内側では、自己同定とその相方がこの役目を持つ。VAE や画素には予測器が無いので、同じ物差しは使えない。候補は次のとおりで、どれも決め手にはならない。

| 候補 | 分かること | 弱点 |
| -- | -- | -- |
| 離れた時刻・別のクリップでの内在次元（TwoNN など） | 1 つの量の展開は 1、独立な因子は因子の数になる（導いた） | 雑音で膨らむ。時間の相関が強い標本では軌跡の 1 次元を拾う |
| 符号どうしの線形の相互予測（同じ $k$ で、A から B を当てる $R^2$ と、その逆） | どちらがどちらを線形に含むか。ラベルも画素の正解も使わない（推測） | 含むことは良さではない。画素の `pca` は多くを含む側になる見込み |
| 独立な介入が動かす方向の数（Codex さんの案） | 選んだ介入の範囲での応答の次元 | 保証は選んだ介入の中だけ。どの介入を因子と認めるかは人の判断 |

「真っすぐさ」と「情報の幅」は逆向きに動かせるので、2 つを 1 つの数にまとめる理論的な重みづけは無い（推測）。まとめた数を作れば、過去 3 回と同じく、当てやすい側へ逃げた符号が良く見える。

## 5. 直した設計（数値を出す前のもの）

Codex さんと Claude の合意（批判の 3 節）を土台にし、自分の変更を加える。

1. **位置づけ**: 「自然な動画の軌跡に沿った、時間の中点・等速外挿の診断」。disentanglement の指標とは呼ばない。主の合否にも、検証項目を減らす根拠にもしない
2. **量**: 全ての符号に同じ三つ組を使い、$E\lVert a \rVert^2$・$E\lVert b \rVert^2$・$E\lVert b - a \rVert^2$ を共通の白色化で直接集計する。ラグは重ならない 0.8 秒以上
3. **読み方**: $(s(\Delta), G_{\mathrm{ext}}(\Delta))$ の曲線を、下限 $2s$ の線と並べる（2.2 節）。$H@q$ を並べる場合は、$\Delta_q$、届かない割合、「0.9037 は定常かつ $s(\Delta_q) = 0.25$ のときの上限」を併記する
4. **層別**: カットの内側とまたぐ三つ組、動きの大小を、入力の側の共通の規則で分ける。対の差はブロックのブートストラップで出し、ブロックの境界をまたぐ三つ組は作らない
5. **対照**: 無加工の画素（`pca`）、8 枚の時間の平均、1 つの量のチェビシェフ展開、合成の K3（`h_mean` の水準を含む）、OU の混合。加えて、時間を並べ替えた符号（$s$ がラグによらない）
6. **実装の確かめ**: V-d0 を残す。足すのは、1 節の恒等式を合成のスペクトルで回収する試験と、1 節の表の値の回収である。V-d0e（2 倍に遅くする）は、交差点が格子に乗る例で行う
7. **解像度の確かめ**: 区別したい最小の差 $\Delta_*$ をユーザーと先に決め、同じ三つ組の対の差で回収できるかを見る。外れたら、モデルの値を計算せずに止める
8. **情報の側**: 離れた時刻での内在次元を記述として並べる。相互予測（4 節）は、採る前にもう一度批判を受ける
9. **比べる範囲**: 各モデルの自分の潜在と、共通の `h_mean` を別々に読む。既存の run の比べは記述にとどめる。目的の優劣を言うなら、入力・データ・予算をそろえて学び直す
10. **平行移動の四つ組**: 足し算の転用まで言いたいときだけ加え、3.2 節の範囲で読む

取り下げるもの: $H@0.25$ を主の指標にすること、「主に測る数は 1 つで足りる」、検証項目を 3 組に減らす見込み、V-d2 の (ii)、V-d3 の (i) の閾値 0.85、`lin_k` を天井と読むこと、`copyw_h` の 2 つの値の比で計算すること、$H_{\mathrm{tr}} = 1$ と加法性の同値。

## 6. ユーザーへ伝えること

- **比べられる 1 つの数は、見つかっていない。** 時間の線形性は VAE・JEPA・画素で同じ目盛りに載るが、その値は「符号がどれだけ遅いか・時間尺度がそろっているか」で決まり、情報を捨てても良くなる。良さの証拠にするには、情報の幅を別に測る必要があり、それをモデルをまたいで測る確かな方法がまだ無い
- **JEPA の検証項目は減らせない。** 減らせるのは表示の重複（中点と外挿の片方）だけである
- この診断に意味が出るのは V19 の未来予測である。等速外挿 $2z_t - z_{t-\Delta}$ は、予測器の学習の要らない対照になり、誤差の下限 $2s(\Delta)$ も式で分かる。予測器がこの対照を上回る分が、線形でない予測の分になる（自分の設計の 7 節の末尾。ここは批判の後も残る）
- 決めてほしい点: (i) 因子として認める介入（平行移動・拡大・時間など）を使ってよいか。使えば「選んだ因子についての分離」は測れるが、人が因子を選ぶことになる。(ii) 情報の幅の物差しに、モデルどうしの線形の相互予測を試すか。(iii) この診断を、V18c の符号で先に記述として出すか、V19 まで待つか

## 7. 確かめていないこと

- 実動画での値は 1 つも無い。画素の $H@0.25$ が上限の近くにあるか、$\Delta_q$ が 0.8 秒以上に入るかも分からない
- 1 節の恒等式は定常を仮定している。カットや場面の入れ替わりのある実際の動画で、どの程度ずれるかは測っていない
- 3.2 節の平行移動への当てはめは、分布が平行移動で変わらないという近似に頼る。位置の埋め込みと画面の端の影響は見積もっていない
- 3.3 節の凸性と 4 節の相互予測は、思いつきの段階で、文献も反例も調べていない
