# 潜在空間の線形性を、JEPA・VAE・画素で同じ目盛りに載せる評価（設計の提案、2026-11-25）

確かさは 3 段で書く。**導いた**は定義から式で出したもの、**文献**は literature.md が引く文献の内容、**推測**はそれ以外である。式の検算は手計算だけで、実行はしていない。

## 0. 要点

1. ユーザーの直観「画像は足しても意味がないが、良い潜在では足し算が意味を持ち、線形になる」は、1 つの量に翻訳できる。動画の符号 $z_t$ の**構造関数** $D(\Delta) = E\lVert z_{t+\Delta} - z_t \rVert^2$ の伸び方 $H(\Delta) = \tfrac12 \log_2 [D(2\Delta)/D(\Delta)]$ である。$H = 1$ は等速の直線、$H = 1/2$ はランダムウォーク、$H = 0$ は時間と無関係な雑音にあたる（導いた、2 節）
2. 「時間の軌跡の曲率」「前後の 2 フレームの符号の平均が、本物の中間のフレームの符号に近いか」「線形外挿が当たるか」「$a + a$ の移動が $a$ の移動の 2 つ分になるか」は、二乗誤差でまとめると**どれも $H$ の 1 対 1 の関数**になる（導いた、2 節）。候補を 3 つ以上並べたが、主に測る数は 1 つで足りる
3. 公平さは 2 つの手続きで得る。1 つは白色化で、参照の組の共分散の逆行列で距離を測ると、値は符号の可逆な線形変換で変わらない（導いた、3 節）。もう 1 つは**符号ごとに時間の刻みを合わせる**ことで、その符号が全体の変動の一定の割合 $q$ だけ動く刻み $\Delta_q$ で $H$ を読む。こうすると、ゆっくり変わる量だけを残した符号が真っすぐに見える抜け道が消える（導いた、3.3 節）
4. ずるい表現の値は理論から先に書ける。定数と位置だけの符号は採点できない（階数が足りない）。時間を並べ替えた符号は $H = 0$。画素とその線形関数は、動きが 1 歩で模様の波長より十分小さいときだけ $H$ が 1 に近づき、それを超えると下がる（4 節）。「画像を足しても意味がない」は、この画素の値が基準線になる
5. 別の場面の変位を足す類推（$z_B + (z_{A'} - z_A)$）は、**どの符号でも期待値が 0 になる**ので、線形性の物差しには使えない（導いた、5.4 節）。実装の確かめの帰無としてだけ使う
6. 主に推すのは、時間の $H$（$k = 64$、$q = 0.25$）である。画素の介入による裏づけとして、`wide` のデータの本物の平行移動で同じ量を測る（5 節）
7. この評価は自己同定の代わりにならない。自己同定は予測器が隠した所を補えるかを測り、$H$ はエンコーダの空間の形を測る。置き換えられそうなのは、モデルをまたぐ物差し比べと、情報の少なさを見張る相方の一部である（推測、7 節）
8. 残る弱点は 2 つある。線形性は情報の量を保証しない（1 つの遅い量を多項式で広げた符号が高い値を取れる）。もう 1 つは、空間のマスクで学んだ V18c の JEPA が時間方向に真っすぐになる理由が理論に無いことで、JEPA が画素を上回らない結果も十分ありうる（8 節・10 節）

## 1. ユーザーの直観を、測れる問いに直す

ユーザーの言葉を 3 つの主張に分ける。

- (a) 画素の空間では、2 枚を足した点は意味のない画像になる
- (b) disentangle された空間では、足した点や、その中を動いた先が、意味のある点になる
- (c) そのとき、線形性のような良い性質が生まれている

「意味のある点」を、人の目や外部の分類器で判定すると、V18c で 3 回止まった形に戻る。デコーダで画像に戻して判定する方法も、JEPA にデコーダが無いので比べられない（文献、literature.md 2.2 節）。そこで、**正解がデータの中にある足し算だけ**を使う。

動画の 3 つの時刻 $t - \Delta$、$t$、$t + \Delta$ を取る。前後の 2 つの符号の平均 $m_t = \tfrac12 (z_{t-\Delta} + z_{t+\Delta})$ は、符号の空間で「2 枚を足した点」である。この点が意味を持つなら、本物の中間 $z_t$ に近いはずである。画素の空間では、2 枚の平均は二重像になり、本物の中間のフレームにならない。Hénaff ら（2019）は、これを人の知覚で確かめた（文献）。使う既知のものは時間の並びだけである。

測る問いは次の 1 つになる。

> 符号の空間で、前後の 2 点の平均は、本物の中間の点にどれだけ近いか。その近さは、画素やその線形関数で同じことをしたときより良いか。

## 2. 量の定義と、3 つの読み替え

### 2.1 構造関数と $H$

符号 $z_t \in \mathbb{R}^k$ は、参照の組で白色化してあるとする（3 節）。$a_t = z_t - z_{t-\Delta}$、$b_t = z_{t+\Delta} - z_t$ と書く。

$$D(\Delta) = E\lVert z_{t+\Delta} - z_t \rVert^2, \qquad H(\Delta) = \tfrac12 \log_2 \frac{D(2\Delta)}{D(\Delta)}$$

期待値は、評価の動画（Zurich）の全ての $t$ についての平均である。$E\lVert a \rVert^2 = E\lVert b \rVert^2 = D(\Delta)$（平均を同じ区間で取れば端を除いて等しい）なので、$D(2\Delta) = E\lVert a + b \rVert^2 = 2D(\Delta) + 2E[a \cdot b]$ となる。ここから次の 4 つが出る（導いた）。

| 量 | 式 | 直線（$H$ = 1） | ランダムウォーク（1/2） | 時間と無関係な雑音（0） |
| -- | -- | -- | -- | -- |
| まとめた曲率の cos | $\bar c = \dfrac{E[a \cdot b]}{D(\Delta)} = 2^{2H-1} - 1$ | 1（0°） | 0（90°） | −1/2（120°） |
| 中点の誤差と copy の比 | $G_{\mathrm{mid}} = \dfrac{E\lVert z_t - m_t \rVert^2}{D(\Delta)} = 1 - 2^{2H-2}$ | 0 | 1/2 | 3/4 |
| 線形外挿の誤差と copy の比 | $G_{\mathrm{ext}} = \dfrac{E\lVert z_{t+\Delta} - (2z_t - z_{t-\Delta}) \rVert^2}{D(\Delta)} = 4 - 2^{2H}$ | 0 | 2 | 3 |
| 加法性の欠け | $r = \dfrac{E\lVert (z_{t+\Delta} - z_{t-\Delta}) - 2a \rVert^2}{D(2\Delta)} = 2^{2-2H} - 1$ | 0 | 1 | 3 |

- 導出: $z_t - m_t = \tfrac12 (a - b)$、$z_{t+\Delta} - (2z_t - z_{t-\Delta}) = b - a$、$E\lVert a - b \rVert^2 = 4D(\Delta) - D(2\Delta)$
- copy は「前の時刻の符号をそのまま答えにする」予測で、誤差は $D(\Delta)$ である
- $E\lVert a - b \rVert^2 \ge 0$ なので $H \le 1$ で、等号は全ての $t$ で $a_t = b_t$（等速の直線）のときに限る
- 線形外挿が copy に勝つ（$G_{\mathrm{ext}} < 1$）のは $2^{2H} > 3$、つまり $H > 0.79$、曲率で 60° 未満のときである
- 雑音の値 120° とランダムウォークの値 90° は、literature.md 2.1 節の導出と一致する

Hénaff ら（2019）の例の列を当てはめると、画素の 99° は $H \approx 0.38$、知覚の 8° は $H \approx 0.996$ にあたる。ただし彼らの値は列ごとの角度の平均で、ここでのまとめた cos とは平均の取り方が違う。目安として読む。

### 2.2 自己相関での読み方

白色化した符号の平均の自己相関を $\bar\rho(\Delta) = \mathrm{tr}(C^{-1} \Gamma_\Delta) / k$（$\Gamma_\Delta$ は遅れ $\Delta$ の共分散）と書くと、$D(\Delta) = 2k(1 - \bar\rho(\Delta))$ である。$H$ は、自己相関の原点での形を測っている。

- 原点が滑らかな山（$\bar\rho \approx 1 - c\Delta^2$）なら $H \to 1$。符号が時間について微分できる、という性質にあたる
- 原点が尖った山（$\bar\rho \approx 1 - c\lvert\Delta\rvert$、Ornstein–Uhlenbeck 過程）なら $H = 1/2$
- 自然な画像の画素の構造関数は、ずれの大きさの 1 より小さいべきで伸びることが知られている（スペクトルが周波数の約 −2 乗で落ちることの帰結。指数の値は文献を読み直していないので推測として扱う）。このとき画素の全次元の $H$ は 1/2 より小さくなり、Hénaff の 99° と同じ向きである

`exp/lib/linear_dyn.py` の `copyw_h` は、白色化した $D$ を符号の分散で割った量である（コードの docstring から）。したがって $H$ は、既存の部品の値 2 つの比で計算できる。当てはめるパラメータは共分散だけで、次元とともに増える読み出しを持たない。

### 2.3 同定の形との関係

いまの自己同定と同じ「対の勝率」の形にもできる。中点 $m_t$ を問い合わせにし、本物の $z_t$ が端の点 $z_{t+\Delta}$ より近ければ勝ちとする。$\lVert z_t - m_t \rVert = \tfrac12 \lVert a - b \rVert$、$\lVert z_{t+\Delta} - m_t \rVert = \tfrac12 \lVert a + b \rVert$ なので、勝つのは $a \cdot b > 0$ のとき、つまりその 3 点の曲率が 90° 未満のときに限る（導いた。円周角の定理と同じ）。

$$A_{\mathrm{mid}} = P(a_t \cdot b_t > 0)$$

ランダムウォークで 0.5、直線で 1、雑音で 0 に寄る。次元が高いと 3 点ごとの cos がまとめた cos の近くに集まるので、$A_{\mathrm{mid}}$ は 0 か 1 に張り付きやすい（推測）。過去 3 回の「目盛りが読めない」形になりうるので、主にはしない。連続な値を取る $H$ を主にし、$A_{\mathrm{mid}}$ は副に並べる。

## 3. 公平に比べるための手続き

### 3.1 白色化: 可逆な線形変換で値が変わらない

参照の組（Zurich でない学習の動画）の符号の共分散を $C$ とし、距離を $\lVert u \rVert_{C^{-1}}^2 = u^\top C^{-1} u$ で測る。符号を $z \mapsto Mz + c$（$M$ は可逆）に替えると、$C \mapsto MCM^\top$ になり、$u^\top C^{-1} u$ は変わらない。中点や外挿の足し算も $M$ と交換する。したがって $D$・$H$・$A_{\mathrm{mid}}$ は、**符号の可逆なアフィン変換で厳密に変わらない**（導いた）。

この不変性が要る理由は 3 つある。

- JEPA の SIGReg は回転で不変なので、軸に意味がない。VAE の軸は KL の項でそろう（文献、literature.md 1.3 節）。軸に頼る量は VAE に有利に偏る
- 白色化しない量は、分散の大きい方向だけで決まる。画素の PCA は上位の成分ほどゆっくり変わるので、分散の配り方だけで値が良くなる。このプロジェクトでも `dyn_h` と `dynw_h` を分けた理由がこれである（`linear_dyn.py` の docstring）
- 明るさの倍率や白の偏りは画素の線形変換なので、白色化した量では値が変わらない。2 回目の試みで的が 1 画素のぼかしで大きく動いた型の問題は、線形な撹乱については起きない

V18c の $z = W \mathrm{vec}(t)$ と $\mathrm{vec}(t)$ は可逆な線形変換の関係にあるので、全次元で読めば同じ値になる。

### 3.2 次元をそろえる: 上位 $k$ 個の主成分と、その影響

全次元の白色化は、次元が標本の数より大きい画素（98304 次元）では定義できない。そこで、どの符号も参照の組の PCA の上位 $k$ 個に射影してから白色化する。$k$ は全ての符号で同じにする。この手続きの影響は次のとおりである（導いた）。

- 白色化の後は、$k$ 個の方向が同じ重みで効く。$D$ は方向ごとの和なので、速く変わる方向ほど大きく効く。値は「$k$ 個の方向のうち、荒いものに引かれた」厳しい向きの読みになる
- 上位 $k$ 個の選び方は分散の順なので、不変性は $k$ 次元の中の可逆な線形変換に限られる。等方に近い JEPA の $z$ では、上位 $k$ 個はほぼ任意の $k$ 次元の部分空間になる。画素では低い空間周波数になる。VAE の $\mu$ では、よく使われている潜在になる
- 階数が $k$ に足りない符号は採点できない。VAE の $\mu$ は 256 次元だが、使われない座標の分散は小さい（推測、inventory.md 1.3 節）。そこを白色化で持ち上げると、意味のない揺れが 1 方向ぶんの重みを持ち、$H$ が下がる。これは符号の性質ではなく手続きの産物である。そこで $k$ は、比べる全ての符号の実効ランク（`pca` 52、VAE 116〜149、JEPA 116〜145、README の V18 の結果 4）より小さくする
- 推定の偏り: 参照の $n$ 個から推定した $\hat C^{-1}$ で別の組を測ると、ガウスの場合に距離が約 $n/(n-k-2)$ 倍に膨らむ（逆ウィシャート分布の平均）。この倍率は $D(\Delta)$ と $D(2\Delta)$ に共通にかかるので、$H$ の比では打ち消す。刻みを合わせる水準 $q$ にだけ効き、$n = 6000$、$k = 64$ で約 1% である。ただし参照の stack は時間の相関が強く、実効の $n$ はもっと小さい。参照の組を半分に分けて値が変わらないことを確かめに入れる（9 節）

提案は $k = 64$ を主にし、16 と 256 を副に並べることである。256 は VAE の $\mu$ の全次元にあたり、上の理由で読みにくい見込みなので、記述にとどめる。`color`（パッチ 16 の平均の色、実効ランク 12.5）は $k = 16$ でだけ他と比べる。

ランダムな射影で次元をそろえる方法は採らない。画素をランダムに $k$ 次元へ射影すると、全ての空間周波数が分散に比例して混ざる。白色化の後は高い周波数の荒い成分が残るので、PCA の上位 $k$ 個より $H$ が低くなる見込みである（推測）。射影の乱数にも依存する。

### 3.3 刻みを合わせる: 遅いだけの符号を有利にしない

固定の $\Delta$ で比べると、ゆっくり変わる量だけを残した符号ほど真っすぐに見える。どんな滑らかな関数も、十分短い刻みではほぼ線形だからである（テイラー展開）。literature.md 2.1 節が挙げた「遅い 1 つの量」の抜け道がこれにあたる。

そこで、符号ごとに刻みを決める。評価の動画での白色化した分散を $V$ として、

$$\Delta_q = \min\{\Delta : D(\Delta) / (2V) \ge q\}, \qquad H@q = H(\Delta_q)$$

とする。$\Delta_q$ は「その符号が、全体の変動の割合 $q$ だけ動くのにかかる時間」である。自己相関が $\bar\rho(\tau) = f(\tau / T)$ の形なら、$H@q$ は形 $f$ だけで決まり、時間の尺度 $T$ によらない（導いた。$D(\Delta_q)$ と $D(2\Delta_q)$ がどちらも $\Delta_q / T$ だけの関数で、$\Delta_q / T$ は $q$ で決まる）。遅くするだけでは値は上がらない。

$q = 0.25$ での形ごとの値（導いた、手計算）:

| 自己相関の形 | $H@0.25$ |
| -- | -- |
| 尖った山 $e^{-\tau/T}$（OU 過程、拡散の形） | 0.40 |
| 滑らかな山 $e^{-\tau^2/2T^2}$ | 0.73 |
| 周波数が一様に散った回転の重ね合わせ（$\mathrm{sinc}$） | 約 0.82 |
| 1 つの周波数の回転 $\cos(\omega\tau)$ | 0.90 |
| 上限 | 1 |

拡散の形と滑らかな形の差は 0.33 ある。$q = 0.1$ では 0.46 と 0.89 で、差はさらに開くが、$\Delta_q$ が短くなり 0.1 秒の刻みに近づく。主は $q = 0.25$ とし、0.1 と 0.5 を副に並べる。$\Delta_q$ そのもの（符号の速さ）も必ず並べる。

刻みは 0.1 秒おきの stack から取り、$\Delta$ は 1 フレームから 32 秒まで、ほぼ等比に並べて $D$ を対数の目盛りで補間する。最短の 0.1 秒で既に $q$ を超える符号は「雑音に近い」と記録する。32 秒でも $q$ に届かない符号は「この範囲では動かない」と記録し、$H$ は出さない。

隣り合う stack は 7 枚を共有する（inventory.md 2.2 節）。固定の 0.1 秒で比べたときに `color` が自明に良くなった問題は、刻みを符号ごとに合わせることで避けられる。遅い符号は長い刻みで読まれるからである。

## 4. ずるい表現で何が出るか（理論から先に書く）

| 表現 | $H@q$ と記録 | 理由 |
| -- | -- | -- |
| 定数（K1） | 採点できない | 分散が 0 で、白色化の階数が 0 |
| 位置だけの符号 | 採点できない | 時間で変わらないので、中心化すると定数と同じ |
| 階数が $k$ に足りない符号（K2、複製の K3 の大域の符号） | その $k$ では採点できない | V18c の複製の K3 は階数が 16 以下なので、$k = 64$ では採点できない。$k = 16$ では大域の中身の値が出る。K3 かどうかはこの量では分からない |
| 時間を並べ替えた符号 | $H = 0$、最短の刻みで $q$ を超える | $D$ が遅れによらない |
| 独立な雑音 | 同上 | 同上 |
| 画素そのもの・画素の PCA（`pca`） | 動きが波長より十分小さい刻みでは 1 に近く、超えると下がる。刻みを合わせた値は、理想的な一様な平行移動で約 0.8、実際の動画ではそれより低い見込み | 下の注 |
| 画素のランダムな射影 | `pca` より低い見込み | 3.2 節 |
| 学習前の符号（`init`） | `pca` と同じかそれ以下の見込み | 画素のランダムな非線形の関数で、非線形性は曲率を足す向きに働く。固定の 0.1 秒・白色化なしの `dyn_1/copy_1` は `init` 0.931、`pca` 0.469 だった（README）。同じ量ではないので推測 |
| ゆっくり変わる量だけの符号（`color` など） | 階数の範囲では刻みを合わせた値が出る。遅いこと自体では上がらない | 3.3 節 |
| 1 つの遅い量を多項式で広げた符号 | 高い値を取りうる。**塞げていない** | 8 節 |

画素についての注（導いた）。画像が一様に速さ $v$ で平行移動するとき、空間周波数 $f$ の成分は平面の上を角速度 $2\pi f v$ で回る。1 歩の位相の進みが小さい（ずれが波長より十分小さい）うちは、軌跡はほぼ真っすぐである。これは「小さくずらした 2 枚の平均は、半分だけずらした 1 枚に近い」という、画素でも足し算が意味を持つ範囲にあたる。ずれが波長の 4 分の 1 を超えると、平均は二重像になる。つまり、**画素の足し算が意味を失うのは、動きが模様の細かさを超えたとき**である。$k$ を大きくすると細かい模様が入るので、画素の値は $k$ とともに下がる。実際の動画では、視差・遮蔽・画面の外から入る新しい内容が加わり、平行移動の理想の値より下がる。

学習した符号が「画素より線形だ」と言えるのは、同じ $k$ で、画素の線形関数の値を上回ったときである。画素の線形関数の中の最良の値（線形の天井）は閉じた式で近似できる。`pca` の 1024 次元の中で、$E\lVert a - b \rVert^2$ と $E\lVert a + b \rVert^2$ の一般化固有値問題を解き、加法性の欠け $r$ の小さい $k$ 方向を取る。基底は参照の組で求め、値は Zurich で測る。これを `lin_k` と呼び、`pca` と並ぶ基準線にする。固定の $\Delta$ での最良なので、刻みを合わせた値の厳密な天井ではない。

## 5. 線形性の候補と、主に推すもの

### 5.1 候補 1: 時間の $H@q$（主に推す）

2 節・3 節の量そのものである。曲率、中点、線形外挿、加法性は同じ数の読み替えなので、分けて数えない。推す理由は次のとおりである。

- 使う既知のものが時間の並びだけで、人が選ぶ変換が無い。刻みも符号ごとに規則で決まる
- 理論の値（0、1/2、1 と、形ごとの値）が閉じた式で決まり、実装の確かめに使える
- 当てはめが共通の共分散だけで、次元による容量の差が無い
- 画素が満点を取れない。ユーザーの言う基準線がそのまま下側の物差しになる
- V19 の未来予測では、予測器の相手になる対照（線形外挿）を同じ式で与える（7 節）

### 5.2 候補 2: 中点の同定 $A_{\mathrm{mid}}$ と、難しい候補つきの版（副）

2.3 節の量。端の点を候補にした版は曲率の符号の統計で、張り付きやすい。いまの自己同定と同じ難しい候補（前後 ±2〜±32 秒）を足した版は、二乗誤差に出ない取り違え（中点が別の時刻の本物に近い）を拾う。値は $H$ とほぼ連動する見込みなので、副に並べる。

### 5.3 候補 3: 画素の介入（平行移動）の加法性 $H_{\mathrm{tr}}@q$（裏づけ）

`wide` のデータ（64 × 112、左右に 24 px の本物の画素）から、8 フレームを同じ量 $a$ だけ横にずらした stack $T_a x$ を切り出す。時間を移動量に置き換えて、同じ式で測る。

$$D_{\mathrm{tr}}(a) = E\lVert z(T_a x) - z(x) \rVert_{C^{-1}}^2, \qquad H_{\mathrm{tr}}(a) = \tfrac12 \log_2 \frac{D_{\mathrm{tr}}(2a)}{D_{\mathrm{tr}}(a)}$$

$H_{\mathrm{tr}} = 1$ は、同じ stack について「$2a$ の移動による変位が、$a$ の移動による変位のちょうど 2 倍」であることと同値である（2.1 節の $r = 0$）。課題の言う「$a + b$ の移動 = $a$ の移動 + $b$ の移動」を $a = b$ で測ったものにあたる。$a$ は 1〜12 px（$2a \le 24$）で取る。

この介入を使う理由は 3 つある。

- 時間の変化には、カメラの動き・物の動き・照明が混ざり、場面ごとに速さも違う。平行移動は量が正確に分かる 1 つの因子で、stack ごとに厳密に同じ操作になる。時間の結果が場面の動きの偏りによるものでないかを確かめられる
- 端から本物の新しい内容が入るので、円環のずらしと違い、画素が自明に線形にならない。明るさ・白の偏り・反転・円環のずらしは画素の線形写像なので、白色化した量では値が変わらないか、画素が満点になる。これらは使わない（inventory.md 5 節の 1 と同じ結論）
- 画素を正解にしない。画素は介入にだけ使い、採点は符号の中で閉じる。移植の局所性の確かめと同じ立場である

注意が 2 つある。平行移動に不変な符号は $D_{\mathrm{tr}} = 0$ で、24 px でも $q$ に届かない。これは「線形」ではなく「その因子を捨てた」と記録する。また、位置ごとのトークンを並べた符号では、パッチの幅（8 px）の移動はトークンの入れ替えに近い。入れ替えは線形な作用だが、軌跡は真っすぐにならない（1 つの座標から別の座標へ中身が跳ぶ。画素と同じ形）。$a = 8$ の付近の値は、この構造を映す。使えるのは Amsterdam・Bangkok・Zurich の 3 本だけである。

### 5.4 候補 4: 類推（別の場面の変位を足す）は使えない

課題の例にある「$z_{t+1} - z_t$ を別の場面に足す」は、変位が場面によらない共通のベクトルであることを求める。その度合いは $\lVert E[\delta] \rVert^2 / E\lVert \delta \rVert^2$（$\delta = z(T_a x) - z(x)$）で測れる。

ところが、データの分布が変換 $T_a$ で変わらないなら、$E[z(T_a x)] = E[z(x)]$ なので $E[\delta] = 0$ になる。**どんな符号でも、この値は 0 である**（導いた）。自然な画像の分布は平行移動でほぼ変わらず、動画は時間について定常に近い。したがって、平行移動や時間の進みを「共通のベクトルの足し算」として表す符号は、原理的に存在しない。分布を保つ変換は、潜在では回転のような作用素としてしか表せない。Bouchacourt ら（2021）が部分空間ではなく作用素を勧めたことと合う（文献、literature.md 1.2 節）。

DCGAN の「笑顔のベクトル」が働くのは、属性の有無がデータの分布を変える変換だからである。街歩きの動画で、分布を変える変換を人のラベルなしに作る方法は見当たらない。

この量は物差しにせず、実装の確かめの帰無に使う（全ての符号で 0 の付近。大きく外れたら、データの切り出しの偏りか実装の誤りを疑う）。

### 5.5 候補 5: 白色化した線形の動力学（副）

`dynw_h / copyw_h` を、同じ $k$、同じ $\Delta_q$ で出す。1 時刻の符号から次を線形に当てる量で、当てはめる行列は $k \times k$ である。$k$ をそろえれば容量は等しい。$H$ は 2 時刻から係数を固定して外挿する量なので、問いが違う。1 時刻の符号が速度まで線形に持っていれば、$H$ が低くても `dynw` は良くなる。Klindt ら（2026）の定理が予言する「線形でガウスの遷移」に近い量である（文献）。なお、同じ定理が仮定する OU の遷移は $H = 1/2$ の形で、真っすぐではない。線形に識別できることと、軌跡が真っすぐなことは別の性質である（導いた）。

### 5.6 見送る候補

- 線形の作用素の当てはめ（$z(T_a x) \approx M_a z(x)$）: 画素がほぼ満点になり、不変な符号も $M = I$ で満点になる（literature.md 2.4 節）
- 別の場面どうしの補間が「意味のある点」か: 正解がデータに無く、判定にデコーダと判定者が要る
- 軸ごとの指標、total correlation、実効ランク: literature.md 1 節・2.6 節・2.7 節の理由で不適
- seed の間の線形の一致（SVCCA）: 空間の線形性ではなく、学習の再現性の量である。手元の 2 seed で計算できるので記述に並べてよいが、画素の符号は決定的なので満点になる

## 6. 比べる符号と、読む場所

読む場所は、数値を出す前に次の 2 つに決める。

- 各モデルの自分の潜在: VAE は $\mu$（256）、JEPA は $z$（1024）、画素は `pca`（1024）
- 共通の場所: 頭・射影の前のトークンの位置の平均 `h_mean`（1024）。VAE・JEPA・学習前で形が同じである（inventory.md 1.3 節）

符号は、`pca`、`lin_k`、`color`（$k$ = 16 だけ）、各腕の学習前、`v16`、`v17`、V18 の P16、V18b の F と M、V18c の長い run、理論の値を持つ合成の符号（9 節）とする。他の自己教師あり学習（MAE、VICReg など）は手元に無く、足すなら同じデータ・同じ ViT-S で学び直す必要がある（inventory.md 4 節）。その場合、時間の対を view にした手法は、この量をほぼ直接に最適化する。そうした手法との比べは、目的と物差しが重なることを明記して読む。

Zurich の 0.1 秒おきの stack をそのまま使うので、1 つの符号あたりの計算は Zurich の全 stack（約 3.9 万個）の符号化 1 回で済む（推測）。

## 8. 残る弱点

1. **線形性は情報の量を保証しない。** 1 つの遅い量 $y$ を $y, y^2, y^3, \dots$ と広げた符号は、線形には $k$ 次元あり、どの方向も $y$ と同じ滑らかさで動く。刻みを合わせても $H$ は高い。Codex さんが `participation` について指摘した抜け道と同じ型である。塞ぐ候補は内在次元（TwoNN。滑らかな再パラメータ化で変わらないので、この符号では 1 になる）を並べることだが、時間の相関が強い標本では軌跡そのものの 1 次元を拾うので、8 秒以上離した stack で測る必要がある。合否には使わず、記述として並べる。JEPA については、自己同定の相方が同じ役目を持つ
2. **平均の取り方の偏り。** $D$ は二乗の平均なので、速く動く場面が値を支配する。止まった場面と動く場面が混ざると、それぞれが滑らかでも、まとめた自己相関は尖って見える。この偏りは全ての符号に同じ動画・同じ時刻でかかるので、符号どうしの比べは保たれるが、理論の値（0.40、0.73）との絶対の比べは目安にとどまる
3. **上位 $k$ 個の選び方が分散の順であること。** 完全に不変な版は、4 節の `lin_k` と同じ一般化固有値問題を各符号に解き、加法性の欠けが閾値より小さい方向の数を数えるものである。ただし 1024 次元の固有値問題は標本の数に対して過学習しやすい。主にはせず、探索として記録する
4. **上回らなくても、表現が悪いとは言えない。** 物体の分類を学んだ CNN は曲率を増やし、不変性で学ぶ自己教師ありの手法も直線化しない（文献、literature.md 2.1 節）。真っすぐでない良い表現はありうる。この量が言うのは「時間について線形か」だけである
5. 2026 年の文献（Klindt ら、Wang ら）は、プロジェクトの決まりどおり、根拠にする前に本文を読み直す。この設計で根拠に使ったのは、Hénaff（2019）と、自分で導いた式である

## 9. 有効性の確かめ（数値を読む前に決め、外れたら止める）

過去 3 回は、物差しの値の幅が狭くて読めなかった。実装の確かめ（厳密な値が決まるもの）と、解像度の確かめ（実際に読む値の付近で差が見えるか）を分ける。Codex さんの指摘（実装の確かめは解像度を保証しない）を踏まえた。モデルの値は、V-d0〜V-d3 が通るまで計算しない。

実装の確かめ（合否は恒等式と閉じた式だけ）:

- **V-d0a**: 合成の符号で理論の値が出る。厳密な等速の直線で $H = 1$（丸めの範囲）、独立なガウスの雑音で $H = 0$、ランダムウォークで $H = 1/2$、$\rho$ を決めた OU 過程で閉じた式の値（後の 3 つは標準誤差の決めた倍数以内。倍数は調べる個数から Bonferroni で決める）
- **V-d0b**: 実際の符号（`pca` の上位 $k$ 個）に、乱数の可逆な行列と平行移動をかけても、$D$・$H$・$\Delta_q$ が相対誤差 $10^{-8}$ 以内で一致する
- **V-d0c**: 時間を逆順にしても値が一致する。時間を並べ替えると $H = 0$ になり、最短の刻みで $q$ を超える
- **V-d0d**: 定数と、階数が $k$ に足りない符号が「採点できない」と返る
- **V-d0e**: 滑らかな合成の過程を 2 倍に遅くしても、$H@q$ が一致し、$\Delta_q$ が 2 倍になる
- **V-d0f**: 類推の量 $\lVert E\delta \rVert^2 / E\lVert\delta\rVert^2$ が、どの物差しでも 0 の付近にある（5.4 節）

解像度の確かめ（物差しだけで行う）:

- **V-d1（刻みが取れる）**: `pca` と学習前の符号で、$k = 64$ の $\Delta_{0.25}$ が 0.2 秒以上 16 秒以下に入る。入らなければ、$2\Delta_q$ まで含めて測れる範囲に無いので止める
- **V-d2（効き目の階段）**: `pca` の上位 $k$ 個の符号に、既知の量の操作を加えた合成の符号で、値が理論どおりに動く。(i) 白い雑音を分散の割合 $\nu$ で足すと、$D$ に定数が足されるので、$H$ の下がり方は閉じた式で決まる。その値と一致する。(ii) 時間方向にガウスの核で平滑化すると（未来も使うので符号ではなく合成の対照）、核の幅とともに $H@q$ が単調に上がる。これは、実際に読む値（画素の付近）で差が見えることの確かめになる
- **V-d3（幅と揺れ）**: 揺れは、連続したブロックのブートストラップの 2 つの長さの大きい方 $\mathrm{SE}^*$ とする（自己同定と同じ流儀）。(i) `pca` の $H@0.25$ が 0.85 以下である。画素が既に理論の上側（1 つの周波数の回転 0.90）に張り付いていれば、上回る余地が読めないので止める。(ii) `pca` の値と、V-d2 の (ii) で核の幅を最大にした対照の値の差が $10\,\mathrm{SE}^*$ 以上ある。(iii) 参照の組を半分に分けた 2 通りと、$k = 48$・$64$・$96$ で、物差しの順序が変わらない

止める規則:

- どれかが外れたら、モデルの値を計算せずに報告する。$q$・$k$・刻みの格子を変えて通る条件を探さない
- 主の設定（$k = 64$、$q = 0.25$、読む場所 2 つ）は、数値を出す前に README に登録する。副の設定の値は、主の読みを変える根拠にしない
- 「上回る」と言う差の大きさ $\Delta_*$ は、V-d3 の $\mathrm{SE}^*$ と seed の間の差を見てから、モデルの値を見る前にユーザーと決める

## 10. 予想（推測。数値はどれも推測）

- `pca`（$k = 64$）の $H@0.25$ は 0.5〜0.75。$k$ が大きいほど低い
- 学習前の符号は `pca` と同じかそれ以下
- VAE（`v16`・`v17`）は `pca` の付近。画素を描き戻す目的は、時間の線形性を直接には求めない
- V18c の JEPA が `pca` を上回るかは分からない。空間のマスクの目的は時間の対を使わないので、Klindt ら（2026）の定理は当てはまらない（literature.md 5 節の 8）。上回らなかった場合は「JEPA は線形にしない」ではなく、「空間のマスクの目的は時間の線形性を作らない」と読む。V19 の未来予測で同じ量を測ると、目的の違いの効果が見える
- M（K3 に崩れた run）は、$k = 64$ で採点できないか、できても他と区別がつかない。崩壊の検出の代わりにならないことの例になる
- 平行移動の $H_{\mathrm{tr}}$ は、位置ごとのトークンを並べた符号では画素に近く、大域の符号（VAE の $\mu$）で差が出うる

## 11. 決めてほしい点

1. 主の量を、時間の $H@0.25$（$k = 64$）にしてよいか。同定の形（$A_{\mathrm{mid}}$）を主にしたい場合は、張り付きの確かめを V-d3 に足す
2. 平行移動を介入として使ってよいか。人が選んだ変換だが、ラベルではなく入力への操作である。使わない場合は、時間だけで進める
3. 読む場所を、各モデルの自分の潜在と `h_mean` の 2 つにしてよいか
4. 他の自己教師あり学習（MAE、VICReg、時間の対を使う手法）を、同じデータ・同じ ViT-S で学ぶか。学ぶなら GPU の作業になり、時間の対を使う手法は物差しと目的が重なる
5. この設計を Codex さんに批判してもらう点。とくに、8 節の 1 の抜け道をほかに塞ぐ方法があるか、刻みを合わせる手続きに別の抜け道がないか、V-d2・V-d3 が解像度の確かめとして足りるか
