# 線形の幅（どの Δ まで時間の線形性が成り立つか）の理論の検討（2026-11-26）

対象は、ユーザーの提案（2026-11-26）と、その続きである。

- 「小さな Δ では線形性はそもそもある。重要なのは、線形な区間を広げること。どの Δ を選ぶかではなく、どの Δ まで成り立つかを測り、崩壊の指標でガードする」
- 「平均的な線形性の幅がどれだけ大きいかが、他の手法と比べる量。拡散での画像の復元で、意味が保たれているかもガードする」

役割は設計の相談だけで、コード・README・plans には触れていない。GPU は使っていない。**学習した checkpoint の値（`judge_geom.json` と各 run の行）は読んでいない。** 使った実測は、README の有効性の節にある物差しの値だけである。

確かさは 3 段で書く。**確かめた**は CPU の numpy で数値を追ったもの（スクリプトは使い捨てで、リポジトリには置いていない）。**導いた**は定義から式で出したもの。**推測**はそれ以外である。

## 0. 結論

1. **提案の筋は良い。ただし「幅」は 0 から始まる区間ではなく、窓 $[\Delta_{\mathrm{lo}}, \Delta_{\mathrm{hi}}]$ で、空のこともある。** テイラー展開が効くのは、符号の軌跡が時間について 2 回微分できるときだけである。フレームごとに独立な雑音が少しでもあると、$\Delta \to 0$ で $G_{\mathrm{mid}}$ は 0 ではなく 3/4 に戻る（1 節）。だから「1/4 を超える手前の $\Delta$」ではなく、「1/4 を下回る $\Delta$ の区間」を測る
2. **$G_{\mathrm{mid}}$ は、続く 2 つの変位の相関 $\rho$ そのものである。** 三つ組ごとの恒等式で $G_{\mathrm{mid}} = (1 - \rho)/2 = 1 - D(2\Delta)/(4 D(\Delta))$ が成り立つ（定常の仮定は要らない。導いた・確かめた）。$D(\Delta)$ は変位の二乗平均である。だから、境 1/4 は $\rho = 1/2$（曲がりの角度 60°、局所の指数 $\alpha = \log_2 3$）、境 1/2 は $\rho = 0$（90°、$\alpha = 1$）に当たる。$\alpha$ は $G_{\mathrm{mid}}$ の目盛りの付け替えで、新しい情報は無い
3. **物差しは 0.8 秒で、すでに $\rho < 0$ である**（`pca` −0.18、`mean8` −0.07、`init_f` −0.39。角度で 94〜113°）。等速の外挿どころか、勢いが逆向きに出ている。重ならない刻み（0.8 秒以上）での幅は、物差しではどれも「無い」。課題は「幅を広げる」より前の、「窓を作る」である
4. **定常で有界な符号では、線形の幅を広げることは、符号を遅くすることと同じである（定理）。** $G_{\mathrm{mid}} \ge s/2$ なので、幅が $\Delta$ に届くには $s(\Delta) < 1/2$ が要る。`pca` の $s$ は 6.4 秒で 0.83 なので、幅を 6.4 秒にするには、符号を画素よりずっと遅くするしかない。遅くする方法が「速い内容を捨てる」か「同じ内容をまっすぐな座標に並べ直す」かは、時間の 2 次の統計では分けられない。分けるのはガードの側である
5. **プールした白色化の $G_{\mathrm{mid}}$ は、いちばん速い方向に支配される。** 64 方向のうち白い雑音のように動く方向が 4 つ以上あると、残りの 60 方向が完全にまっすぐでも、境 1/4 の窓は無くなる（3 つなら有る。導いた・確かめた、2.3 節）。プールした幅を目的にすると、「速い情報を持つ方向を 3 つ以下にする」ことを求めることになる
6. **推奨**: (a) 幅は、時間で重みづけた量（三つ組ごとに外挿が copy に勝つ割合 $p(\Delta)$）を主にし、プールした曲線の横切りを必ず並べる。(b) 境は 1/4 を主、1/2 を副にする。(c) 主の幅は 0.8 秒以上で定義し、0.8 秒未満は `mean8` と並べた記述にとどめる。(d) 拡散のデコーダのガードは、中点より**外挿**を主にし、距離や FID ではなく時間の近傍の中での同定で読む。(e) V19 では、まず評価だけにして、目的に入れるのは別の腕にする
7. **塞げない穴が 2 つ残る。** 1 つの量を多項式で広げた符号（既知）と、Inception の特徴が短い $\Delta$ を分けられない場合の拡散のガードである

## 1. ユーザーの提案の筋の良さと危うさ

### 1.1 恒等式（導いた・確かめた）

三つ組ごとに $\nu = \tfrac14\lVert a - b\rVert^2$、$\delta = \tfrac12(\lVert a\rVert^2 + \lVert b\rVert^2)$ で、$\lVert a - b\rVert^2 = 2\lVert a\rVert^2 + 2\lVert b\rVert^2 - \lVert a + b\rVert^2$ なので

$$\nu = \delta - \tfrac14 \lVert w_{t+\Delta} - w_{t-\Delta} \rVert^2 = \tfrac12 \delta - \tfrac12 \langle a, b \rangle$$

となる。三つ組の集合で和を取ると

$$G_{\mathrm{mid}}(\Delta) = \frac{1 - \rho(\Delta)}{2} = 1 - \frac{\tilde D(2\Delta)}{4 \bar D(\Delta)}, \qquad \rho = \frac{\sum \langle a, b\rangle}{\sum \delta}$$

である。$\tilde D(2\Delta)$ は同じ三つ組の両端の変位の二乗平均。定常の仮定は要らない（乱数の系列で 3 つの式が 15 桁一致した）。物差しの表でも、$1 - s(2\Delta)/(4 s(\Delta))$ は `pca` 0.592（実測 0.589）、`mean8` 0.539（0.536）、`init_f` 0.700（0.695）で、差は三つ組の集合と層の違いの分である。

| | $G_{\mathrm{mid}}$ | $\rho$ | 角度 | $\alpha = \log_2 (D(2\Delta)/D(\Delta))$ |
| -- | -- | -- | -- | -- |
| 等速の直線 | 0 | 1 | 0° | 2 |
| 等速の外挿と copy が同じ | 1/4 | 1/2 | 60° | $\log_2 3 = 1.585$ |
| ランダムウォーク | 1/2 | 0 | 90° | 1 |
| 白い雑音 | 3/4 | −1/2 | 120° | 0 |

- $\rho$ は Hénaff らの曲率（続く変位の角度）を、変位の大きさで重みづけてプールしたものである
- 境 1/4 は「0 次のテイラー（copy）より 1 次のテイラー（等速の外挿）が良い」境で、ユーザーの言う「1 次の項で近似できる」をそのまま操作にしたものである
- 境 1/2 は「前の変位が次の変位について何も言わない」という自然な帰無である。変位に最適な倍率 $\rho$ を掛けた予測 $\hat b = \rho a$ の誤差は copy の $1 - \rho^2$ 倍なので、$\rho > 0$ なら勢いを使う線形の予測は copy に勝つ
- 外挿を $h$ だけ先に伸ばす版（速度を $\delta$ で測り、$h$ 先を当てる）の誤差も、$D(h) + (h/\delta)^2 D(\delta) - (h/\delta)[D(h + \delta) - D(h) - D(\delta)]$ で、$D$ だけで決まる（導いた）。**プールした量の候補は、どれも $D(\cdot)$ の関数である**

### 1.2 Claude の整理への訂正

| 整理 | 判定 | 訂正 |
| -- | -- | -- |
| 1. 滑らかなら $G_{\mathrm{mid}} \approx \tfrac14 (\lvert z''\rvert/\lvert z'\rvert)^2 \Delta^2$。曲率半径に当たる | 式は正しい。読みは 3 点直す | (i) 比は期待値の比 $E\lvert z''\rvert^2 / E\lvert z'\rvert^2 = E_\mu[\omega^4]/E_\mu[\omega^2]$ で、速い瞬間に重みがかかる。(ii) $z''$ は軌跡に沿った加速（速さの変化）も含む。まっすぐな線を不等速に進んでも 0 にならない。幾何の曲率（Hénaff の角度）とは違う。(iii) 2 回微分できることが前提で、雑音の床があると成り立たない（1.3 節） |
| 2. $G_{\mathrm{mid}} < 1/4 \Leftrightarrow G_{\mathrm{ext}} < 1$。代わりの境 1/2 | 正しい | $G_{\mathrm{ext}} = 4 G_{\mathrm{mid}}$ は三つ組ごとの恒等式。分母は対称な $\bar D$ で、未来の copy の誤差 $E\lVert b\rVert^2$ ではない（Codex さんの指摘のまま）。`in` の層では前半と後半の差を記録する |
| 3. $G_{\mathrm{mid}} \ge s/2$ なので、安い方法は遅い成分だけ残すこと | 正しいが弱い | 「安い方法」ではなく**必要条件**である（定常のとき、幅が $\Delta$ なら $s(\Delta) < 1/2$）。ずるかどうかは幅の側では決まらない。もう 1 つ、プールした値は速い方向に支配される（2.3 節）。TwoNN は 8 秒おきの点で測るので、遅い多様体の次元であり、速い情報を捨てたことは見ない |
| 4. 幅は 0.8 秒未満。最短の刻みが問題かもしれない | 半分正しい | 0.8 秒未満は測れる（stack は 0.1 秒おきにある）が、8 枚の箱形の平均だけで窓ができる（1.4 節）。問題は最短の刻みではなく、**重ならない刻みでは物差しに窓が無い**ことである |

### 1.3 危うさ 1: 雑音の床で、小さな Δ でも 0 に行かない（導いた・確かめた）

符号が「滑らかな成分 + フレームごとに独立な成分（分散の比 $\nu$）」なら、注入の式 $G_\nu = (sG + \tfrac34\nu)/(s + \nu)$ がそのまま当てはまる。滑らかな成分が 1 つの帯（$G = s/2$）なら

$$G_\nu < q \iff s \in \Big(q - \sqrt{q^2 - (\tfrac32 - 2q)\nu},\; q + \sqrt{q^2 - (\tfrac32 - 2q)\nu}\Big)$$

である。窓があるのは $\nu < q^2/(\tfrac32 - 2q)$ のときだけで、**境 1/4 では $\nu < 1/16$、境 1/2 では $\nu < 1/2$** である。

- 曲線は U 字になる。小さな $\Delta$ では雑音が支配して 3/4、中間で下がり、大きな $\Delta$ で飽和してまた 3/4
- 実データの雑音の源は、センサーと圧縮の雑音、歩きの揺れ（周期 0.5 秒前後と推測）、白色化が分散の小さい方向を 1 に引き伸ばすこと、である
- 画素に近い符号では、1 フレームの動きが特徴の相関の長さを超えると、テイラーの範囲がフレームの間隔（0.1 秒）より短くなる。線形の幅の物理的な意味は「場面が、特徴の相関の長さだけ動く時間」である（推測）

### 1.4 危うさ 2: stack の重なり（確かめた）

OU 過程（どの刻みでも $G > 1/2$ で、窓が無い）を 8 枚の箱形で平均すると、窓ができる。

| 元の OU の時定数 | 0.1 秒 | 0.2 秒 | 0.4 秒 | 0.6 秒 | 0.8 秒 | 1.6 秒 |
| -- | -- | -- | -- | -- | -- | -- |
| 0.8 秒 | 0.095 | 0.149 | 0.299 | 0.462 | 0.565 | 0.697 |
| 8 秒 | 0.066 | 0.105 | 0.215 | 0.332 | 0.405 | 0.500 |
| 80 秒 | 0.063 | 0.101 | 0.205 | 0.314 | 0.381 | 0.456 |

- 箱形の平均は微分できる系列を作るので、中身がランダムウォーク的でも、0.4〜0.5 秒までの窓が自動で生まれる。`mean8` の 0.8 秒の 0.536 は、時定数 0.8〜8 秒の行の間にある
- 白いフレームの平均では $D \propto n$ で、$G = 1/2$ のまま（窓はできない）。窓は「重なり × 入力の時間の相関」で生まれる
- `pca`（stack を並べたベクトル）は平均を取らないので、重なっても滑らかにならない。重なりの効きは符号器しだいである
- feed-forward の符号器が時間を平滑にできるのは 0.8 秒の窓の中だけである。実測でも、`mean8` と `pca` の差は 0.8 秒で 0.053、1.6 秒で 0.013、3.2 秒以上で 0.003 以下だった。**3.2 秒以上の幅は、時間の平滑では作れない**。作れるのは、内容の選び方（遅い特徴の選別）だけである
- V19 で状態を持つモデル（再帰）を測るときは別である。OU の積分（速度が時定数 $\tau$ の OU）は、入力の情報を何も持たなくても、幅 $1.151\,\tau$（境 1/4）を持つ。境 1/2 は上から超えない（確かめた）

### 1.5 危うさ 3: まっすぐさは、予測しやすさの十分条件で、必要条件ではない

- 回転（$z_{t+1} = A z_t$、固有値 $e^{i\omega}$）は、線形の予測器で何歩先でも誤差 0 だが、$G_{\mathrm{mid}} = \sin^2(\omega\Delta/2)$ で、幅は周期の 1/6 しかない（境 1/2 で 1/4。確かめた）
- まっすぐ ⊂ 線形に予測できる ⊂ 予測できる、の包含がある。「遅くなければならない」という定理（結論の 4）は、まっすぐさにだけ掛かる。線形に予測できることには掛からない
- だから、周期的で速い内容（歩み、車輪、信号）は、長く予測できても、まっすぐにはならない。幅だけを追うと、こうした内容を捨てる向きに働く
- ユーザーの目的（ダイナミクスモデルが予測しやすい、長くシミュレートできる）に直接当たるのは、学習した線形の予測器の誤差である。幅は、そのいちばん厳しい版として位置づけるのがよい（4 節）

### 1.6 筋の良い点

- 刻みを 1 つ選ぶ恣意が無くなる。曲線を 1 つの数（時間の単位）にまとめ、$k$ や層ごとに並べられる
- 境 1/4 は理論から決まり、データを見て選ばない
- Hénaff ら・Niu ら（2024）と同じ向きで、対照（copy・等速の外挿）が学習なしで作れる
- 幅が必ず遅さを伴うことが式で分かっているので、ガードが何を守るべきかが先に決まる（速い内容の保持）

## 2. 幅の定義と推定量

### 2.1 定義の候補

| 記号 | 定義 | 重み | 長所 | 短所 |
| -- | -- | -- | -- | -- |
| $\Delta_{\mathrm{lin}}^{\mathrm{pool}}$ | プールした $G_{\mathrm{mid}}(\Delta) < q$ の区間 | 変位の二乗（速い瞬間） | 恒等式と下限が使える。V19 の外挿の対照の MSE と同じ | 速い出来事（見落としたカット、速い振り）に支配され、手法の差がつぶれやすい |
| $p(\Delta)$ と $\Delta_{\mathrm{typ}}$ | 三つ組ごとに $\nu_t < q\,\delta_t$（その瞬間に外挿が copy に勝つ）の割合 $p(\Delta)$。$p$ が 1/2 を下回る $\Delta$ が、局所の幅の中央値 | 時間（どの瞬間も同じ） | 「平均的な幅」の言葉に合う。まれな出来事に強い。割合なので揺れの扱いが簡単 | 止まった場面では $\nu$ も $\delta$ も雑音だけになり、負けに数える。閉じた式は直線・回転・白い雑音に限る |
| $\bar\Delta$ | $\int_{\Delta_{\min}}^{\Delta_{\max}} p(\Delta)\,d\Delta$（区間を切った平均の幅） | 時間 | 「平均」そのもの。打ち切りを区間の端で明示できる | 格子の範囲に依存する |
| 層ごとの横切り | `slow`・`mid`・`fast` のプールした曲線 | 層の中で変位の二乗 | 動きの速さへの依存が見える | 層は刻みごとに決まり、下限 $s/2$ は成り立たない |

$q$ は 1/4（主）と 1/2（副）。

### 2.2 プールした横切りと、局所の幅の平均は違う（ユーザーの問い (f)）

- 静かな場面が 8 割（幅 6 秒）、速い振りが 2 割（幅 0.5 秒）で、速い側の変位の二乗が 10 倍なら、プールした曲線は速い側の重みが 0.71 になり、横切りは 0.5 秒の近くに落ちる。局所の幅の中央値は 6 秒、平均は 4.9 秒である（導いた）
- どちらも「平均」で、重みが違う。プールは「予測器の二乗誤差が見るもの」、時間の重みは「典型的な瞬間にどこまで伸ばせるか」である
- **推奨**: 手法の間で比べる主の量は、時間の重みの $\Delta_{\mathrm{typ}}$（と $\bar\Delta$）にする。理由は、ユーザーの言葉に合うことと、Zurich にはカットの塊が 45 か所あり、プールした値がデータの出来事で決まりやすいことである。プールした横切りは必ず並べ、順位が食い違えば両方を書く。層ごとの曲線は、説明のために出す（主にしない）
- 三つ組ごとの比を使った「局所の幅」（初めて境を超える $\Delta$）は主にしない。格子を細かくするほど超える機会が増え、値が格子に依存する
- 止まった場面の扱いは、特別な規則を足さず、`slow` の層の $p(\Delta)$ を並べて見る。`slow` で負けが多ければ、雑音の床（1.3 節）の現れである

### 2.3 プールした値は、速い方向に支配される（導いた・確かめた）

方向ごとに $s_i$・$G_i$ とすると、プールした値は $G = \sum_i s_i G_i / \sum_i s_i$ で、動く方向ほど重い。$k = 64$ のうち $m$ 方向が白く（$s = 1$、$G = 3/4$）、残りが 1 つの帯なら、1.3 節の式で $\nu = m/(64 - m)$ になる。

| $m$ | $\nu$ | 境 1/4 の窓 | 境 1/2 の窓 |
| -- | -- | -- | -- |
| 3 | 0.049 | 有る（$s \in (0.135, 0.365)$） | 有る |
| 4 | 0.067 | **無い** | 有る |
| 21 | 0.488 | 無い | 有る |
| 22 | 0.524 | 無い | 無い |

合成（周期 64 歩の帯 + 白い方向）でも、$m = 3$ は最小 0.233 で窓が有り、$m = 4$ は最小 0.258 で窓が無かった。

- プールした幅（境 1/4）は、「64 方向のほぼ全部が同時にまっすぐ」という厳しい条件である
- SIGReg は全方向の分散をそろえるので、自分の潜在では、速い方向を小さな分散に隠せない。「SIGReg + 幅を広げる」は「どの方向も遅くする」になり、情報の幅とぶつかる
- **案（ユーザーの判断。前回の裁定では「方向ごとに分ける版は採らない」とした）**: 方向ごとの幅の分布を記述に足す。$N_{\mathrm{lin}}(T)$ = 幅が $T$ 以上の方向の数。方向は、偶数番のブロックで一般化固有値問題（中点の誤差の共分散と変位の共分散）を解いて決め、奇数番のブロックで値を出す（選び方の偏りを避ける）。「時間の幅 × 次元の幅」が 1 本の曲線になり、速い情報を捨てるずるは $N_{\mathrm{lin}}$ が増えない形で見える。弱点は前回と同じで、1 つの量の展開を多くの方向に数える

### 2.4 推定量

1. **密な格子**: 三つ組を $n = 1, \dots, 64$ の全部と 128・256 で作る（符号化は 1 回で、三つ組は添字で引くだけ）。内挿はほぼ要らない。層別（`slow`・`mid`・`fast`）は画素の変位の計算が重いので、今の 6 つの刻みと、追加の少数（例: 1.2・2.4・4.8 秒）に限る
2. **$D(n)$ のブロック和を残す**: 1.1 節のとおり、プールした候補はどれも $D$ の関数である。$n = 1, \dots, 512$ の対の変位のブロック和を行に残せば、境や伸ばし方を変えた量を、符号化し直さずに出せる
3. **窓の読み方**: 主の範囲は $\Delta \ge 0.8$ 秒。$G(0.8) \ge q$ で、それより長い刻みにも窓が無ければ「0.8 秒以上に窓は無い」と書く（数を出さない。外に伸ばして推定しない）。窓が有れば $[\Delta_{\mathrm{lo}}, \Delta_{\mathrm{hi}}]$ と、最小の $G$ とその刻みを出す。横切りは隣の格子点の間を $\log \Delta$ で線形に内挿する
4. **区間**: 今のブロックのブートストラップ（128 秒と 256 秒の大きいほう）の各抽出で横切りを求め直し、分位で区間を作る。窓が無い抽出の割合も出す
5. **0.8 秒未満**: $n = 1, \dots, 7$ は記述として出し、`mean8`・`pca` と並べる。0.8 秒未満の幅は符号器の手柄として読まない。重なりなしで測るには stack を短くするしかなく、いまのモデルではできない
6. **$\Delta_*$**: 幅の比で決める（オクターブ）。物差しの 0.8 秒では、$k$ を 48・96 に変えたときの動き 0.03 が、曲線の傾き 0.07/オクターブに対して 0.4 オクターブに当たる。境 1/4 の近くでは傾きが大きい（滑らかな範囲で $2 \ln 2 \cdot G \approx 0.35$/オクターブ）ので、もっと小さくなる見込みである（推測）。仮の案は 0.5 オクターブ（1.41 倍）で、有効性の確かめの後、モデルの値を見る前に決める

### 2.5 比べを公平にする条件

- 同じ三つ組・同じ層（入力の側の規則）・同じ格子（いまのまま）
- 同じ白色化の手続き（参照の組・$k$・$\epsilon$）。$k$ = 16・256 と、上位 $k$ が担う分散の割合を必ず並べる
- 手法ごとに読む符号の水準（VAE は $\mu$、JEPA は $z$ か `h_mean`）を、値を見る前に決める
- どの手法も同じ 8 枚の stack を入力にする（重なりの条件がそろう）。stack の長さが違う手法は、重ならない刻みが違うので、同じ表に並べない
- 状態を持つモデルは、feed-forward と同じ表に並べるとき、1.4 節の積分のずるを別のガードで見る

## 4. V19 への組み込み

**推奨: まず評価だけにする。目的に入れるのは、その結果を見てからの別の腕にする。**

### 4.1 評価

- 対照の階段を、同じ刻み・同じ三つ組で並べる。分母は未来の copy の誤差 $E\lVert b\rVert^2$
  1. copy（0 次）
  2. 等速の外挿 $2z_t - z_{t-\Delta}$（1 次。倍率 1）
  3. 倍率 1 つの線形 $z_t + \hat\rho\,(z_t - z_{t-\Delta})$
  4. 学習した線形の予測器（$z_t$ と $z_{t-\Delta}$ から。参照の動画で当てはめ、Zurich で測る。`exp/lib/linear_dyn.py` の拡張）
  5. V19 の学習した予測器
- 段の間の差が読みになる。2 と 4 の差が大きければ「線形だが回っている」、4 と 5 の差が大きければ「非線形の予測が要る」
- 計量は 2 つ出す。損失の計量（生の $z$）と、手法の間で比べる白色化の上位 64
- 予測の対象の stack は、文脈の stack と重ねない（$\Delta \ge 0.8$ 秒）。重なると、入力のフレームが漏れる
- 学習した刻み（例: 0.8 秒）より長い刻みで幅が伸びるかを見る。学習した刻みでだけまっすぐなら、損失に合わせただけである

### 4.2 目的に入れる場合（腕 S）

- 損失は $E\lVert z_{t+\Delta} - (2z_t - z_{t-\Delta})\rVert^2 + \lambda\,\mathrm{SIGReg}$（Niu ら 2024 と同じ形で、予測器を持たない）
- **自明解**: 共分散が $I$ の制約の下でこの損失を最小にするのは、$E_\mu[(1 - \cos\omega\Delta)^2]$ が小さい順の $D$ 個の特徴である（SFA の 4 次の版。導いた）。定数にも低ランクにもならず、K1・K2 を通る。しかし (i) 速い内容を捨てる。(ii) いちばん遅い 1 つの量の高調波を並べた解（チェビシェフの展開）が、白色化の制約を満たしたまま損失を小さくする（SFA で知られた形）。SIGReg がこれを止める保証は無い（多くの高調波の射影はガウスに近く見える。推測）
- だから、入れるなら、空間のマスク予測の損失への補助の項として小さな重みで足し、重みを掃引して「幅とガード（5 節）のパレートの曲線」で読む。1 点の値で決めない
- 腕 S の幅は、目的そのものなので、成績としては読まない。読むのは、ガードの側と、学習していない刻みへの伸びである
- 局所性: この損失は 1 つのノードの 3 時刻の出力だけを使い、ノードをまたぐ逆伝播を要らない。必要なのは、$2\Delta$ 分の出力のバッファである。勾配を止める場所（目標の側）は設計で決める。mujou の `locality-and-async` との突き合わせは、実装の前に要る（確かめていない）

## 5. 拡散のデコーダを使うガード（ユーザーの問い (g)）

### 5.1 結論

- **ガードとして使える。ただし、距離や FID ではなく、時間の近傍の中での同定で読む。中点より外挿が鋭い**
- 「意味の保たれた線形の幅」と呼べるのは、「線形の演算で作った符号が、正しい時刻の、それらしい画像に戻る $\Delta$ の範囲」である。3 節の「速い内容を捨てる」ずるを塞ぐ、いちばん直接のガードになる

### 5.2 手続きの案

各符号の、既に学習したデコーダ（`posthoc_gen` の `ckpt/dec-*.pt`。条件は標準化した符号、的は stack の最後のフレーム）を、学習し直さずに使う。標準化はアフィンなので、中点・外挿と入れ替えられる。

- 条件にする符号: 本物 $z_t$（天井）、中点 $m = \tfrac12(z_{t-\Delta} + z_{t+\Delta})$、外挿 $2z_t - z_{t-\Delta}$、端 $z_{t-\Delta}$（copy）
- 同じ候補には、4 つとも同じ雑音 $x_0$ を使う（差が符号だけから出るようにする）
- **同定の候補は時間の近傍にする**: $\{x_{t + j\Delta}\}_{j = -J..J}$（同じ動画の、刻み $\Delta$ ずつ離れた本物）。中点は $j = 0$、外挿は $j = +1$ に当たれば正解
- 出す数: 正解率（中点・外挿・天井・copy）と、天井に対する比。$\Delta$ は 0.8・1.6・3.2・6.4 秒
- 絵（主の出力。ユーザーの言う「定性的な」確認）: 固定の規則で選んだ候補について、本物の 3 枚、$z_t$ から描いた絵、中点の絵、外挿の絵、画素の平均の絵を並べる。数値を読む前に見る

### 5.3 見かけの良さの対照（デコーダの事前分布の効果）

| 落とし穴 | なぜ起きるか | 対照 |
| -- | -- | -- |
| 絵がそれらしい | 拡散のデコーダは、どんな条件でもそれらしい絵を描く | FID やそれらしさを、線形性の証拠にしない。同定で読む |
| 距離が copy より近い | 2 つの特徴の平均は、どの特徴空間でも端より中央に近い（$G_{\mathrm{mid}} < 1$ と同じ算術） | Inception の特徴の平均 $\tfrac12(\phi(x_{t-\Delta}) + \phi(x_{t+\Delta}))$ を「平均するだけ」の基準に置く。距離は主にしない |
| 中点が $j = 0$ に当たる | 対称性で、二重像でも 0 番にいちばん近くなりうる | 画素の平均の画像（デコーダなし）と、`pca` の中点をそのデコーダで描いた絵を、同じ同定にかける。**外挿には対称性の抜け道が無い**（画素の外挿 $2x_t - x_{t-\Delta}$ は絵にならない）ので、外挿を主にする |
| 場面が遅く、端も中央も同じに見える | 候補どうしが区別できない | copy（$z_{t-\Delta}$ の絵）が 0 番に当たる割合を床にする。天井（$z_t$ の絵）が床から離れない刻みは「解像度が足りない」とする |
| 中点が符号の平均に寄る | 2 つの平均はノルムが縮み、デコーダが平均的な絵を描く。特定の候補に当たりが集まる | `pick_max`（hub）を並べる。`uncond` の行を置く |
| 情報は有るが、幾何が線形でない | — | 中点を条件に学習し直したデコーダ（「中点に有る情報」の上限）との差。記述の追加で、主にしない |

- 「それらしく、かつ正しい時刻に当たる絵」は、操作の上で「意味のある中間・未来」と呼んでよい。残る抜け道は、候補が区別できない場合だけで、床と天井で見る
- 速い内容を捨てた符号は、天井（$z_t$ の絵の、刻み $\Delta$ の近傍での同定）が低く出る。**幅は、天井が床から離れる刻みでだけ数える**

### 5.4 VAE と比べるときのデコーダの強さ

- どの符号も、同じ形・同じ step 数・同じ学習の組の、後から学習した flow のデコーダを使う（いまの G の評価のまま）。VAE 自身のデコーダは主に使わない（記述の行として足すのは構わない）
- デコーダの形は同じでも、符号ごとに「デコーダが学びやすいか」が違う。その差は天井（$z_t$ の絵）に出るので、中点・外挿は天井に対する比で読み、天井の値も並べる
- VAE は学習中に雑音つきの符号をデコードするので、自分のデコーダでは内挿に強い。後から学習したデコーダは $\mu$ だけで学ぶので、この利点は入らない。どの符号にも同じ条件である
- 多様体の外の符号への強さをそろえたいなら、デコーダの学習で符号に小さな雑音を足す手があるが、全デコーダの学習し直しになる。まずは今のデコーダで測る

### 5.5 限界

- Inception の特徴が、0.8 秒離れた 2 枚を分けられるかは分からない（`real_shift` は、1 秒後の本物でも 7〜8 秒おきの候補の中で 0.84 当たる。近い時刻の特徴は似ている）。短い刻みでは、どの符号でも「解像度が足りない」になりうる。物差しで先に確かめる（6 節の V-h3）
- 標本は候補 512 個までなので、幅の区間は粗い。主の幅の代わりではなく、ガードである

- 画素の平均の画像と、Inception の特徴の平均の当たり方を出す。中点の同定がこれらを超えられる余地があるかを、モデルの値の前に確かめる

## 7. 未決の点（ユーザーに決めてもらう）

2. **境**: 1/4 を主、1/2 を副（推奨）でよいか
3. **主の範囲**: 0.8 秒以上にし、0.8 秒未満は `mean8` と並べた記述にとどめる（推奨）でよいか。物差しが全部「窓なし」になるのを受け入れるか

## 8. 文献との関係

- Hénaff ら（2019）: 曲率は三つ組ごとの角度の平均で、速さによらない。ここの $\rho$ は、変位の大きさで重みづけてプールした余弦である。$p(\Delta)$ は三つ組ごとに数えるので、Hénaff の量に近い
- Niu・Savin・Simoncelli（2024）: まっすぐさを目的にし、自明解を分散・共分散の項で防いだ。4.2 節の腕 S と同じ形である。自明解が「崩壊」だけでなく「遅い特徴の選別と高調波」にもあることは、SFA（Wiskott・Sejnowski）の側の知見である（記憶に基づく。本文は読み直していない）

## ユーザーの決定（2026-11-26）

- 主の幅は時間の重み（三つ組ごとに「外挿が copy に勝つ」割合 p(Δ) が 1/2 を下回る Δ = 局所の幅の中央値）。プールした曲線が 1/4 を横切る Δ も並べる
- 境は 1/4 を主、1/2 を副
- 拡散のデコーダのガードは外挿を主、中点を副。候補は時間の近傍。どの符号も同じ形の後付けの flow デコーダを使う
- 位置づけ: 6 つの刻みのモデルの値は見た後なので、V18c までの細かい刻みの値は探索の記述として扱う。幅の定義・境・Δ*（仮に 0.5 オクターブ）は V19 の checkpoint の値を見る前に固定し、そこで判定する
- 残り（方向ごとの幅の分布 N_lin(T) を足すか、0.8 秒以上を主の範囲にするか、Δ* と拡散のガードの閾値）は、事前登録を書くときに推奨案で置き、ユーザーに示す
