# 1 つの stack の中の時空間の補完（設計の提案、2026-11-27）

ユーザーの方針（2026-11-27）は次のとおりである。「フレームを stack した理由は、画像 1 枚だけでは時間的な特徴量を得られないからだった。4 つの stack を並べるやり方は、シンプルでも、統一された扱いでもない。ある stack の中で、空間・時間のどちらにも補完を行えることが重要である。stack のフレームの間隔は 0.1 秒でなくてもよい。tubelet もありうる。early fusion は空間の補完だけを考えた結果で、時間の補完を考えれば考え直す必要がある」。

この文書はその方針に沿った設計の提案である。前の提案 [st-completion.md](st-completion.md)（4 つの stack をまたぐ格子、いまの V18d）を置き換える。コードは書いていない。読んだのは前の提案、`plans/v18d.md`、`results/v18d/README.md`（短い run の表まで。長い run と H1F〜H3 の値はまだ無い）、`plans/dyn.md`、`results/dyn/README.md` の 0.8 秒未満の記述、[linear-horizon.md](linear-horizon.md)、`models.py` である。

確かさは 3 段階に分ける。**確かめた**は、使い捨ての numpy のスクリプトで数値を追ったもの（リポジトリには置いていない。式は 8 節のオラクルに書き直せる）。**導いた**は定義から式で出したもの。**推測**は実データでの予想と計算時間である。この形で学習した符号の値は 1 つも無い。

## 0. 要点

1. **変えるのはトークンの箱の形だけである。** V18c のトークンはすでに時空間の箱である。形は 8 フレーム × 8 画素 × 8 画素で、格子は時間 1 × 空間 8×8 になっている。時間の格子が 1 点しか無いので、時間の補完を定義できなかった。箱を 2 フレーム × 16 画素 × 16 画素（tubelet）に変えると、格子は $4 \times 4 \times 4$ になる。トークンの数（64）、1 つの箱の入力の次元（1536）、符号の次元（$64 \times 16 = 1024$）、学習するパラメータの数、計算量は V18c と同じである（1 節）
2. **目的・エンコーダ・予測器・$z$・SIGReg は V18c のままで、格子 $P$ を $\Omega = T \times P$ に読み替える。** エンコーダは stack の中の見えるトークンの集合の関数で、時間もまたいで混ぜる。$z = W\,\mathrm{vec}(t(\Omega))$ は stack ごとに 1 つで、SIGReg は 128 個の stack にかける。時刻の番号ごとに分ける必要は無くなる（1 節）
3. **マスクの族はいまの V18d と同じ組み合わせである。** 空間の族 $F_8$ を全ての時刻にかけた管（今）と、4 つの時刻のうち 2 つを丸ごと隠す 6 通り（未来・過去・間など）を使う。どのトークンも隠れる確率は 1/2、隠す数は常に 32 である（2 節）
4. **時間の尺度はstack のフレームの間隔 $s$ で覆う。** 8 枚を間隔 $s$（0.1 秒の $s$ 倍）で等間隔に取り、$\log s$ を一様に引く。伸縮で格子が自分に写るので、前の版では刻みの分布だけにあった尺度の対称性が、格子そのものに入る。$s = 1$ は普通の stack で、stack の中の時刻の差は 0.2〜0.6 秒になる。$s$ を 128 まで引けば、隣の時刻の差は 0.2〜25.6 秒になる（3 節）
5. **失うものが 1 つある。** 前の版では、丸ごと隠した時刻の的は見える画素と無関係に計算されたので、時間の側には漏れの逃げ道が無かった。エンコーダが時間をまたぐと、この性質は無くなる。時間の側は空間の側と同じ穴（V18c の導出 5、鏡の符号）を持つ。評価では重ならない画素から作った部分の視野の符号と、移植した候補を使う（5 節、6 節）
6. **自明な解**: 定数と K3 は前と同じ閾値で排除される。「時間に沿って一定のトークン」は SIGReg の超過が約 0.09 しか無く、$\lambda = 0.5$ では排除されない。これは K3 の時間の版で、空間と対称に測れる（5 節）
7. **評価は 3 つの軸の半分で統一する。** 立方体の格子を x・y・t のどれかの軸で半分に切り、一方の半分だけを見た符号から他方の半分だけを見た符号を当てる。x・y が今、t の前半→後半が未来、後半→前半が過去である。V18c と比べるのは、今（既存の N）と、$z$ の dyn/copy（F・P）である（6 節）
8. **推奨**: 腕は 3 つ。T0（管だけ）、S1（管 + 時間の側、$s = 1$）、Sσ（同じ、$\log s$ 一様）。どれも 1 step が V18c と同じ約 0.115 秒と見込めるので、長い run は 1 本 約 1.9 時間である（7 節、9 節）

## 1. 形

### 1.1 記号

- フレーム $x_\tau$（$\tau$ は 0.1 秒の単位）。**stack** は、始点 $\tau$ と間隔 $s$ で決まる 8 枚 $x_\tau, x_{\tau + s}, \dots, x_{\tau + 7s}$ である。$s = 1$ がいまの stack（0.8 秒）
- **トークンの箱**: 続く 2 枚 × 16×16 画素。時刻の番号 $j \in T = \{1, 2, 3, 4\}$（$j$ 番目の箱は $x_{\tau + 2(j-1)s}$ と $x_{\tau + (2j-1)s}$）、空間の位置 $p \in P$（$4 \times 4$）。格子は $\Omega = T \times P$、64 個
- 埋め込み: 箱を平らにした $2 \cdot 3 \cdot 16 \cdot 16 = 1536$ 次元の線形写像（V18c は $8 \cdot 3 \cdot 8 \cdot 8 = 1536$）。位置の符号は固定の sincos で、$e_P(p) + \phi(u_j)$（$u_j = j - \tfrac52$）。間隔 $s$ はエンコーダに渡さない
- エンコーダ $f$: V18c と同じ ViT（幅 1024、μP、4 ブロック）。見えるトークンの集合 $V \subset \Omega$ だけを通す（keep）。attention は時刻も位置もまたぐ
- トークン $t(\omega) = R\,f(x; \mathrm{keep} = \Omega)_\omega \in \mathbb{R}^{16}$。符号 $z = W\,\mathrm{vec}(t(\Omega)) \in \mathbb{R}^{1024}$。固定の $R$（16 × 1024）と $W$（1024 × 1024）は V18c と同じ形である
- 予測器 $g$: V18c と同じ（幅 256、4 段、列の長さ 64）。位置の符号は 3 節

**$z$ は stack ごとに 1 つである。** SIGReg をかける単位も、dyn/copy などの評価の単位も、この $z$ になる。評価の $z$ は $s = 1$ の stack から作る。入力は V18c・`pca` と同じ 8 枚なので、既存の評価をそのまま当てられる。

### 1.2 損失

$$
L = (1 - \lambda)\, E_{x, s}\, E_{U \sim \mu} \left[ \frac{1}{\lvert U \rvert\, d} \sum_{\omega \in U} \bigl\lVert g(c_V, V, \omega) - t(\omega) \bigr\rVert^2 \right] + \lambda\, \mathrm{SIGReg}\bigl(\{z_b\}_{b=1}^{128}\bigr)
$$

$c_V = f(x; \mathrm{keep} = V)$、$V = \Omega \setminus U$、$d = 16$。stop-gradient も EMA も無い。V18c の式の $P$ を $\Omega$ に替えただけである。

- 128 個の stack は動画・始点・間隔を独立に引くので i.i.d. である。SIGReg は V18c と同じ 1 つの統計量で足りる。前の版の「番号ごとの 4 項の平均」は、同じ clip の 4 つの $z$ の相関を避けるためのものだった。stack が 1 つなら、その相関が無い
- Sσ では $z$ の分布が間隔 $s$ の混合になる。SIGReg が縛るのは混合の周辺分布で、$s$ ごとの分布ではない。$s = 1$ の $z$ が等方から外れうる（動きの方向の分散は $s$ が大きいほど大きい）。評価は参照の組で白色化し直すので、定義は崩れない。$s = 1$ だけで測った `sigreg_heldin` を記録に足す
- 損失の下限は前の提案の 1.3 節のままである。エンコーダを固定すると最良の予測器は条件つき期待値で、場がガウスで文脈が $t_V$ そのものなら $E^*(U \mid V) = \mathrm{tr}(\Sigma_{UU} - \Sigma_{UV} \Sigma_{VV}^{+} \Sigma_{VU})$ になる。ただし文脈は keep をかけて符号化したもので、$t_V$ の切り出しとは違う。この注意は管にも時間の側にも当てはまる

### 1.3 特別な場合（導いた）

箱の形を（フレーム, 画素, 画素）で書く。

| 形 | 格子 | 中身 |
| -- | -- | -- |
| (8, 8, 8) | $1 \times 8 \times 8$ | V18c。箱を平らにする順を合わせれば、early fusion + patch 8 の埋め込みとビットまで同じになる。時間の側は空 |
| (2, 16, 16) | $4 \times 4 \times 4$ | この提案。トークン 64、$D = 1024$ |
| (2, 8, 8) | $4 \times 8 \times 8$ | 空間の細かさを V18c に揃える形。トークン 256、計算は約 4 倍。$\mathrm{vec}(t)$ が 4096 次元になり、$W$ が正方でなくなる（4 節） |
| (1, 16, 16) | $8 \times 4 \times 4$ | フレームごとの箱。トークン 128。1 つの箱の中に動きが入らない |

V18c との違いは「格子の細かさを空間から時間へ移した」ことだけである。箱の体積（512 画素フレーム）は同じである。

## 2. マスクの族

$$
\mathcal{M} = \bigl\{ T \times M : M \in F_8 \bigr\} \;\cup\; \bigl\{ J \times P : J \subset T,\ \lvert J \rvert = 2 \bigr\}
$$

- **管（今）**: V18c の族 $F_8$（$4 \times 4$ の上の 436 個）を、4 つの時刻の全てで同じ位置にかける。V18c では粗い $4 \times 4$ を細かい $8 \times 8$ へ広げていた。ここでは粗い格子がトークンの格子そのものになる。隠す画素の領域は V18c のマスクと同じである
- **時間の側**: 4 つの時刻のうち 2 つを丸ごと隠す 6 通り。$\{3,4\}$ が未来、$\{1,2\}$ が過去、$\{2,3\}$ が間、$\{1,4\}$ が外向き、$\{2,4\}$ と $\{1,3\}$ が補間と 1 歩先（1 歩前）である
- 各 step の 128 個の stack のうち 64 個を管、64 個を時間の側にする（層別。いまの `st_masks` と同じ）

性質は前の提案の 2.2 節のままである（数え上げは同じ組み合わせ）。どのトークンも隠れる確率は 1/2。隠す数は常に 64 のうち 32 で、V18c の $r = 0.5$ と揃う。時刻の反転 $j \mapsto 5 - j$ で閉じる。箱の形が (8, 8, 8) なら V18c の族になる。

格子は 3 つの軸が同じ長さ 4 の立方体になった。それでも族を 3 次元の箱の和（前の提案の 2.4 節の 24138 個）にはしない。理由は前と同じで、その族は丸ごとの時刻を隠すマスクをほとんど含まず、今・過去・未来を別々に読めなくなる。2 つの側の重み 1/2 は$\Omega = T \times P$ の 2 つの因子を対等に扱う取り決めのまま残る。

## 3. 時間の尺度

### 3.1 間隔 $s$ を引く（導いた）

1 つの stack が覆う時間の範囲は、フレームの間隔で決まる。選び方を尺度の対称性で決める。

- **等間隔にする。** 等間隔の格子は反転で自分に写り、尺度が 1 つの数 $s$ で決まる。対数の間隔（$1, 2, 4, 8, \dots$ 単位おき）は、1 つの stack で多くの尺度を覆えるが、反転で別の格子になる。マスクの族が反転で閉じなくなり、未来と過去が同じ形の課題でなくなる。採らない
- **$\log s$ を一様に引く。** 伸縮の群の上の不変な測度で、どの尺度も優先しない分布はこれしかない（前の提案の 3 節と同じ理由）。伸縮 $s \mapsto cs$ はstack の格子の全体を、箱の中の 2 枚の間隔まで含めて、同じ形の格子に写す。前の版では stack の長さ 0.8 秒が固定で、刻みだけが伸縮した。そのため、刻みが stack の長さに近い所で対称性が崩れていた。この形では、崩れるのは下端 $s = 1$（標本化の周期 0.1 秒）だけである
- **範囲は $s \in [1, 128]$。** 隣の時刻の差は $2s$ 単位で 0.2〜25.6 秒、半分どうしの差（6 節）は $4s$ 単位で 0.4〜51.2 秒になる。上端は評価の主の範囲（半分どうしで 25.6 秒、$s = 64$）の 1 オクターブ上である。stack の長さは最大 $7 \cdot 128 + 1$ 単位（約 90 秒）で、動画（1 本 約 5 万単位）の端で除かれる始点は 2% 未満である

### 3.2 2 つの腕

- **S1（$s = 1$ に固定）**: ユーザーの言う「ある stack の中で」をそのまま行う形である。学習が読むのは V18c と同じ stack だけになる。目的の式は0.8 秒の窓の中の統計だけで決まる（導いた。$E^*(U \mid V)$ に入る $\Sigma$ は stack の中の共分散だけである）。0.8 秒より長い予測しやすさは、目的に直接は入らない
- **Sσ（$\log s$ 一様）**: 0.2〜25.6 秒の時刻の差を、同じ 1 つの stack の形で覆う。dyn/copy の主の範囲（0.8〜25.6 秒）は、$s \ge 4$ の stack の隣の時刻の差にあたる

### 3.3 評価の $z$ との関係（導いた）

Sσ には弱点が 1 つある。評価の $z$ は $s = 1$ の stack の符号である。Sσ の学習で $s = 1$ の stack は約 8% しか無い（$\log_2 1.5 / 7$）。さらに、Sσ の目的が直接に下げるのは「間隔 $s$ の stack の中の、時刻の間の当てやすさ」で、dyn/copy が測るのは「続いた 8 枚の $z$ どうしの、時刻 $n$ をまたぐ当てやすさ」である。この 2 つは別の量である。前の版は後者を直接に学習の的にしていた。1 つの stack に閉じると、この直接さを失う。

そこで評価を 2 つ並べる（6 節）。1 つは目的に合わせた stack の中の評価（間隔 $s$ の stack の半分どうし）で、もう 1 つは V18c と比べられる $z$ の dyn/copy である。Sσ の $z$ が dyn/copy で良くなるかは、エンコーダが尺度をまたいで同じ特徴を使うかによる。値で見る。

### 3.4 対称性と位置の符号

| 変換 | 扱い |
| -- | -- |
| 平行移動 | 不変。始点は一様に引く。エンコーダも予測器も、stack の中の相対の番号 $u_j$ だけを受け取る |
| 反転 | 課題の分布は不変（族が反転で閉じる）。予測器に対称性は課さない。箱の中の 2 枚の順は自然なままにする |
| 尺度 | $s$ の分布は不変。予測器には $\ell = \log_2 s \in [0, 7]$ を渡す。エンコーダには渡さない |

予測器の位置の符号はいまの `st_positions` と同じ $e_P(p) + \phi(u_j) + \psi(\ell)$ である。S1 と T0 では $\psi$ を足さない。学習するパラメータは増えない。対称性の主張は `plans/v18d.md` で弱めた形（$\phi$・$\psi$ のそれぞれ単独では反転が sin の符号の入れ替え、尺度が周波数ごとの回転として働く。和の上の 1 つの線形写像としては定まらない）のままにする。

エンコーダに $s$ を渡さない理由は、符号を画素だけの関数に保つためである。評価の $z$ が「どの尺度のつもりで符号化したか」に依らない。

## 4. 作りの選択と理由

| 形 | 得るもの | 失うもの | 判断 |
| -- | -- | -- | -- |
| (2, 16, 16) の箱、時間をまたぐ attention | V18c と同じトークン数・次元・計算量。空間と時間を同じ仕組み（keep と予測器）で扱う。1 つの箱が速度（2 枚の差）を持てる | 空間の箱が 8 画素から 16 画素になる。時間の側の漏れの無さ | **推す** |
| (2, 8, 8) の箱 | 空間の細かさが V18c と同じ | トークン 256 で計算が約 4 倍。$\mathrm{vec}(t)$ が 4096 次元で $W$ が $1024 \times 4096$ になる。$W$ の零空間の 3072 次元は SIGReg に縛られないので、時間に沿って一定のトークンが罰なしで作れる。$d = 4$ にすれば正方に戻るが、K3 の導出が変わる | 次の候補 |
| (1, 16, 16) の箱 | stack の中の 0.1 秒の差まで格子に載る | トークン 128。$D = 1024$ に揃えるには $d = 8$。1 枚の箱は速度を持てない | 採らない |
| 時刻ごとに符号化する（attention を 1 つの時刻の中に限る） | 時間の側に漏れが無い。stack をずらすと、重なる時刻のトークンがビットまで同じになる | エンコーダが見るのは 0.2 秒だけになる。stack の時間的な特徴は、4 つの符号の連結にしか無い。空間と時間で扱いが分かれる | 採らない。stack した理由（時間的な特徴）に合わない |
| early fusion のまま、フレームを落とす | 作りが V18c と同じ | 下に書く | 採らない |

2 枚の箱にする理由をもう 1 つ書く。2 次の運動（位置と速度で状態が決まる）では、1 枚は状態にならず、2 枚が状態になる最小である。dyn/copy が 2 点入力を使うのと同じ理由である。

**early fusion のまま stack の中の時間を扱う形**は 1 つ考えられる。early fusion の埋め込みは、フレームごとの線形写像の和 $\sum_j E_j x_j(p)$ である。文脈の側で、隠したフレームの項を和から落とせばよい。しかし的のトークンに時刻が無い。全体を見たトークンを的にすると、課題は「フレームを落としても符号が変わらないこと」になり、今・過去・未来を分けられない。隠したフレームだけの符号を的にする形もあるが、$E_j$ は stack の中の絶対の番号ごとに別の重みなので、平行移動の対称性が無い。フレームを落とした入力は、和の大きさが変わる。整った形にならないと判断した。

## 5. 自明な解

比べるのは目的の式の大域的な最小どうしの値で、予測器はそのエンコーダに対して最良とする。SIGReg の超過は前の提案と同じ近似 $0.241\,N\,(1/q - 1/1024)$（$N = 128$、$q$ は $z$ のランク）で見積もる。

| 解 | 補完の損失 | SIGReg の超過 | 目的で排除されるか | 見える量 |
| -- | -- | -- | -- | -- |
| (a) 定数・位置だけの関数 | 0 | 51.3 | $\lambda > 0.02$ で排除（V18c と同じ） | `Whitener`、$S$ |
| (b) K3（全トークンが 1 つの 16 次元の符号） | 管 0、時間の側は残る | 約 1.90 | $\lambda \ge 0.5$ で排除（利得は 1 以下） | `token_r2`、`rank` |
| (b') 時刻ごとに空間で一定（ランク 64） | 管 0、時間の側は残る | 約 0.45 | $\lambda = 0.5$ では利得が 0.45 を超えれば選ばれる | 時刻ごとの `token_r2` |
| (b'') 時間に沿って一定（ランク 256） | 時間の側がほぼ 0、管は変わらない | 約 0.09 | **$\lambda = 0.5$ では排除されない**（利得が 0.09 を超えれば選ばれる。$\lambda = 0.8$ で 0.36、$\lambda = 0.95$ で 1.72） | 下の `time_r2`、$E^d$ |
| (c) 予測器が代わりをする | — | 0 | されない | `pathway_gap`（$h$ と $t$ で学び直す比べ） |
| (d) 遅くする | 時間の側が下がる | 0 | されない | $V/D$ の分解、$E^d$ |
| (f) 時計・尺度だけ | — | — | 番号 $u_j$ だけの関数は標本によらない定数で、(a) に入る。$s$ はエンコーダに渡らない | — |
| (h) 隠した所に周りの情報を詰める（鏡の符号） | 管でも時間の側でも下げられる | 0 | されない | 移植した候補での同定、部分の視野の評価 |

- **(b'') は K3 の時間の版である（導いた）。** $t(j, p) = \sigma(p)$ とすると、的はどの時刻でも同じになる。見える 2 つの時刻から $\sigma$ を当てる誤差は、隠した 4 枚が $\sigma$ に足す分だけで、$\sigma$ を静止した内容にすれば小さい。$z$ のランクは 256 に落ち、超過は $0.241 \cdot 128 \cdot (1/256 - 1/1024) = 0.090$（確かめた、算術）。時間の側の健全な損失を $\ell_T$ とすると利得は約 $\tfrac12 \ell_T$ なので、$\lambda = 0.5$ では $\ell_T > 0.18$ で選ばれる。この解の $z$ は stack の中の動きを持たない。stack した理由を失う解なので、必ず見る
- **`time_r2`**: トークンの分散のうち、位置ごとの時間の平均 $\bar t(p) = \tfrac14 \sum_j t(j, p)$ で説明できる割合。`token_r2`（K3 の指標）の軸を空間から時間に替えたもので、新しい考え方は要らない。閾値は V18c の K3 の $\theta_3$ と同じ作り方（学習前と物差しの値）で、値を見る前に決める
- (d) は (b'') の連続的な版で、扱いは前の提案の 5 節のままである。間隔が短いほど隣の時刻は似ているので、$s = 1$ では写すだけで当たる分が大きい。勾配の多くが「隣と同じにする」向きになる（推測）
- **(h) が時間の側にも開く（導いた）。** 的 $t(j, p)$ は全体を見たエンコーダの出力なので、隠した時刻の的が見える時刻の画素の関数になりうる。前の提案の 8 節の「時間の切り口には漏れの逃げ道が無い」は成り立たない。ただし的はマスクによらない 1 つの関数で、時刻 1 を隠す 3 つのマスクの見える時刻（$\{3,4\}$・$\{2,4\}$・$\{2,3\}$）に共通の時刻は無い。どのマスクでも当たるのは、どの 2 つの時刻からも読める内容だけである。だから時間の側の鏡の符号は (b'')・(d) に重なる。管の側は V18c と同じ穴である
- 前の提案で「理論で根拠づけられた直し」とした、予測器の入力を $t = Rh$ にする形は、ここでもそのまま使える。発動の条件（`pathway_gap`）も同じにする

## 6. 評価（今・過去・未来を別々に）

### 6.1 考え方

前の提案の考え方を保つ。**重ならない画素から同じエンコーダで作った符号の間で、一方から他方を当て、その誤差を copy の誤差と平均の予測の誤差で割る。** エンコーダが stack の全体を混ぜるので、重ならない画素から符号を作るには、keep で部分だけを見せる。

### 6.2 半分の視野（目的に合わせた評価）

立方体の格子を、3 つの軸のどれかで半分に切る。半分 $H$ は 32 トークンで、符号は $e_H(x) = \mathrm{vec}(R\,f(x; \mathrm{keep} = H)) \in \mathbb{R}^{512}$ である。32 トークンの文脈は、学習でエンコーダが実際に受け取る形である（管も時間の側も、見えるのは常に 32）。

| 軸 | 半分の対 | 切り口 |
| -- | -- | -- |
| x・y | 左と右、上と下 | **今**。4 つの向き。`plans/v18d.md` の N と同じ定義 |
| t | 前半（時刻 1・2）と後半（時刻 3・4） | 前半→後半が**未来**、後半→前半が**過去**。差は $4s$ 単位 |

- 手続きは N のままである。軸ごとに、訓練の参照の組だけから 2 つの半分を合わせて PCA64 の白色化を 1 つ当てる。的と入力の平均は向きごとに固定する。copy の分母は平均で補正した copy、平均の分母は的の平均の予測である。線形と 2 層の残差 MLP を、dyn/copy と同じ規則で当てる
- 平均で補正する理由も N と同じである。エンコーダは時刻の番号 $u_j$ を受け取るので、前半と後半の符号の原点は揃わない
- 半分は 2 つの時刻を含むので、1 点入力でも速度が入っている。dyn/copy の 2 点入力にあたる
- **刻みの軸は間隔 $s$ で作る。** $s \in \{1, 2, 3, 4, 6, 8, 11, 16, 23, 32, 45, 64\}$ で、差は 0.4〜25.6 秒になる。主の範囲 0.8〜25.6 秒は $s = 2..64$ の 11 点で、dyn/copy の半オクターブの格子を 1/4 にしたものである。$\overline{\log R}$ は同じ台形の積分で出す。0.4 秒（$s = 1$）は別に書く
- S1 は $s = 1$ でしか学んでいない。S1 の $s \ge 2$ の値は学習の分布の外の入力での値として記録にとどめる
- 物差しは同じ半分の画素の PCA（`pca`）と自分の学習前である。**V18c は今（x・y）だけ測れる。** 時間の keep が無いので、t の軸は測れない
- 間（時刻 2・3 を、時刻 1・4 から）は、2 つの視野が平行移動で重ならないので copy が定義できない。平均の分母だけの記述にする
- 言える範囲: 部分の視野の符号の間の予測で、全体を見た $z$ の性質ではない

OU の場（時刻の間の相関 $r$、空間は任意）での閉じた式（導いた・確かめた、白色化しない座標）: 前半→後半の $R_{\mathrm{clim}} = 1 - (r^2 + r^4)/2$、$R_{\mathrm{copy}} = (2 + r^2)/4$。$r = 0.6$ で 0.7552 と 0.59、数値と一致した。

### 6.3 $z$ の dyn/copy（V18c と比べる評価）

$s = 1$ の stack の $z$ に、既存の dyn/copy をそのまま当てる。未来 F は既存の値と同じ定義で、過去 P と間 B は `plans/v18d.md` の表のとおりである（同じ三つ組で役を入れ替える）。主の範囲は 0.8〜25.6 秒。V18c・`pca`・既存の 34 個の符号と並ぶ。

### 6.4 0.8 秒未満（箱 1 つの符号）

0.8 秒未満では、8 枚の stack はフレームを共有する。重ならない画素から符号を作るには、stack より短い窓が要る。箱 1 つ（2 枚）だけを見せた符号 $c(\tau) = \mathrm{vec}(R\,f(x; \mathrm{keep} = \{j_0\} \times P)) \in \mathbb{R}^{256}$ を使う。$j_0$ は固定し（$j_0 = 2$ と登録する）、当てたい 2 枚がその番号に来るように stack の始点をずらす。平行移動の不変性があるので、どの 2 枚でも同じ座標の符号になる。

- 三つ組 $(c(u - n), c(u), c(u + n))$ に dyn/copy の F・P・B をそのまま当てる（白色化 PCA64、線形と 2 層、2 つの分母）。2 つの箱が重ならない条件は $n \ge 2$ なので、0.2〜0.7 秒（$n = 2..7$）が出る。同じ符号で $n \ge 8$ まで続ければ、0.2〜25.6 秒の 1 本の曲線になる
- 0.1 秒は出ない。0.1 秒の差は 1 つの箱の中にあり、補完の対象ではなく箱の中身である
- 弱点: 16 トークンの文脈は学習の形（32）の外である。物差し（2 枚の画素の PCA、学習前）も同じ手続きを通るが、判定には使わず記述にする
- V18c はこの評価で測れない（8 枚より短い窓の符号を作れない）

### 6.5 0.1 秒おきに重なる stack の格子との関係（導いた・確かめた）

既存の 0.1〜0.8 秒の行は重なる stack の $z$ の間の予測である。これが何を測るかを、連結の符号で導いた。符号が $m$ 個の原子（フレームや箱ごとの符号）の連結 $Z_\tau = (a_\tau, \dots, a_{\tau + m - 1})$ で、$k < m$ 個ずらした $Z_{\tau + k}$ を $Z_\tau$ から線形に当てるとする。共有する $m - k$ 個は誤差 0 で当たり、誤差は新しい $k$ 個にだけ出る。

- 原子の場がマルコフ（VAR(1)）なら、完全に白色化した座標で $R_{\mathrm{clim}} = k/m$ になる。原子の相関 $r$ によらない。スカラーの OU では $R_{\mathrm{copy}} = k / (2(m - r^k))$ である。白色化しない座標では $R_{\mathrm{clim}} = \tfrac1m \sum_{j=1}^{k} (1 - r^{2j})$
- 数値（$m = 4$、$r = 0.6, 0.9, 0.99$、1 点入力と 2 点入力）は式と 6 桁一致した。正規でない行列の 3 次元の VAR(1) でも $k/m$ になった。マルコフでない場（隠れた 5 次元の雑音つきの観測）では 0.249・0.481・0.692 で、$k/m$ を少し下回った
- つまり重なる格子の $R_{\mathrm{clim}}$ は、ほぼ「新しいフレームの割合」である。符号が共有するフレームを線形に取り出せる形かどうかを測り、ダイナミクスの当てやすさはほとんど測らない。`pca` は画素の線形写像なのでこの形に近く、early fusion で学んだ符号はフレームを非線形に混ぜるのでこの形にならない。学習した符号が 0.8 秒未満で `pca` より悪かったことの一部は、これで説明できる（推測。実際の評価は PCA64 で切るので、式の値そのものは当てはまらない）
- この提案のエンコーダも時間をまたいで混ぜるので、重なる stack の $z$ は線形にずれない。重なる格子の行はこれまでどおり記述として並べる。0.8 秒未満の主の読みは 6.4 節でする

### 6.6 自分の予測器による同定

`self_eval.py` を切り口ごとに当てる。採点する領域はどの切り口でも 16 トークン（256 次元）にする。格子が立方体なので、空間の四半分の管（$2 \times 2$ の位置 × 4 時刻）と 1 つの時刻（16 位置）が同じ大きさになる。

| 切り口 | マスク（学習の族の中） | 採点する領域 |
| -- | -- | -- |
| 今 | 管 $T \times M$（`e1f_masks` の $k = 8$） | 四半分の管 |
| 未来 | $\{3,4\}$ と $\{1,4\}$ | 時刻 3 と、時刻 4 |
| 過去 | $\{1,2\}$ と $\{1,4\}$ | 時刻 2 と、時刻 1 |
| 間 | $\{2,4\}$ と $\{1,3\}$ | 時刻 2 と、時刻 3 |

- 採点（対の勝率と `top1`、難しい候補は前後 ±2〜±32 秒の stack）と対照（`copy` は最も近い見える時刻の同じ位置、`const`）は前の提案の 8 節のままである。Sσ では $s \in \{1, 4, 16, 64\}$ を別々に出す
- **移植した候補を、時間の切り口にも使う。** 漏れが時間の側にも開いたためである。隠した時刻の 4 枚を別の stack の残りの時刻に移植して的を作る

## 10. 推奨と、ユーザーの問いへの答え

### 10.1 問いへの答え

「stack を 4 つ取ってくる必要はなく、1 つの stack の中でできないか」への答えは、できる、である。条件は early fusion をやめることで、それ以外は V18c のまま足りる。

- **できること**: 1 つの stack・1 つのエンコーダ・1 つの予測器・1 つの $z$ で、空間（今）と時間（未来・過去・間）の補完を同じ仕組みで行える。計算量は V18c と同じで、いまの V18d の約 1/3.5 になる。SIGReg は V18c と同じ 1 項に戻り、時間の対応を壊した対照も要らなくなる。フレームの間隔を引けば、0.2〜25.6 秒の時刻の差を同じ形で覆える
- **できないこと・失うもの**
  1. early fusion のままではできない。トークンに時刻が無いので、時間の的を定義できない
  2. 間隔が 0.1 秒のままだと、目的は 0.8 秒の窓の中の統計しか見ない。0.8 秒より長い予測しやすさは目的に入らない
  3. 間隔を広げても、目的が下げるのは stack の中の当てやすさである。dyn/copy が測る「続いた 8 枚の $z$ どうしの当てやすさ」を直接の的にはできない。4 つの stack の版が持っていた直接さを失う
  4. 時間の側の漏れの無さを失う。時間の側は空間の側と同じ穴を持つ
  5. 同じ計算量にすると、空間の箱が 8 画素から 16 画素になる

### 10.2 推奨

次の腕として回す価値はあると考える。理由は 3 つある。形が V18c から 1 つの読み替えで出る。計算が安い。T0・S1・Sσ の 3 つで、作り・時間の補完・尺度の効果が 1 つずつ分かれる。

1. **まず学習なしで測る（数分〜1 時間）**: 6.2 節と 6.4 節の評価を、物差し（画素の PCA）と学習前の箱のエンコーダに当て、曲線の形と区間の幅を見る。P1〜P12 のうち評価の側を通す
2. **T0・S1・Sσ の短い run**（V18c と同じ掃引）を回し、崩壊の指標と `time_r2`、内容のガードで長い run の設定を選ぶ
3. **長い run** で、$z$ の dyn/copy（F・P）と今を V18c と、時間の切り口を T0・物差しと比べる

予想（推測）: S1 は 0.8 秒未満の評価（6.4 節）と半分の視野の $s = 1$ を良くするが、$z$ の dyn/copy の主の範囲は T0 から動かない。Sσ は主の範囲の $R_{\mathrm{clim}}$ を下げうるが、$R_{\mathrm{copy}}$ は分からない。どの腕でも、$\lambda = 0.5$ では `time_r2` が上がり $E^d$ が下がる向きの圧力がある。

### 10.3 置いた仮定と取り決め

- **仮定**: 場は同じ動画の中で定常とみなす。stack は等間隔。エンコーダは 1 つの stack の画素だけの関数（尺度を受け取らない）
- **取り決め**: 箱の形 (2, 16, 16)（V18c と同じ数に揃う形で、2 枚は速度を持てる最小）。2 つの側の重み 1/2。間隔の範囲 1〜128。箱 1 つの符号の番号 $j_0 = 2$
- **足していないもの**: 項の重み、時間のための別の予測器、尺度ごとの SIGReg、遅さへの罰。(b'') と (d) は目的では排除できないと導出のとおりに書き、`time_r2` と $E^d$ で見る
- **特別な場合の包含**: V18c（箱 (8, 8, 8)）、T0（時間の側を除く）、S1（間隔の分布を 1 点にする）
- **前の提案から引き継ぐもの**: 損失の下限、マスクの組み合わせ、対称性の扱い、$z$ の dyn/copy の F・P・B と恒等式、時間の矢の読み方、同定の採点
- **この提案で分からないこと**: Sσ の $z$ が dyn/copy で良くなるか（3.3 節）。(b'') へ向かう強さ。16 画素の箱で内容がどれだけ落ちるか。離れたフレームの読み出しの速さ。どれも値で見る
