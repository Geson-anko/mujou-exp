# M17: 位置のずれに鈍い再構成の誤差（2026-11-12）

M17 の posthoc の `recon`（画素の二乗誤差 / 平均の画像の二乗誤差）は、画素の位置がぴったり合うことを求める。JEPA のエンコーダに求めるのは、主要な視覚の特徴（構造）を持つことで、画素の正確な位置ではない（MILESTONES.md の M17「方針の見直し」）。ユーザーの要望は「ぼかした後で測るような」誤差、つまり 1 px ずらしてもほとんど変わらない誤差。候補を調べ、Walking Tours の実データで測り、1 つを勧めて `exp/lib/blur_error.py` に実装した。**評価だけに使う**。M17 は学習に再構成の項を入れないので、どの損失にも使わない。

## 結論

- **勧める指標**: ガウスでぼかした後の二乗誤差を、平均の画像の同じ誤差で割ったもの。$\sigma = 2$ px（128×128 の画像で）

  $$\mathrm{recon}_\sigma = \frac{\operatorname{mean}\big((G_\sigma * (\hat x - x))^2\big)}{\operatorname{mean}\big((G_\sigma * (\bar x - x))^2\big)}$$

  $G_\sigma$ は半径 $\lceil 3\sigma \rceil$（$\sigma=2$ で 6 px、13 タップ）の分離可能なカーネルで、和を 1 にし、境界は reflect。1 は平均の画像、0 は真のフレーム、$\sigma=0$ は今の `recon` と一致する
- **σ = 2 の理由**: 実フレームの 1 px のずれで 0.010（平均の画像の 1%。今の `recon` では 0.115）。4 px のずれは 0.125、1 秒後のフレームは 0.49、別のフレームは 1.80 で、構造の違いは残る。周波数で見ると、応答の二乗 $K(\omega)^2 \approx e^{-\sigma^2\omega^2}$ が 1/2 になる波長は $2\pi\sigma/\sqrt{\ln 2} \approx 15$ px。ViT の patch（16 px）程度より大きい構造の誤差は半分以上残り、それより細かい誤差は落とす
- **名前の案**: `recon_blur`（$\sigma=2$）。PCA の線形の再構成は `recon_lin_blur`
- **今の結論は変わらない**: 学習した JEPA の像は、どの指標でも平均の画像と同じ程度（0.89〜1.06）。PCA ≪ 学習前の ViT < 学習した JEPA の順位は、どの候補でも同じ。ぼかすと、PCA-256 と学習前の ViT の差は 2.9 倍（`recon`）から 5.3 倍（$\sigma=2$）に広がる

## 候補の調査

| 候補 | 1 px のずれ | ぼけた像 | 事前学習の網 | 備考 |
| -- | -- | -- | -- | -- |
| 画素の MSE（今の `recon`） | 敏感（0.115） | 細部の欠けを全部数える | 不要 | MSE が最小のデコーダはぼけた像を出す（Blau & Michaeli 2018） |
| ガウスでぼかした MSE（1 つの σ） | σ で調節できる | ぼけと同じ帯域の誤差は数えない | 不要 | 線形で、cos への応答 $K(\omega)$ が閉じた形。σ→0 で MSE |
| 複数の σ の平均 | 1 つの σ と同程度 | 同上 | 不要 | 実測では順位が σ=2 と同じ。足す意味が小さい |
| ガウス・ラプラシアンのピラミッド（Burt & Adelson 1983） | 最も細かい帯域を入れると敏感 | 同上 | 不要 | Lap1（Bojanowski et al. 2018, arXiv:1707.05776）は L1 で細かい帯域を含み、1 px で 0.23。細かい帯域を除くと σ≈1〜2 のぼかしとほぼ同じ |
| 縮小（平均の pool）の MSE | pool の格子に依存 | 同上 | 不要 | 境界をまたぐずれで値が跳ぶ（エイリアス）。pool4 で 1 px 0.021 |
| SSIM（Wang et al. 2004, IEEE TIP 13(4)） | **非常に敏感**（0.40） | 対比の項がぼけを強く罰する（σ=1 のぼけで 0.24） | 不要 | 局所の構造の相関を見るので、位置合わせが前提。平均の画像と学習した JEPA の像の区別がつかない（どちらも約 1） |
| MS-SSIM（Wang, Simoncelli & Bovik 2003） | 敏感（0.12） | 同上 | 不要 | 128 px では 3 段まで。粗い段の重みが小さい |
| 小さな平行移動の最小（±2 px） | 0 | ぼけは罰する（σ=2 で 0.10） | 不要 | 25 倍の計算。ずれは許すが、ぼけは許さない。4 px では急に悪くなる |
| 低い周波数だけの Fourier の誤差 | 鈍い | 鈍い | 不要 | 理想の低域通過で、σ のぼかしとほぼ同じ値。端の扱い（周期の境界）と ringing が欠点 |
| LPIPS（Zhang et al. 2018, arXiv:1801.03924）・DISTS（Ding et al. 2020, arXiv:2004.07728） | 鈍い（DISTS はずれに頑健に作られている） | — | **要る**（ImageNet の AlexNet / VGG） | 依存と重みのダウンロードが要り、テストではダウンロードできない。「$z$ が構造を持つか」を別の学習した表現で判定することになる。今は採らない。採るなら後から 1 度、順位が変わるかの確認に使う |

参考: Zhao et al., "Loss Functions for Image Restoration with Neural Networks"（arXiv:1511.08861、MSE・SSIM・その混合の性質）、Blau & Michaeli, "The Perception-Distortion Tradeoff"（arXiv:1711.06077）、I-JEPA（Assran et al. 2023, arXiv:2301.08243、画素の細部を捨てて意味の特徴を予測する）。

### 条件

- データ `3c3e6805fdaa`（std-00 の `/data/geson/mujou-exp/.fleet/data/3c3e6805fdaa`）。Zurich から 400 フレームを無作為に選んだ（`numpy.random.default_rng(0)`、40 フレーム手前まで）。各フレームの 3 フレーム後（0.1 秒）と 30 フレーム後（1 秒）も取った
- 平均の画像: 学ぶ 9 本からそれぞれ 300 フレームを無作為に選んだ 2700 枚の画素の平均（posthoc の平均の画像は学ぶ積みの最後のフレームの平均で、これの近似）

- 値はすべて「その指標の誤差 / 平均の画像の同じ誤差」（SSIM は 1 − SSIM で同じ比）。全体の和の比で、`recon` と同じ形
- 候補の定義: `blurσ` = `exp.lib.blur_error.blur_mse`、`pool k` = k×k の平均の pool の後の MSE、`gpyr` = ガウスのピラミッド（σ=1 でぼかして 1/2）の段 1〜4 の MSE の平均、`lap2c` = ラプラシアンのピラミッドの最も細かい帯域を除いた 4 段の MSE の平均、`lap1` = 5 段すべての L1 の平均、`minsh2` = ±2 px の平行移動の最小の MSE（端 2 px を除く）、`lowf r` = 半径 r（周期/画像）以内の Fourier 係数の誤差、SSIM は窓 11・σ 1.5、MS-SSIM は 3 段、`msblur` = blur1・2・4 の平均
- 計算はスクリプト（作業用の scratchpad、コミットしない）で、Mac の CPU、float64

### 読み

- **画素の MSE は位置合わせに支配される**: 完璧な像を 1 px ずらすだけで 0.115 で、PCA-256 の val の `recon`（0.169）の 7 割に当たる。0.1 秒後のフレーム（0.180）は PCA-256 より悪い
- **σ=2 のぼかし**: 1 px で 0.010、2 px で 0.037、σ=2 のぼけで 0.008。0.1 秒後のフレームは 0.057、1 秒後は 0.49、別のフレームは 1.80 で、構造の違いはよく残る。PCA-256 の像（0.138）より 1 px のずれが 1 桁以上小さい
- **σ を大きくしすぎない**: σ=4 では 4 px のずれでも 0.054 で、1 秒後のフレームも 0.38 まで縮み、構造の違いを数えにくくなる。σ=1 は 1 px で 0.026 と、σ=2 よりずれに 2.6 倍敏感
- **PCA の 3 つの順位**: MSE では PCA-256 < PCA-512 < PCA-128 で、σ ≥ 1 では PCA-512 が一番悪い（σ=2 で 0.199）。PCA-512 の MLP のデコーダは線形の再構成より悪い（results/m17.md の `recon` 0.170 と `recon_lin` 0.140）。σ=2 では、PCA-512 の像は細部を描くが粗い構造の誤差が大きい、と読める。線形の `recon_lin_blur` を測ってから判断する（8 フレームの値なので確かではない）
- **SSIM・MS-SSIM は向かない**: 1 px で 0.40・0.12、σ=1 のぼけで 0.24・0.05 と、ずれとぼけの両方に敏感。学習前の ViT と JEPA の像はどちらも約 1.0 で、平均の画像と区別できない。ぼけた像を出すデコーダの評価には合わない
- **平行移動の最小（minsh2）** はずれを完全に許すが、ぼけた像を許さない（σ=2 のぼけで 0.10）。デコーダの像はぼけているので、目的に合わない
- **pool・gpyr・lowf** は σ≈2〜3 のぼかしと同じ程度の値。pool は格子に依存し、lowf は周期の境界を仮定する。ガウスのぼかしの方が単純で、性質（cos への応答、σ→0 で MSE）が閉じた形で書ける
- **自分の平均の色** が 0.96 で、平均の画像とほぼ同じ。画像の分散のほとんどは場面の中の空間の構造にある。学習した JEPA の像（0.89〜1.05）はこれと同じ水準で、場面の色しか持たないという results/m17.md の読みと合う

## 実装（`exp/lib/blur_error.py`）

- `gaussian_kernel(sigma)`、`gaussian_blur(x, sigma)`（`(..., H, W)`、reflect、σ=0 で恒等）、`blur_mse(a, b, sigma)`（スカラーのテンソル）、`blur_recon(x_hat, x, mean, sigma=SIGMA)`（float、1 = 平均の画像）。`SIGMA = 2.0`
- テスト（`tests/lib/test_blur_error.py`）のオラクル: 同じ画像で 0、σ=0 で画素の MSE と一致、平均の画像で 1（σ = 0・1・2・4）、カーネルの和が 1・対称・半径 $\lceil 3\sigma\rceil$、一様な像を保つ、両端で偶な cos（$\omega(W-1) = m\pi$）は全体で $K(\omega)$ 倍（reflect が厳密に延長する）、1 px ずらした cos の誤差は内部で $K(\omega)^2$ 倍になり、連続のガウスの $e^{-\sigma^2\omega^2}$ と 1% で合う（3σ で切った分）、縦横で同じ、負の σ と小さすぎる画像を拒む

## 組み込み方（まだ組み込んでいない）

M17 のコードは別の作業が並行して直しているので、`encoder_eval.py` には触れていない。組み込むときは次のとおり。

1. `exp/video/measure/encoder_eval.py` の `_evaluate` に 2 行足す（`self._mean` は `(1, C, H, W)` で、`expand_as` が通る）

   ```python
   from exp.lib.blur_error import blur_recon
   ...
   "recon": _mse(x_hat, f0) / base,
   "recon_blur": blur_recon(x_hat, f0, mean_img),
   ...
   if code.linear is not None:
       ...
       line["recon_lin_blur"] = blur_recon(lin, f0, mean_img)
   ```

   必要なら動力学の像も同じ形で `img_dyn_{h}_blur` にする。`recon_fit` の側（`_fit_error`）は、batch ごとに `blur_mse(...) * len` を足せば同じ比になる
