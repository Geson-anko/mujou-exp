## 0. 要点

1. **ユーザーの直観は 1 つの問いに言い直せます。** 「動画の前後 2 時刻の符号を平均した点は、本物の中間の時刻の符号にどれだけ近いか」という問いです。画素では 2 枚を平均すると二重像になり、中間のフレームにはなりません。正解（本物の中間）は動画そのものに入っているので、ラベルも外部の物差しも要りません（1 節）
2. **ただし、これだけでは良さの証拠になりません。** Fable さんと Codex さんの議論で、次のことが分かりました。この種の「時間の線形性」の値はどれも符号の時間のスペクトル（どの速さで変わる成分がどれだけあるか）だけで決まります。情報を捨てて遅くなった符号も、良い値を取れます。1 つの量だけを 64 次元に広げた符号が、理論の上限の近くまで届く例もあります（2.3 節）
3. **そこで、2 つの量を組にして並べることを推します。** 1 つは「中点の誤差の曲線」（足し算が効くか）です。もう 1 つは「離れた時刻での内在次元」（どれだけ多くの独立な変化を表せるか）です。片方のずるい当て方はもう片方で値が悪くなります（3 節）
4. **これは disentanglement の合否の指標ではなく、記述です。** VAE・JEPA・画素を同じ目盛りに載せられますが、1 つの数で順位をつける理論的な根拠はありません。この点は Fable さんと Codex さんの合意です
5. **軸ごとの指標（MIG・DCI など）と、独立性（total correlation）は使いません。** 正解の因子のラベルが要るか、JEPA の SIGReg が回転で不変なために VAE に有利に偏るかの、どちらかだからです（2.4 節・7 節）
6. **いまの JEPA の検証項目はこの評価では減らせない見込みです。** 崩壊の検出（K1〜K3）・移植と局所性・自己同定は、この評価では見張れない抜け道を塞いでいます。減らせるのは表示の重複など小さなものだけです（6 節）
7. **この評価がいちばん役に立つのは、V19 の未来予測です。** 学習の要らない「等速の外挿」が、予測器の対照になります。その誤差の下限も式で分かります（6 節）

## 1. ユーザーの直観を、測れる問いに言い直す

ユーザーの言葉を、3 つの主張に分けます。

- (a) 画素の空間では 2 枚の画像を足した点は意味のない画像になる
- (b) disentangle された空間では足した点や、その中を動いた先が意味のある点になる
- (c) そのとき、線形性のような良い性質が生まれている

「意味のある点か」を人の目や外部の分類器で判定すると、V18c で 3 回つまずいた形に戻ります。デコーダで画像に戻す方法も、JEPA にはデコーダが無いので比べられません。そこで、**正解がデータの中にある足し算だけ**を使います。

動画の 3 つの時刻 $t - \Delta$、$t$、$t + \Delta$ を取ります。前後の符号の平均 $m_t = \tfrac12 (z_{t-\Delta} + z_{t+\Delta})$ は、符号の空間で「2 枚を足した点」です。この点が意味を持つなら、本物の中間の符号 $z_t$ に近いはずです。

Hé naff ら（2019、Nature Neuroscience）は、これを人の知覚で確かめました（文献、本文を読んだ）。自然な動画の軌跡は画素の空間では大きく曲がります（例の列で 99°）。人の知覚の空間ではほぼ真っすぐになります（8°）。逆に、2 枚を画素で混ぜた列は画素では真っすぐ（0°）ですが、知覚の上では曲がります（増加の中央値 53°）。ユーザーの直観「画像をそのまま足しても意味がない」を、心理物理の実験で示した研究です。

言い直した問いは次の 3 つです。

| 問い | 測れるか | 対応する量 |
| -- | -- | -- |
| Q1. 符号の空間で、前後 2 点の平均は本物の中間にどれだけ近いか。画素より近いか | 測れる | 中点の誤差の曲線（3.1 節） |
| Q2. Q1 が良いのは、情報を捨てて遅くなったせいではないか | 測れるが、決め手は無い | 離れた時刻での内在次元（3.2 節） |
| Q3. 画像の変化の要因（因子）が、空間の中で別々の方向に分かれているか | 人のラベルを使わず、2 次の統計だけでは測れない。人が選んだ入力の操作（平行移動など）を「因子」と認めれば、その範囲で一部を測れる | 7 節・9 節の決めてもらう点 2 |

Q1 と Q2 は、ユーザーの言う「線形な空間に落ちる」「足しても意味がある」にあたります。Q3 は、文献で言う狭い意味の disentanglement（因子が軸に分かれること）にあたります。この 2 つは別の性質なので、分けて扱います。

なお、LeJEPA が等方なガウスを目指す理由（線形の probe の推定が最も効率よくなること）は、ここで言う線形性とは別の量の話です（文献、LeJEPA の 3 節を読んだ）。等方性は画素を白色化した表現や独立な雑音でも成り立ちます。

## 2. 候補の指標の一覧

### 2.1 記号

- $z_t$: 時刻 $t$ の stack（8 フレーム、0.8 秒）の符号
- 白色化: 参照の組（Zurich でない学習の動画）での符号の共分散を $C$ とし、距離を $\lVert u \rVert_{C^{-1}}^2 = u^\top C^{-1} u$ で測ります。以下の距離はすべて、この白色化した距離です
- $a_t = z_t - z_{t-\Delta}$、$b_t = z_{t+\Delta} - z_t$（前半と後半の変位）
- $\bar D(\Delta) = \tfrac12 (E\lVert a \rVert^2 + E\lVert b \rVert^2)$: 1 歩の変位の大きさ。「前の時刻の符号をそのまま答えにする」予測（copy）の誤差にあたります
- $s(\Delta) = \bar D(\Delta) / (2V)$: その刻みで、全体の変動のどれだけの割合が動くか（$V$ は評価の動画での白色化した分散）。遅い符号ほど小さくなります

### 2.2 一覧

### 2.3 Fable さんと Codex さんが合意した点

1. **時間の線形性の値はどれも符号の時間のスペクトルだけで決まります**（導いた。Codex さんの反例を、Fable さんが 1 つの恒等式にまとめました）。白色化した符号の時間のパワースペクトルを確率測度 $\mu$ とし、$c = \cos\omega\Delta$ と置くと、定常な符号では次が成り立ちます。
   $$G_{\mathrm{ext}}(\Delta) = \frac{2\,E_\mu[(1 - c)^2]}{E_\mu[1 - c]} = 2s(\Delta) + \frac{2\,\mathrm{Var}_\mu[c]}{s(\Delta)}, \qquad H@q = \tfrac12 \log_2\!\Big(4 - 2q - \frac{2\,\mathrm{Var}_\mu[\cos\omega\Delta_q]}{q}\Big)$$
   ここから次の 3 つが出ます。
   - **下限**: $G_{\mathrm{ext}} \ge 2s$（$G_{\mathrm{mid}} \ge s/2$）です。等速の外挿が copy に勝てる（$G_{\mathrm{ext}} < 1$）のは $s < 1/2$ の刻みに限られます。定常で有界な符号は局所的にしか真っすぐになれません
   - **共通の刻みで読むと「遅さ」を測ります**。刻みが小さい範囲では $G_{\mathrm{ext}} \approx \Delta^2 E_\mu[\omega^4]/E_\mu[\omega^2]$ となり、速い成分を捨てるほど良くなります。このプロジェクトでも、V1〜V5 で `dyn_1/copy_1` が下がった理由を「符号がほとんど動かなくなったため」と区別できなかった前例があります（exp/vision/README.md）
   - **刻みを合わせると「時間尺度のそろい方」を測ります**。$s = q$ に固定すると、残るのは $\mathrm{Var}_\mu[\cos\omega\Delta_q]$ だけです。場面のような遅い内容と、動きのような速い内容の両方を含む符号ほど、値が下がります
2. **$H@q$ は主の指標にしません。** $q = 0.25$ での上限は $\tfrac12 \log_2 3.5 = 0.9037$ です。Fable さんの最初の表の「上限 1」は誤りでした
3. **1 つの量を広げた符号が抜け道になります**（導いた、Codex さん）。位相 $\theta_t = \Theta + \omega t$ の 1 つの量 $y_t = \cos\theta_t$ から、$z_j(t) = \sqrt2 \cos(j\theta_t)$（$j = 1000, \dots, 1063$）を作ります。共分散は単位行列、内在次元は 1 で、$H@0.25 \simeq 0.90356$ と上限の手前まで届きます。しかも、この符号と「独立な 64 因子」の符号では全ての刻みで 2 次の統計が一致します。$D$ や $G$ をどう使っても、この 2 つは区別できません
4. **値は尺度の混ぜ方で大きく動きます**（導いた、数値で確かめた）。白色化した方向の半分が OU 過程、半分が滑らかな山の自己相関である符号を考えます。滑らかな側の時間尺度を 1・3・10・30 倍にすると、$H@0.25$ は 0.504・0.353・0.299・0.293 と下がります。この値は純粋な OU（0.404）にも、純粋な滑らかな山（0.725）にも負けます。独立な情報を足すと値が下がり、捨てると上がります
5. **白色化で公平さを取ります。** 全次元・フルランクの白色化なら、符号を可逆なアフィン変換しても値は厳密に変わりません。ただし、上位 $k$ の PCA で次元をそろえると、不変性は $k$ 次元の中に限られます。$k$ ごとに、残る分散の割合・末尾の固有値・正則化への感度を並べます
6. **刻みは 0.8 秒以上にします。** 隣り合う stack は、8 枚のうち 7 枚を共有します。白い入力を 8 フレームで移動平均しただけでも $s(d) = \min(d/8, 1)$ となるので、0.8 秒未満の真っすぐさは入力の重なりと区別できません
7. **全ての符号に同じ三つ組を使い、2 階差分を直接集計します。** 前半と後半の変位の二乗平均が違うと、$H$ と加法性の対応が崩れます。Codex さんの例では $z(0), z(a), z(2a) = (0, 1, -2)$ で $H = 1$ になります
8. **既存の run どうしの比べは記述にとどめます。** 学習の目的の優劣を言うには、入力・データ・計算の予算をそろえて学び直す必要があります
9. **いまの JEPA の検証項目は減らせません。** 減らせるのは表示の重複（中点と外挿の片方）だけです
10. 軸ごとの指標・total correlation・有効ランク・線形の作用素の当てはめ・2 領域の移植の混合差分（画素が厳密に満点になる）は使いません

## 3. 推奨する組み合わせ

### 3.1 主 1: 中点の誤差の曲線（足し算が効くか）

- 量: 全ての符号に同じ三つ組 $(t - \Delta, t, t + \Delta)$ を使い、$E\lVert a \rVert^2$・$E\lVert b \rVert^2$・$E\lVert z_t - m_t \rVert^2$ を共通の白色化で直接集計します。$G_{\mathrm{mid}}(\Delta)$ を $s(\Delta)$ に対して描き、下限の線 $s/2$ を並べます
- 刻み: 0.8 秒以上、32 秒まで、ほぼ等比に並べます
- 層別: カットの内側の三つ組と、カットをまたぐ三つ組を分けます。動きの大小でも分けます。分け方の規則は入力の側で決め、全ての符号に同じものを使います
- 次元: 参照の組の PCA の上位 $k$ に射影してから白色化します。主の $k$ は 64 で、16 と 256 を副に並べます。$k$ は、比べる全ての符号の実効ランク（`pca` 52、VAE 116〜149、JEPA 116〜145）を目安に、数値を出す前に決めます
- 読み方: 曲線が下限の線に近いほど「足し算が効く」ことになります。同じ刻みで比べると遅さが、同じ $s$ で比べると時間尺度のそろい方が見えます。合否にはしません

ユーザーの直観にいちばん近いので、外挿ではなく中点を表に出します。外挿の誤差は中点の誤差のちょうど 4 倍なので、情報は同じです。

### 3.2 主 2: 離れた時刻での内在次元（情報を捨てていないか）

- 量: 8 秒以上離した stack の符号で、TwoNN の内在次元 $\hat d$ を出します。時間の相関が強い標本では軌跡そのものの 1 次元を拾ってしまうので、間隔を空けます
- 標本: Zurich だけでは 8 秒おきで約 490 stack しかありません。学習に使っていない時刻の別の都市の動画を足すか、標本の数による偏りを合成の符号で確かめます（推測。設計の確定のときに決めます）
- 読み方: 主 1 の曲線と並べます。2 つを 1 つの数にまとめる理論的な重みづけは無いので、まとめません（Fable さんの返答の 4 節）

### 3.3 この 2 つを組にする理由

2 つの量は互いのずるい当て方を塞ぎます（導いた）。

| ずるい表現 | 主 1（中点） | 主 2（内在次元） |
| -- | -- | -- |
| 1 つの量を多項式で広げた符号 | 下限の近く（良く見える） | 1（悪く見える） |
| 独立な雑音・時間を並べ替えた符号 | 3/4（悪く見える） | 大きい（良く見える） |
| K1（定数） | 採点できない | 0 |
| 遅い量だけを残した符号 | 共通の刻みでは良く見える。同じ $s$ で比べると差が消える | 小さい |

ただし、両方を同時にすり抜ける符号が無いことは、まだ示せていません。合成の対照（4 節・5 節）で、すり抜けないことを先に確かめます。

### 3.4 対照（全ての符号と同じ三つ組・同じ白色化に通す）

| 対照 | 役目 | 理論の値 |
| -- | -- | -- |
| 無加工の画素の PCA（`pca`、1024） | ユーザーの言う「画像を足しても意味がない」の基準線 | 動きが模様の細かさより十分小さい刻みでは良く、それを超えると悪くなる（導いた） |
| 8 枚の時間の平均 | stack の重なりの分 | 白い入力なら $s(d) = \min(d/8, 1)$ |
| 1 つの量のチェビシェフ展開（合成） | 主 1 の抜け道 | 下限の近く、内在次元 1 |
| 合成の K3（`h_mean` の水準を含む） | 崩壊が主 1・主 2 で見えるか | V18c の射影の後なら階数 16 以下で $k = 64$ では採点できない。`h_mean` の水準では採点できてしまう |
| OU 過程の混合（合成） | 尺度の混ぜ方の効き方 | 2.3 節の 4 の値 |
| 時間を並べ替えた符号 | 雑音の床 | $s = 1$、$G_{\mathrm{mid}} = 3/4$ |
| 学習前の符号（各腕の step 0）と `color` | 学習の前と、局所の色だけの符号 | 値は未知（推測では `pca` と同じかそれ以下） |

## 5. 有効性の確かめ（モデルの値を計算する前に決めるもの）

過去 3 回は物差しの値の幅が狭くて読めませんでした。そこで、実装の確かめ（値が厳密に決まるもの）と、解像度の確かめ（実際に読む値の付近で差が見えるか）を分けます。モデルの値は全てが通るまで計算しません。

### 5.1 実装の確かめ（合否は恒等式と閉じた式だけ）

- **V-d0a**: 合成の符号で理論の値が出ること。等速の直線で $G_{\mathrm{mid}} = 0$（丸めの範囲）、独立なガウスの雑音で 3/4、ランダムウォークで 1/2、OU 過程で閉じた式の値になります（後の 3 つは標準誤差の事前に決めた倍数以内）
- **V-d0b**: 2.3 節の恒等式を、合成のスペクトル（1 つの帯・2 つの帯・雑音を足したもの）で回収できること。2.3 節の表の値（0.9037、0.504・0.353・0.299・0.293 など）も回収します
- **V-d0c**: 全次元・フルランクの符号に、乱数の可逆な行列と平行移動をかけても、値が相対誤差 $10^{-8}$ 以内で一致すること
- **V-d0d**: 時間を逆順にしても値が一致すること。時間を並べ替えると $s = 1$、$G_{\mathrm{mid}} = 3/4$ になること
- **V-d0e**: 定数と、階数が $k$ に足りない符号が、「採点できない」と返ること
- **V-d0f**: TwoNN が合成の多様体の次元を回収すること（チェビシェフ展開で 1、独立な $n$ 因子で $n$）
- **V-d0g**: 類推の量 $\lVert E\delta \rVert^2 / E\lVert \delta \rVert^2$ が、どの物差しでも 0 の付近にあること（データの切り出しの偏りと、実装の誤りの検出）

### 5.2 解像度の確かめ（物差しだけで行う）

- **V-d1（範囲）**: `pca` と学習前の符号で、$s(\Delta)$ が 0.8〜32 秒の間に、下限の線と区別できる範囲を横切ること。0.8 秒で既に $s \approx 1$ なら、読める刻みが無いので止めます（具体的な閾値は、設計の確定のときに決めます）
- **V-d2（回収）**: `pca` の符号に、効き目が閉じた式で決まる操作を加えた合成の符号を作り、その変化を、同じ三つ組の対の差で回収できるかを見ます。例は固定した白色化の座標で等方に雑音を足すこと（$s_\nu = (s + \nu)/(1 + \nu)$）です。Fable さんの最初の案「時間の平滑化で単調に上がる」は偽だったので、使いません
- **V-d3（揺れと安定）**: 揺れは連続したブロックのブートストラップで出し、ブロックの境界をまたぐ三つ組は作りません。参照の組を半分に分けた 2 通りと、$k = 48$・64・96 で、物差しの順序が変わらないことを見ます
- **区別したい最小の差 $\Delta_*$**: V-d3 の揺れと seed の間の差を見てから、モデルの値を見る前に、ユーザーと決めます。V-d2 にはこの $\Delta_*$ の大きさの差を回収できることを求めます

### 5.3 止める規則

- どれかが外れたら、モデルの値を計算せずに報告します。$k$・刻みの格子を変えて、通る条件を探すことはしません
- 主の設定（$k$、刻みの格子、層別の規則、読む場所 2 つ）は、数値を出す前に README に登録します
- 合成の対照（3.4 節）が理論の値から外れたら、実装を疑って止めます

## 6. いまの JEPA の検証項目との関係（見立て）

ユーザーは「disentanglement が確かめられれば、検証項目をシンプルにできるかもしれない」と書きました。Fable さんと Codex さんの議論の結論は**この評価では減らせない**です。理由はこの評価では見張れない抜け道を、いまの項目が塞いでいるからです。

| いまの項目 | 見立て | 理由 |
| -- | -- | -- |
| K1・K2（定数・次元の崩壊） | 残す | 安く、学習の途中で要る。この評価でも、階数が足りない符号は採点できないので、健全さが採点の前提になる |
| K3（`token_r2`） | 残す | 合成の K3 は、`h_mean` の水準では主 1 で採点できてしまい、捕まらない |
| 自己同定（難しい候補の $A$、`pool`・`flat`・`interp` との差） | 残す | 測るものが違う。自己同定は「予測器が隠した所を補えるか」という JEPA の目的そのものを測る。この評価は予測器を使わず、エンコーダの空間の形を測る。VAE や画素には予測器が無いので、自己同定はモデルをまたげない。この評価は、そのモデルをまたぐ側を受け持つ |
| 移植と局所性（$a_U$・$a_V$・$L$） | 残す | 鏡の符号を捕まえられるのは移植だけ。局所性の高い符号では、カメラの動きがトークンの間の中身の移動になり、軌跡が画素と同じ形で曲がる。局所性が高く主 1 が悪い符号は、矛盾ではない |
| 自己同定の相方（スペクトル、`participation`、帯ごとの比） | 残す | 主 2 と役目が一部重なるが、主 2 も雑音で膨らむので代われない |
| V18 の `dyn_1/copy_1` | 置き換えられそう | 白色化なし・固定の 0.1 秒・次元が不ぞろいの量だった。白色化した線形の動力学か、主 1 に置き換える |
| `recon_blur`、Inception・Places365 の物差し | 既に主から外れている | 「モデルをまたいで `pca`・VAE・学習前と並べる」役目は、主 1・主 2 に移せる |
| 中点と外挿の両方の表示 | 片方に減らす | 同じ三つ組では、外挿の誤差は中点の誤差のちょうど 4 倍 |

この評価が役に立つのはむしろ V19 の未来予測です（Fable さんの設計の 7 節。批判の後も残った点）。等速の外挿 $2z_t - z_{t-\Delta}$ は、学習の要らない未来の予測で、空間のマスクでの `interp` にあたる対照になります。その誤差の下限 $G_{\mathrm{ext}} \ge 2s$ も、式で分かります。予測器がこの対照を上回った分が、線形でない予測の分です。ただし、回転のような線形の作用でも等速の外挿に勝てるので、学習した線形の予測器も対照に置きます（Codex さん）。

## 7. 言えることと言えないこと

### 7.1 Locatello ら（2019）の結果との関係

Locatello ら（ICML 2019）は、次のことを示しました（文献、要旨）。因子分解できる事前分布に対しては、同じ分布を保ったまま因子を混ぜる変換が無数にあります。そのため、観測の分布だけからは「因子に沿った符号」と「混ざった符号」を区別できません。等方なガウスでは回転がそのまま例になります。

このプロジェクトでは次の 3 つが関わります。

1. **JEPA の SIGReg は、符号を等方なガウスに寄せます。** 目的の値は回転で変わらないので、JEPA の符号の「どの軸がどの因子か」は原理的に決まりません（導いた）。VAE では対角の事後分布のおかげで軸が偶然そろいます（Rolinek ら 2019、文献、要旨）。軸ごとの指標で JEPA と VAE を比べると、目的の側の性質を測ってしまいます
2. **時間は識別のための追加の手がかりになります。** 文献では時間の隣り合う観測を使えば因子が識別できる場合があります（SlowVAE、iVAE、Klindt・LeCun・Balestriero 2026）。この提案の主 1 も時間を使います。ただし主 1 は、それを 2 次の統計に縮めてしまいます。そのため、チェビシェフ展開と独立な 64 因子を区別できません（2.3 節の 3）
3. **逆向きの反例もあります**（導いた、Codex さん）。独立な OU 過程の因子をそのまま返す、完全に軸で分かれた符号でも、$H@0.25 = 0.404$ と低くなります。つまり、時間の線形性が高いことは因子が分離している必要条件でも十分条件でもありません

### 7.2 言えること

- 「指定した刻みと計量で、自然な動画の中点（と等速の外挿）の相対誤差が、画素や他のモデルより小さい（大きい）」
- 「そのとき、離れた時刻での内在次元はこうだった」
- 2 つを並べて、「情報を捨てて真っすぐになった」形か、そうでないかの記述

### 7.3 言えないこと

- 因子が分かれていること（狭い意味の disentanglement）
- 任意の 2 つの場面を補間した点が意味を持つこと（正解がデータに無いため）
- 表現の良し悪しの順位。分類を学んだ CNN は、自然な動画の曲率を増やします。不変性で学ぶ自己教師ありの手法も、直線化しません（Hé naff 2019、Niu 2024、文献）。真っすぐでない良い表現はありえます
- 既存の run の差を、学習の目的の差のせいにすること（4.1 節）

### 7.4 V18c の JEPA についての注意

Klindt・LeCun・Balestriero（2026）の定理は「整合 + 等方なガウスの制約」の最小解が真の潜在の直交変換になることを示しました（文献、本文の前半を読んだ）。ただし、正の対は時間の遷移の対です。V18c は空間のマスクで学んでいるので、この定理は当てはまりません。V18c の JEPA が画素を上回らない結果も、十分ありえます。その場合は「JEPA は線形にしない」ではなく、「空間のマスクの目的は時間の線形性を作らない」と読みます。この 2026 年の論文は根拠にする前に本文を読み直します。

計算の見積もりの根拠は次のとおりです。自己同定の評価では 156 checkpoint を約 2.8 時間（4060 と 4090 の混成）で回しました。この評価は予測器も移植も使わないので、1 checkpoint あたりはそれより軽い見込みです。学習の時間は V16 の 1 本が 4090 で 73〜87 分、パッチ 8 の JEPA が 0.115 秒 / step（60000 step で約 2 時間）です。

## 9. ユーザーに決めてもらう点

1. **この評価の位置づけ**
   - 推奨: 「disentanglement の合否の指標」ではなく、「時間の線形性（中点の誤差の曲線）と、情報の幅（内在次元）を並べた記述」として進める。順位や合否には使わない
   - 理由: 2 人の合意として、1 つの数で VAE・JEPA を順位づける理論的な根拠は見つかっていません（2.3 節）。合否に使うと、過去 3 回と同じく、当てやすい側へ逃げた符号が良く見えます
2. **因子として認める入力の操作（狭い意味の disentanglement に踏み込むか）**
   - 推奨: まず時間だけで進める。平行移動（`wide` のデータの四つ組 $R_{a \to b}$）は、Q1 の結果が読めてから、記述として足すかを決める
   - 理由: 人のラベルを使わずに因子の分離を測るには、人が選んだ操作（平行移動・拡大など）を因子と認める必要があります。ラベルではなく入力への操作ですが、人が因子を選ぶことになります。平行移動の四つ組は Fable さんの見立てでは「細部を捨てた符号」と区別できません。使える動画も 3 本だけです
3. **比べる相手**
   - 推奨: 段階を踏む。(i) 手元の物差しと run（VAE 2 種、JEPA 4 系統、M、学習前）で記述する。(ii) 同じデータ・同じ ViT-S で、β-VAE と MAE を学び直す（手間が小さい）。(iii) 拡張や時間の view を使う手法は目的と物差しが重なるので後回しにする。公開モデルは参考にとどめ、DoRA は Zurich を学習に含むかを先に確かめる
   - 理由: 既存の run は、パッチの大きさ・学習の方法・見た量が違うので、差を目的のせいにできません（4.1 節）
4. **いつ進めるか**
   - 推奨: 設計の確定・実装・有効性の確かめを、今のうちに済ませる。V18c の既存の checkpoint には記述として当てる（GPU は 1〜2 時間）。本命の使い道は V19 の未来予測の対照（等速の外挿）にする
   - 理由: 空間のマスクで学んだ V18c には時間の線形性を作る理論がありません（7.4 節）。V19 ではこの評価が予測器の対照と直接つながります

このほかに、区別したい最小の差 $\Delta_*$ を、有効性の確かめ（V-d3）の後、モデルの値を見る前に決めてもらいます（5.2 節）。
