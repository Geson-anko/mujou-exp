対象は計画 [exp/vision/plans/jepa.md](../../../exp/vision/plans/jepa.md) の「線形の幅の内容のガード v3（2026-11-26、V19 の値を見る前）」の初稿と、[../guard-v3/design.md](../guard-v3/design.md)。skill `ask-codex` の手順で、読み取り専用（1 回目 `-e high`、2 回目 `-e medium`、thread `01a217cf-857a-7d53-8e1f-9a9173f19a2e`）。Codex さんはファイルを書き換えていない。v3 の値も V19 の値も、まだ計算していない。

確かさの区別: **確かめた** は Claude が式を追って確かめたもの、**Codex さんの意見** はそれ以外。

## 1 回目

結論（Codex さん）: 方向は妥当。ただし命題 1' の有限標本の上界が誤りで、V-h5a0 が v2 の 2 つの外れを同じ機序で再現する見込みにも疑問がある。

1. **ホールドアウトの $2\delta$ の不等式は正しいが、$\delta$ は候補全体の最大の偏差で、勝者と次点の標準誤差では抑えられない。「最小二乗から 2SE 以内」は劣化を検出できないときに通る。** → **採った**（V-h5a4・V-h5b4 を、$E_{\mathrm{sel}} - 2^{-\psi_*}E_{\mathrm{lin}}$ の下端による非劣性に替えた。標準誤差は記録にとどめると書いた）
2. **命題 1' の $\varepsilon_c$ は和集合の最良を基準にすべき。** 反例: 独立な $u, v, w \in \{\pm1\}$、$c = (u,v,w)$、$c' = (u,v)$、$y = uv + w/2$。$uv$ は線形の特徴と直交するので最小二乗は族の最良 $w/2$（誤差 1）に届き、族ごとの届かなさは 0。$c$ の MLP が $uv$ を学べず、$c'$ の MLP が学べば誤差は 1/4（**確かめた**: $\mathrm{Var}(y) = 1.25$、$E$ は $0.25/1.25 = 0.2$ から $1/1.25 = 0.8$）。→ **採った**
3. **閉じ方は `drop`（白色化した座標のマスク）と `rot` で成り立つ。差の線形の係数は $[B, -B]$ でノルム $\sqrt2\lVert B\rVert_F$、MLP の複製には幅 $2h$ が要る。** → **採った**（水準で選んだ読み出しの差そのものを変化の候補に入れた。ノルムの点を本文に書いた）
4. **Zurich への分布のずれだけで射影が有利になりうる**（訓練 $y = 2x + z/2$、評価 $y = 2x - z/2$ で、$E$ は 13/17 → 16/17。**確かめた**: 評価の分散 $4 + 1/4 = 17/4$、全符号の誤差 $(z/2 + z/2)^2 = z^2$ で 1、$2x$ の誤差 $z^2/4$ で 1/4）。可逆な並べ直しでも、逆写像を学べなければ「落とした」になる。`rot` は線形しか確かめない。→ **採った**（保証しないこと (vi)）
5. **2 つの量は条件つき平均しか見ない**（$y_t = (s_t, a_t u_t)$ の例）。→ **採った**（保証しないこと (vii)）
6. **隣の区間の依存が残る。** 中央の半分の最短距離は約 25.6 秒で、$\ell = 60$ 秒なら相関約 0.91。動画単位か長い連続区画を先に確保すべき。→ **一部採った**（検証の区間に 256 stack の間隔、距離との関係の記録、manifest。動画単位の分割は、訓練の 512 区間が全ての訓練の動画にまたがるので、訓練の組を引き直さずには作れず、ずるの族と幅の登録も変わるので採らなかった）
7. **V-h5a0 (ii) の再現は厳しい。** 陰性の真の差の予測の $E^d = 0.0876$ をゼロにするには、差の余分な誤差が 0.0099 要る。$n$ の偽の予測（分散 $q$、lag 1 の相関 $\rho$）の寄与は $2q(1-\rho)$ で、$q = 0.1034$ でも $\rho \le 0.952$ が要る。滑らかな場面の記憶は差で打ち消し合いうる（**確かめた**: $2 \times 0.1034 \times 0.048 = 0.0099$）。(i) も僅差で負けるだけでは区間の記憶を特定できない。→ **採った**（(i) に $n$ の座標の $E$ の符号を足し、差の機序は閉じた式の解析の対照 V-h5a0-d に分けた）
8. **ガウスの核の標準偏差 $b$ では自己相関 $\exp[-\Delta^2/(4b^2)]$ なので $b = \ell/\sqrt2$。** 較正の条件つき平均は $u_t$ の関数として書くべき。数値 0.49336・0.0023702 は正しい（Codex さんも同じ値）。ridge は差の向きの小さな固有値（0.0328）の係数を縮める（$\alpha = 0.01$ で約 0.766 倍）ので、選択の頻度を見るべき。→ **採った**
9. **V-h4 を受けた探索の作り直しとして正当。** V19 の前に SHA・区間の manifest・主の比べ・合否と止める条件を固定し、先回りの V-h5b も外れを含めて残す。→ **採った**
10. **判定を $E_a - 2^{-0.1}E_b$ の対の区間で行い、比は表示にする。** いまの `ratio_interval` は、$E_a$ の点推定が 0 以下だと、引き直しに正が多くあっても上端まで $-\infty$ にする（**確かめた**: `exp/lib/fidelity.py` の `ratio_interval` は `point = -inf` から `hi = point + 2 tot`）。→ **採った**

結論（Codex さん）: 差の式と $D$ の境界の同値は正しい。実行前に直したいのは 3 点。

1. V-h5a0-d の誤差の割合の式は正しい（約 6.86。全成分の $E^d$ は水準の差で約 −0.509、組の最良で約 +0.0060）。解析値と比べるのは組の**最小二乗**と書けば、選択の揺れを切り分けられる。→ **採った**
2. $D$ の同値は境界について成り立つ。V-h5b3 を $\psi$ の区間で読むと、別々に作った区間で合否が食い違いうるので、両向きの $D$ を正式な判定にする。→ **採った**
3. V-h5a4・b4 の「$E_{\mathrm{sel}} - 2^{-0.1}E_{\mathrm{lin}}$ の下端 > 0」は、$E_{\mathrm{lin}}$ が 0 に近いと、最小二乗そのものを選んでも構造的に落ちる。絶対の幅の余裕を事前に固定すべき。→ **採った**（余裕を、比べる相手の $\hat E_{\mathrm{lin}}(b)$ の尺度の $m = (1 - 2^{-\psi_*})\hat E_{\mathrm{lin}}(b)$ にした。理由: $a$ の届かなさは $D$ をそのままずらし、判定の余裕は $E$ の単位で $(1 - 2^{-\psi_*})E_b$ だから）
4. $2\delta$ の比べる先は「水準で選んだ読み出しの差」で、v2 の決まった MLP の差ではない。→ **採った**（文言を直した）
5. 動画単位の分割は、Zurich の中の checkpoint の比べに主張を限るなら必須ではない（Codex さんの意見）。→ 計画はその範囲に主張を限っている
