## 1. 論点ごとの指摘

### (a) 逃げ道を塞ぐか

- **同意（導いた）**: パッチの埋め込みはパッチごとで、`TokenEncoder` は attention の前に隠した位置を落とす。マスクごとに中心化すれば、位置とマスクだけで決まる加法の項は消える。完全な崩壊では `top1` = 0、$A$ = 0.5。複製の K3 では `flat` が `pred` と同じ順位を与える。移植で厳密に落とせるのは「外側を固定したとき $Q$ の画素に反応しない符号」である
- **反論 1（反例。導いた）**: 四半分ごとに粗い 2 次元の統計 $u_q$ を持たせ、自然な stack では $u_q = u_n$（全四半分で共通）とする。四半分の中で和が 0、対角の四半分どうしで逆符号の固定の符号 $s_p \in \{\pm 1\}$ を置き、$t_{p \in q} = s_p(\epsilon u_q + B u_{\mathrm{opp}(q)})$、予測 $\hat t_{n,p} = s_p(\epsilon + B) u_n$ とする。すると自然・移植の候補とも `pred` は `top1` = $A$ = 1、`pool` = `flat` = 0（$s_p$ の和が 0）、`swap` = 1。$a_U = \epsilon/(\epsilon + B)$、$a_V = B/[3(\epsilon + B)]$ で、$B = 0$ なら $L$ = 1、$\rho_V$ = 0 まで満たす。つまり**一般の $A_p u$ の族（$A_p = s_p I$）が、`flat`・`pool`・`swap`・局所性・移植のすべてを満点で通る**。全体を $\epsilon' \to 0$ 倍しても順位と $L$ は変わらない
- **反論 2（導いた）**: $t_Q = (K u_n, v_n)$、$\hat t_Q = (K u_n, 0)$ で各成分群のノルムが候補の間で一定なら、$v_n$ を一切当てずに $A$ = `top1` = 1。固定の $R$ でも $h = R^+ t + k$（$k \in \ker R$）なので、$h$ の側の尺度の偏りを排除できない
- **実装の指摘（確かめた）**: `JEPAModules.tokens` は `proj(encoder(...))` だが `fill_eval._context` は射影の前の $h$ を返す。`pool` は位置の軸を戻して `mods.proj` をかけてから平均する必要がある。また `S_1` = `Q_tl` ∪ `Q_br` で、tl と br は 180° 回転の対なので、鏡の符号の写し元も隠れる。V-s5 の `swap` = 1 は「注入した oracle の検査」と明記するか、見える領域に情報を持たせた形に直す
- **Claude の反論と、それへの返答**: $B = 0$ の符号では、予測器は符号が持つ情報を正しく補完している。これは逃げ道ではなく「空間が持つ情報が少ない」問題（Fable さんの残る弱点 1）で、反例 2 も「識別に足る成分が 1 つあれば満点」という同定そのものの性質だ、と返した。Codex さんは同意したうえで、反例が崩すのは「**同定が満点なら、隠した領域の多様な成分を補完できている**」という読みだ、とした
- **修正案（Codex さんの意見。理論の裏づけつき）**: 相方として (i) 中心化した本物のスペクトルと `participation`、(ii) **主成分の帯ごとの `pred_ratio`**（独立な参照の組で PCA の基底を固定し、採点の組で帯ごとの二乗誤差の和を本物の分散の和で割る。全体の `pred_ratio` はこの値の分散で重みをつけた平均なので、どの帯が全体を支えるかが分かる。分散の小さい成分は帯にまとめ、帯の分散も出す）を推す。(iii) 上位 $k$ 主成分を除いた補空間での同定にも根拠がある（上位 $k$ 主成分への射影は、ランク $k$ の直交射影の中で最も多くの分散を回収する。補空間での同定は「最も分散を担う $k$ 方向を使わずに候補を区別できるか」という別の問い）。基底と $k$ を採点の前に固定し、残る分散の割合と並べる。`participation` は 1 変数を直交する非線形の特徴に展開するだけで高くできるので単独では弱い。`token_r2` は単一トークンどうしの線形の冗長さで、複数の見えるトークンに分け持つ大域の符号には、見える領域全体を使う診断が別に要る

### (b) 移植と継ぎ目

- **同意（導いた）**: 全フレームをパッチの境界で切れば、各パッチの中の画素は保たれる。固定した $j$ について外側だけで決まる加法の項 $b(j)$ は、候補の中心化で消える
- **反論（反例。導いた）**: $t_Q(q, c) = b(c) + M(c) a(q)$ のように文脈と中身が掛け合わさると、中心化の後に $M(j)(a(q_m) - \bar a)$ が残る。さらに継ぎ目に反応する符号を作れる: 自然な画像では鏡の符号を返し、四半分の境界の不連続を見つけたときだけ、移植の中を $s_p[(1-\alpha) u_j + \alpha u_m]$、外を $s_p[(1-\beta) u_j + \beta u_m]$ にする。すると $a_U = \alpha$、$a_V = \beta$、$L = \alpha - \beta$。**自然な画像での振る舞いが同じでも、継ぎ目への反応だけで $(\alpha, \beta) = (1, 0)$ なら局所性も移植の同定も満点、$(-1, 0)$ なら $L = -1$・移植の $A$ = 0** になる。Fable さんの「継ぎ目の成分は候補の間で共通だから中心化で消える」は、加法の場合にしか成り立たない
- **修正案（Codex さんの意見）**: V18c では移植の同定と $L$ を記述に下げ、文脈 $j$ を「別の動画」と「同じ動画の近い時刻」の 2 種、両向き $x_{j \leftarrow m}$・$x_{m \leftarrow j}$、$j$ ごとの値を並べれば足りる。近い時刻の $j$ は候補の組ごとに固定し、$j = n \pm 2$ 秒は難しい候補に入るので、±1 秒にするか、±2 秒なら $j$ を全条件の候補から外す（そうしないと負例の 1 つだけが自分への移植になる）。自然な本物を問い合わせにして移植した候補を引く `oracle_tr` を並べる（`pred` が上回ることもあるので「天井」とは呼ばない）。内外の $\lVert \Delta \rVert^2$ と $\lVert \Delta_Q - \delta_Q \rVert^2$、継ぎ目の近くと内部を分けた値も出すと、内積に出ない変化を拾える
- **継ぎ目を減らす介入（Codex さんの意見）**: 境界の内側の 1 列を $j$ のまま残せば、元の $Q$ の境界の画素の差は厳密に 0 になる。新しい継ぎ目が 1 列内側にできるので、移植した内部だけを採点し、通常の移植との感度の差を見る。分布を保つ理論の上の介入は「固定した外側のもとでの $Q$ の真の条件つき分布から引く」ことで、近い時刻や境界合わせはその近似にすぎない。attention を通るトークンへの継ぎ目の効果の大きさは実測が要る（理論では決まらないと書くべき）

### (c) 比べてよい条件と中心化

- **同意（Codex さんの意見）**: 同じ凍結した的・候補・マスク・中心化のもとでの、予測器や対照どうしの比べは解釈できる。run・step ごとに的が変わる比べは「それぞれの課題での同定の推移」としてだけ読める。P16・F・V18c で四半分を 256 次元にそろえても、幾何や難しさはそろわない
- **反論 1（反例。確かめた）**: 格子の候補 $(\pm1, 0), (0, \pm1)$、問い合わせ $(1,0), (0,1)$ の 2 個で完全な予測でも、格子の平均は 0、予測の平均は $(1/2, 1/2)$ なので、別々に引くと (`top1`, $A$) が (1, 1) から (0, 5/6) に落ちる。別々の中心化は、問い合わせの組の作り方で値を変える
- **反論 2（反例。確かめた）**: 全候補に共通の成分でも cos の順位は変わる。$e = (1, 0)$、候補 $(1,0)$・$(2,1)$ では第 1 候補が勝つが、両方に $c = (0, -1)$ を足すと cos が $1/\sqrt2$・1 になり逆転する。難しい候補で Zurich の動画に固有の平均が残ると、順位に効く
- **修正案（Codex さんの意見）**: 予測と本物の平均は、独立な参照の stack の組（Zurich でない学習の動画）から段・マスク別に推定して固定する。難しい候補では、その問い合わせの候補 33 個の平均で本物を中心化する版を副として並べてよい（全候補に同じ操作で、正解のラベルは使わない。$r_i - \bar r = \frac{32}{33}(r_i - \bar r_{-i})$ なので、cos では自分を除く平均を引くのと同じ。ただし時間の窓を共有する信号も消える）。問い合わせの側の中心化は固定のまま。候補どうしの cos の分布を遅れ別に、引き分けの近さ・勝ち負けの余裕・分散・`participation`・V-s6 の雑音の量を座標の RMS との比で並べる（難しさの違いの診断）。run をまたいで同じ補完の優劣を言うには、凍結した共通の的での比べも要る

### (d) 有効性の確かめ

- **同意（導いた）**: V-s6 は、候補を固定し、中心化した $r_n$ に独立なガウスの雑音を足して中心化し直さないなら厳密（勝ち負けの差は平均 $r_n^\top d_{nm}$、分散 $\sigma^2 \lVert d_{nm} \rVert^2$ の正規分布。問い合わせの cos の正規化は正の共通因子で順位に効かない。$d_{nm} = 0$ は 0.5 として別に扱う）。中心化し直すなら信号から問い合わせの平均が引かれ、雑音の分散に $1 - 1/N$ がかかる。乱数の SE は候補の対を独立とせず、雑音の反復から求める
- **反論（Codex さんの意見）**: V-s0〜V-s6 は実装の正しさの確かめで、物差しの解像度は確かめない。V-s6 は候補の向きが区別できれば $\sigma$ の調整でいつでも通り、実際の `pred` の付近に解像度があることを示さない。旧 E1′ も実装の確かめは通り、`e1f` は全入力で 0.015 以下だった。V-s1 の `oracle` も、別のベクトルが正規化の後に同じ向きなら引き分ける。V-s2 の「大きな定数を足してもビットまで一致」は浮動小数点で丸めが出るので、厳密に表せる合成の例に限る
- **修正案と、Claude の反論への返答**: 予測を確率 $q$ で陽性対照に置き換え、差 $q[A(o) - A(\mathrm{pred})]$ を回収する検査を最初に提案した。Claude が「期待値が線形なので、実質はブロックのブートストラップの SE と $\Delta_*$ の比べだ」と返すと、Codex さんは **V18c では省いてよい** とした（足すのは注入した依存構造での検出率・被覆率の確認だけで、実際の checkpoint の差の構造を模さない限り上積みは小さい）。V19 では、比べたい 2 条件の**対の差**の区間幅を $\Delta_*$ と比べ、動画・seed の間の揺れと、得点の床・天井への張り付きを合わせて見る（SE が小さくても両条件が同じ床にいれば解像度は無い）。陽性対照を置くなら、`oracle` より「同じ凍結した的・同じ採点の領域を、少し多くの見える文脈から予測する条件」が実用の域に近い（差の向きと幅は実測）
- **Fable さんの問い (4)**: 主は難しい候補の $A$、`top1` は副。33 候補でいつも 1 個だけ正解より上なら $A = 31/32$ でも `top1` = 0 なので、両方に情報がある

## 2. Claude の見立て（Codex さんとの議論の後）

- 同意する点: `pool` の射影の抜け（実装の誤りになる）、V-s5 の `swap` の注記、継ぎ目の掛け算の反例による移植の量の記述への格下げ、中心化を独立な参照から固定すること、主を $A$ にすること、V-s0〜V-s6 を「実装の確かめ」と呼び分けて解像度の主張に使わないこと
- 反論して決着した点: $s_p$ の反例と $(K u_n, v_n)$ の例は逃げ道ではなく「空間の情報が少ない」・「同定は識別に足る成分 1 つで満点」という性質で、同定の満点を「多様な成分を補完した」と読まないための注意（Codex さんも同意）。相方は帯ごとの `pred_ratio` とスペクトル（と、固定した $k$ の補空間での同定）
- 未決（ユーザーの判断が要る）: V19 の主を「移植した難しい候補の $A$ の `pred` − `flat`」にするか。Codex さんは単独の主に反対で、帯ごとの `pred_ratio`・凍結した共通の的での比べと組にする条件を出した。$\Delta_*$ はどちらにしても V19 でユーザーと決める
