## 0. 結論

**2 つを並べる方針には同意。ただし提案書 3.3 節の「2 つの量は互いのずるい当て方を塞ぐ」は偽なので削る。** 真の内在次元が 1 の符号が、中点の誤差では定常の下限にほぼ一致し、TwoNN では 64 因子の符号と同じ程度の値になる（確かめた）。第 3 の量を足すのではなく、TwoNN を「指定した距離・標本・尺度で見える局所の次元」と言い直し、2 つは「別々の失敗の形を観察する」記述と書く。

## 1. 論点ごとの指摘

### 1.1 (a) 2 つを同時にすり抜ける符号

母共分散 $I_{64}$ のチェビシェフ展開 $z_j = \sqrt2\cos(j\theta)$ で、位相を独立に $N = 490$ 点引いたときの値（Codex さんの数値、8 回の平均。Claude も下の 3 行を 1 回の draw で再現した）。

| 周波数の選び方 | $s = 0.25$ での $G_{\mathrm{mid}} - s/2$ | TwoNN の $\hat d$ | Claude の再現 |
| -- | --: | --: | -- |
| 連続 64 本、$m = 1$ | 0.0915 | 1.04 | 1.06 |
| 連続 64 本、$m = 100$ | 0.00873 | 1.20 | — |
| 連続 64 本、$m = 1000$ | 0.000147 | 2.07 | 2.16（$N = 2000$ で 2.03） |
| $10^8$ から幅 $10^6$ の帯に散らした整数 64 本 | 0.00000308 | 34.98 | 35.3・35.1・33.3 |
| 独立な 64 位相（比べる相手） | 周波数が同じなら 1 因子版と同じ | 34.80 | — |

- **Claude の最初の懸念は半分外れた（確かめた）**: 「連続帯の $m = 1000$ は曲線が長すぎて TwoNN に分解できず、64 に近い値が出る」と予想したが、実際は約 2。連続帯は $z_j = \sqrt2\cos(m\theta + (j - m)\theta)$ と書け、局所の巻きを分解できない尺度では「搬送波の位相」と「包絡の位相」の 2 変数に見える（導いた、Codex さん）。曲線の全長だけでは TwoNN は決まらない
- **ただし疎な帯ですり抜ける（確かめた）**: 帯の中に周波数を疎に散らすと、真の次元は 1 のまま、下限との差は $3\times10^{-6}$、$\hat d \approx 35$（64 因子と同じ）。連続帯でも、下限との差は狭帯域近似で $\mathrm{Var}(j)/\bar j^2$ に比例し（導いた）、TwoNN の値とは別に決まる
- **規則格子の標本は不安定（確かめた）**: 連続帯 $m = 1000$ を 8 秒の規則格子で採ると、初期位相や $\omega$ で $\hat d$ が 1.9〜123（Codex さん）、1.9〜38.8（Claude）と飛ぶ。$r_1$ と $r_2$ がそろって、周囲の次元 64 さえ超えうる
- **雑音**: 連続帯 $m = 1000$ に独立な白い雑音を足すと、$\hat d$ も下限との差も増える（Codex さん: σ = 0.05 で 2.07 → 2.27、差 0.000147 → 0.00545。Claude: ε = 0.1・0.3・1.0 で 2.66・4.39・16.2）。白い雑音は中点の誤差にも出るが、**時間に滑らかな狭帯域の雑音**なら、中点の誤差を下限の近くに保ったまま局所の次元を増やせる（導いた、Codex さん）
- **位置だけの符号（導いた）**: 厳密な白色化では、$z_t = p + \eta g_t$ の固定の位置の項 $p$ と小さい倍率 $\eta > 0$ が消え、2 つの値は $g_t$ のものと同じになる
- **K3（導いた）**: $t_p = g(x)$ は `h_mean` で厳密に $g(x)$ になる。`self_eval._k3`（平均を全位置に複製する対照）は、`h_mean` で 2 つの値が「変わらない」ことを確かめる対照として使える。K3 を捕まえるのはこの評価ではなく、いまの `token_r2`

### 1.2 (b) TwoNN の偏りと測る空間

- **有限標本の負の偏り（確かめた）**: $N = 490$ の等方ガウスで、真の $d = 4, 8, 16, 32, 64$ に対し Codex さん 4.2・7.6・13.4・22.9・35.9、Claude 3.98・8.70・13.73・22.01・33.01。同じ周辺分布の 64 次元でも、標本の間の AR(1) の相関を 0.9 にすると約 10（Codex さん）。偏りは標本数・分布・時間の相関にまたがるので、**一律の補正の係数は入れない**（Codex さんの意見、Claude も同意）
- **報告のしかた（Codex さんの意見）**: Zurich の同じ時刻の集合を全ての符号で使う。8 秒以上の間隔を保った複数の間引きで、$\hat d$ を $N$ と $r_2$ の尺度に対して示す（Facco ら 2017 の間引きの曲線）。近傍に同じクリップが占める割合と、短い時間差の近傍を除いたときの変化も出す。別の都市は都市ごとに示し、混ぜて $N$ を増やした結果は別の母集団として読む。上位 10% を捨てる割合を固定し、捨てない値は感度に回す。完全な重複の扱い・ほぼ重複の距離の床・$r_2/r_1 \simeq 1$ の割合を先に決める。定数の符号は幾何では 0 次元だが TwoNN は定義されない。復元抽出は同じ点を複製してゼロ距離を作るので、揺れは重複なしのブロックの部分標本で出す
- **測る空間（1 回目と 2 回目で Codex さんの推奨が変わった）**:
  - 1 回目: 主を $G_{\mathrm{mid}}$ と同じ「PCA64・白色化の後」、白色化の前を感度に
  - Claude の反論（確かめた）: 8 次元の信号に 56 方向の標準偏差 $10^{-3}$ の雑音を足した符号は、白色化の前 7.36、後 33.66。分散が $i^{-1.5}$ で減る 64 次元ガウスは、前 18.71、後 32.58。白色化の後で測ると、小さい雑音の方向がそのまま次元に数えられ、主 2 のずるい当て方（雑音で膨らむ）を強める
  - 2 回目（合意）: **主は「PCA64・白色化の前」、白色化の後は感度。** 白色化の前は VAE の異方性や低分散の有用な信号も値に効くので、「観測の尺度での局所の次元」と呼ぶ。白色化の後には eps と末尾の固有値を添え、前後の差が大きければ「計量に依存する」と読む
  - 横軸の尺度は前後とも $\mathrm{median}(r_2)/\sqrt{2\,\mathrm{tr}\,C_{\mathrm{eval}}}$（無作為な 2 点の間の RMS 距離に対する近傍の半径）。$C_{\mathrm{eval}}$ は各計量で、間引く前の同じ固定の評価の集合から求める。比べには同じ間引きの標本を使い、$N$ を添える
- **白色化の正則化（導いた、Codex さん）**: 白色化の後の各方向の分散は $\lambda/(\lambda + \epsilon)$ なので、VAE の不活性な次元や小さい雑音は $\epsilon$ しだいで効く（`exp/lib/linear_dyn.py` の正則化と同じ形）。参照の末尾の固有値・残る分散・評価側の分散を記録する。真のランクが足りない・数値的に識別できない方向がある符号は、共通の $k$ の欄を欠測にする。**符号ごとに黙って $k$ を下げない**（比べの条件が変わる）

### 1.3 (c) 有効性の確かめの直し

- **V-d0（Codex さんの意見、Claude も同意）**: 「TwoNN が真の次元を回収する」を有限標本での合否にしない（1.2 節の偏りで外れる）。既知の距離を持つ点の集合で、近傍・同じ距離・重複・上位を捨てる処理を検査する。低い周波数の 1 因子は回収の試験、高い周波数・疎な帯・雑音つきは「失敗の形」の対照として値を記録するだけにする。$m$・$N$・時刻の格子・位相の取り方・乱数 seed を事前に登録する（外れたときに $m$ を変えて通すのは規約違反になるので）
- **並べ替え（導いた）**: 有限の集合を非復元で並べ替えると $E[s] = N/(N - 1)$。V-d0d に $s = 1$ の厳密な一致を求めない
- **V-d0g**: 類推の量は延期した平行移動の側の話なので、今回の合否から外してよい（Codex さんの意見）
- **V-d1・V-d3（導いた、Codex さん）**: $s/2$ は**定常のときの**参照の線。単調なドリフト $z_t = t$ は $s > 0$・$G_{\mathrm{mid}} = 0$ で線を下回り、負の自己相関があれば定常でも $s > 1$ になる。$V$ は固定した白色化で測った評価側の分散とし、カットをまたぐ層などで線から外れても実装の失敗とはみなさない。刻みと層ごとに三つ組の数と寄与するブロックの数を出す。参照の半分・$k$・$\epsilon$ での順位の入れ替わりは感度として報告する
- **ブートストラップの実装（確かめた）**: `exp/lib/metrics.py` の `block_bootstrap` は全符号に共通の分母 `v` を仮定している。$G_{\mathrm{mid}}$ は符号ごとに分母 $\bar D$ が違うので、符号ごとの分子・分母のブロック和を、同じ抽出で引き直す形に足す必要がある
- **V-d2 の作り方（Codex さん、Claude が手で導き直して一致）**: 固定した白色化の座標で、`pca` に総分散 $\nu V$ の独立な白い雑音を足す。共通の刻みで
  $$G_\nu = \frac{sG + \tfrac34\nu}{s + \nu}$$
  なので、目標の差 $\delta$ には $\nu = \delta s / (\tfrac34 - G - \delta)$ を選ぶ（$\delta < \tfrac34 - G$ の範囲だけ）。複数の $\delta$ を事前に用意し、同じ三つ組・同じブロックの抽出で対の差と区間を回収する。TwoNN の側は、同じ $N$・時間の相関・計量で、既知の次元を変えた合成の対の有限標本での分かれ方を校正する。解像度が足りなかった量・刻みは差の判定を保留し、独立に確かめられた記述は残す

### 1.4 (d) Δ\* を決めるときの材料と「区別できた」の規則

- **示す材料（Codex さんの意見）**: モデルの値を開く前に、物差し（`pca`・学習前・8 枚の平均）の対の差の区間の幅（刻みごと）、V-d2 で注入した既知の効果の回収率、参照の半分・$k$・$\epsilon$ での揺れの幅。**V18c の seed の間の差は学習済みのモデルの値なので、開封の後の再現性の確認に使う**（Δ\* の材料には入れない。提案書 5.2 節の「seed の間の差を見てから」を直す）。対照どうしの理論の間隔（3/4・1/2・$s/2$）は目盛りの説明に使い、実用上どれだけの差が要るかは別に決める
- **Δ\* の分け方**: $G_{\mathrm{mid}}$ と $\hat d$ で別の Δ\* を決める。曲線は事前に指定した共通の刻みで比べ、曲線全体について言うなら同時区間を使う。同じ $s$ での比べは、両方が届く枝を事前に指定する
- **言葉づかいの規則（Codex さんの案）**:
  - 「実用上の差を区別できた」: 対の差の区間が、同じ向きに $\Delta_*$ を丸ごと超えたときだけ
  - 「実用上の差は小さい」: 区間全体が $[-\Delta_*, \Delta_*]$ の中
  - 「解像度が足りない」: それ以外
  - V-d2 で真の差がちょうど $\Delta_*$ のとき求めるのは、差の回収と 0 からの分離まで。「区間全体が $\Delta_*$ を超える」かの検証には、それより大きな注入の効果を使う
