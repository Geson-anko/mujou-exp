## 結論（Codex さん）

いまの登録のままでは、V19 で「速い内容を保って線形の幅が広がった」とは確証できない。大きな穴は 3 つ。刻みごとに採点する時刻の集合が変わること。ガードが、幅を測った部分空間と刻みを検査していないこと。V-h0 の回転のオラクルが、登録した窓の規則と矛盾すること。

## 指摘と扱い

計画の表の番号 C1〜C25 で書く。

### (a) 幅の定義と推定

- **致命的: 中央値の解釈には、全ての刻みで同じ時刻の集合が要る**。V18c の `in` は 0.8 秒で 36926 個、25.6 秒で 14097 個（**確かめた**: README の組の節）。各時刻の勝ち負けが単調でも、入れ替わりだけで $p$ が上がりうる。勝つ刻みが飛び飛びなら、$\int p = E\lvert A_t \rvert$ は成り立つが、中央値の解釈は崩れる。→ **採った**（C1。共通の中心を主にし、刻みごとの `in` は感度に回す。生き残りの曲線を記述に足す）
- **重要: 空の窓・U 字・2 つの窓**。全域で $p = 0.49$ なら窓は無いが、$\bar\Delta$ = 12.952 秒になる（**確かめた**: $0.8 + 0.49 \times 24.8$）。窓が無いときを 0.8 秒と数えると、上端 1.15 秒の窓が出ただけで 0.524 オクターブの差になる。両方とも窓が無ければ比は 0 になる。6.4 秒より先は格子が 1 オクターブ間隔で、0.5 オクターブを分けられない。→ **採った**（C4 の 0.1 秒おきの格子、C6 の $\Delta_{\mathrm{typ}}$ の比の条件）。**採らなかった**: 主の量を $\int p$ だけにする案（ユーザーの決定 1 が両方を読むと決めている。V19 の主の比べを $\bar\Delta$ にして受けた）
- **重要: 重なり・比・白色化**。勝ち負けは割り算をせずに $q\delta_t - \nu_t > 0$ で判定する。動かない三つ組を除くと、止まった場面で固めるだけで勝率が上がる。区間は参照を固定した条件つきである。→ **採った**（C3・C5）。参照の引き直しは**採らなかった**（「条件つき」と書くことで受けた）
- **重要: 窓の端の percentile 区間は不連続**。同時の帯で窓を挟む案。→ **採らなかった**。主の比べを積分の $\bar\Delta$ にしたので、窓の端の不連続さは主の判定に入らない。$\Delta_{\mathrm{typ}}$ は C6 の条件で受けた。ブロックの起点をずらした感度は採った（C5）

### (b) 幅を稼ぐ表現

- **致命的: 崩壊の指標と時刻の同定の両方を通っても、速い内容は落とせる**。Inception が遅い背景 $S_t$ で候補を分け、符号が $S_t$ だけを持ち、デコーダが速い物体 $F_t$ をそれらしく描けば、$c = e = 1$・$f = 0$ でも $F_t$ は失われる。1 つの位相の高調波は共分散をフルランクにできる（V18c の `cheb_c` の TwoNN は約 35。**確かめた**: README）。→ **言葉づかいで採った**（C15。ガードを通っても「速い内容を捨てていない」とは書かない）。背景をそろえ速い物体だけを変えた候補を作る案は**採らなかった**（Walking Tours では自然に作れない。別の設計としてユーザーに残す）。局所の特徴（2×2）の版を記録に足した（C11）
- **重要: PCA64 の主張はその計量に限る。再帰なら、入力の差し替えと状態の初期化を対にする**。→ **採った**（C24・C25）

### (c) 拡散のガード

- **致命的: ガードを、幅を測った刻みと座標に合わせる**。$\bar\Delta$ は積分なので、それ以下の最大のガードの刻みが勝つ窓に入る理由は無い。既存のデコーダは全次元の符号を条件にするので、PCA64 が落とした方向で当てられる。候補の範囲 $9\Delta$ は 25.6 秒で 230.4 秒になり、128 秒のブロックに入らない。→ **採った**（C8 の PCA64 の条件、C13 の「潜在で勝つ全てのガードの刻み」）。候補の間隔を刻みから切り離して 25.6 秒まで伸ばす案は**採らなかった**（床の copy の絵の的が候補から外れ、天井と床の対が崩れる。6.4 秒より先は「ガードの範囲外」と書く）
- **重要: 1/9 は交換可能性の裏づけが無い。2 seed の差の最大は揺れの上限にならない。負けを言うには上端が 0 を下回る必要がある**。→ **採った**（C9 の同じ場面の中での入れ替え、C12 の $\sigma_{\mathrm{dec}}$（3 seed）と錨の揺れの分散の和、C13 の「保留」）
- **重要: 外挿は分布の外に出る**（$E\lVert 2w_t - w_{t-\Delta} \rVert^2 = V(1 + 4s)$）。「特徴の平均は必ず中央に近い」は誤り。→ **採った**（C10 の陽性の対照、C14 の理由の書き直し）

### (d) 有効性の確かめ

- **致命的: V-h0b・c・f のオラクル**。周期 12.3 秒の回転は 12.8・25.6 秒で三つ組の $G$ が約 0.016・0.064 で、また勝つ（**確かめた**: $\sin^2(\pi \cdot 12.8/12.3) = 0.0162$、$\sin^2(\pi \cdot 25.6/12.3) = 0.0638$）。「最も長い区間」の規則ではこちらが窓に選ばれる。ランダムウォークは境 1/2 で、母集団の $p$ がちょうど 1/2。→ **採った**（C2 の最初の窓、V-h0b・c のオラクルの書き直し、C16）
- **重要: 恒等式と逆順は、共通の添字のずれを通す。白色化の漏れを捕まえる確かめが無い。確証の解像度を既知の差で確かめていない**。→ **採った**（C17 の V-h0i の拡張と V-h0k、C18 の V-h0l・V-h0m）。V-h0k の閾値は二項分布から導いた（**確かめた**: $B(200, 0.025)$ の 99.9% 点は 13、$B(200, 0.95)$ で 180 回未満の確率は 0.0012）
- **致命的: V-h2 は、ガードが何も読めなくても通る**。2 倍（1 オクターブ）は、主張できる 0.5〜1 オクターブの見かけの改善を試していない。中心の箱形の平均は未来の入力を使う。方向を Zurich の偶数番で選ぶと評価に漏れる。256 区間 × 256 stack = 65536 で 131072 にならない（**確かめた**）。→ **採った**（C19・C20・C21）。情報を保ったまま幅を広げる陽性の対照は、白色化した PCA64 の上では作れない（可逆な線形変換は白色化で消える）ので、「正しい改善を通す」側は V-h3 の天井と床でしか示さない、と書いた

### (e) V19 の確証

- **致命的: 主の比べを 1 つにする**。同じ batch・FIFO・更新の数・入力の集合で順序だけを変えた腕との比べが、いちばん混ざりものが少ない。ほかの相手は族を固定して多重比較を扱う。→ **採った**（C23。V19 の計画にもともとある順序の対照の腕。副の族は Bonferroni）
- **重要: 動画の中の精度、学習の再現性、未知の動画への一般化を分ける。開封の前に seed・束ね方・step・初期化・欠け・止める規則・ハッシュを固定する。$\Delta_*$ は $G$ の傾きからは導けない**。→ **採った**（C22・C24・C7）。未知の動画を取り分ける設計は V19 の計画に回した
