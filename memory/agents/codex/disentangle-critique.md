# Fable さんの「潜在空間の線形性を同じ目盛りに載せる評価」への、Codex さんの批判（2026-11-25）

対象は [../fable/disentangle.md](../fable/disentangle.md)（白色化した符号の時間の構造関数 $D(\Delta)$ の伸び $H@q$、刻み合わせ $\Delta_q$、平行移動の $H_{\mathrm{tr}}$、有効性の確かめ V-d0〜V-d3）。あわせて [../disentangle/literature.md](../disentangle/literature.md) と [../disentangle/inventory.md](../disentangle/inventory.md) を渡した。skill `ask-codex` の手順で、読み取り専用（`-e xhigh` で 1 回、反論を返して `-e high` で 1 回）。thread `01a212bc-5d86-73f1-8daa-b344c3f70ce5`。Codex さんはファイルを書き換えていない。コード・README・plans は触っていない。GPU は使っていない。

聞いたこと: (a) $H@q$ が disentanglement や「意味のある線形性」ではなく、滑らかさ・低次元への潰れ・時間の近さ・位置・尺度を測っていないか、(b) 崩壊・画素・K3 などのずるい符号が良い値を取れないか、(c) JEPA・VAE・他の手法を公平に比べる条件、(d) Locatello ら（2019）の不可能性との関係、(e) 過去 3 回の外部の物差しの失敗と同じ轍を踏まないか、(f) Fable さんの §11.5 の問い、(g) 時間の直線化以外の候補。

確かさの区別: **確かめた** は Claude が手計算か数値計算で追ったもの、**導いた** は定義から論理で出したもの（Claude も追った）、**Codex さんの意見** はそれ以外。実動画・checkpoint での値は、誰も 1 つも測っていない。

## 0. 結論

**$H@q$ は「時間についての線形性（中点と等速外挿が効くか）」の診断として採る。disentanglement の主の指標にはしない。いまの JEPA の検証項目（K1〜K3・局所性・自己同定）を減らす根拠にもならない。** 理由は次の 3 つ（いずれも確かめた）。

1. 1 つの大域の量だけから作った 64 次元の符号が、$H@0.25$ の理論上の上限（0.9037）までほぼ届く。しかも、独立な 64 因子の符号と、全てのラグの 2 次の統計が一致する。$D$ をどう使っても両者は区別できない（1.2 節）
2. 刻み合わせは、全体が 1 つの倍率で伸び縮みする場合の時間尺度しか消さない。方向ごとに時間尺度が違う符号では、情報を足すと値が下がり、捨てると上がる（1.1 節）
3. $q = 0.25$ での $H@q$ の上限は 1 ではなく 0.9037。画素が 0.85 なら、上回る余地は約 0.05 しかない（1.4 節）

ユーザーへは「disentanglement を測った」ではなく、「自然な動画の軌跡に沿った、時間の中点・等速外挿の診断」と言う（Codex さん・Claude とも同意）。

## 1. 論点ごとの指摘

### 1.1 (a) 刻み合わせの抜け道: 尺度の混合

- **同意（導いた）**: 固定した計量で、前半と後半の増分の二乗平均が等しいなら、Fable さんの表の換算（曲率の cos・中点・外挿・加法性の欠けが $H$ の 1 対 1 の関数）は正しい。定常なら $s(\Delta) = D(\Delta)/(2V) = 1 - \bar\rho(\Delta)$ で、$H$ は 2 つのラグでの 2 次の統計である。増分の大きい三つ組ほど強く効くので、Hénaff らの角度の平均からは直接換算できない
- **反論 1（Codex さん、導いた。Claude も追った）**: 白色化した分散のうち割合 $p$ の帯だけが振動し、残りが静止しているとき、$s(\Delta) = p(1 - \cos\omega\Delta)$。同じ振動で $p = 1, 0.5, 0.25$ のとき $H@0.25 = 0.904, 0.792, 0.500$ になり、$p < 0.125$ では $q$ に届かない。動く部分の割合（カット・静止・移動のどれに反応するか）で値が変わる
- **反論 2（Codex さん、導いた）**: 率 $\lambda$ のカットで独立な場面の値に入れ替わるだけの符号は、$s = 1 - e^{-\lambda\Delta}$ で $H@0.25 = 0.404$（OU と同じ値）
- **反論 3（Claude、数値計算で確かめた。Codex さんも再計算で一致）**: 白色化した方向の半分が OU（$\rho = e^{-\tau}$）、半分が滑らかな山（$\rho = e^{-\tau^2/2s^2}$）の混合では、$H@0.25$ は $s = 1, 3, 10, 30$ で 0.504・0.353・0.299・0.293。$s \to \infty$ では滑らかな帯が交差点でほぼ静止し、OU の帯だけで $1 - e^{-\Delta} = 0.5$ に達する必要があるので $\Delta_q \to \ln 2$、$H \to \tfrac12\log_2 1.5 = 0.2925$。**純粋な OU（0.404）にも純粋な滑らかな山（0.725）にも負ける。** 独立な情報（遅くて滑らかな成分）を足すと値が下がり、速い成分を捨てると 0.725 に上がる。Fable さんの「遅くするだけでは値は上がらない」（§3.3）は、全方向が 1 つの尺度で伸び縮みする場合にしか成り立たない
- **修正案（Codex さんの意見）**: 主に読むのは、全ての符号に共通の物理ラグでの $s(\Delta)$ の曲線と、外挿の誤差と copy の誤差の比にする。$H@q$・$\Delta_q$ は副に並べる。固定ラグでは全ての符号に同じ中心時刻の三つ組を使い、カットの内側と、カットをまたぐ三つ組、動きの大小を入力の側の共通の規則で層別する。$q$ に届かない割合・最短ラグで既に超える割合・交差が不安定な割合も出す。V-d0e（2 倍に遅くしても $H@q$ が一致）は、交差点が格子に乗る合成の例を使うか、補間の誤差を含めて検査する

### 1.2 (b)(f) 1 つの量の展開、崩壊、白色化

- **反論（Codex さん、導いた。Claude も追った）**: $\theta_t = \Theta + \omega t$（$\Theta \sim U[0, 2\pi)$）とし、画面全体から読める 1 つの量 $y_t = \cos\theta_t$ だけを使う。$z_j(t) = \sqrt2\,T_j(y_t) = \sqrt2\cos(j\theta_t)$（$T_j$ はチェビシェフ多項式、$j = m, \dots, m+63$）とすると、共分散は $I_{64}$、内在次元は 1。$m = 1000$ で $H@0.25 \simeq 0.90356$（上限 0.9037 の手前）。しかも、各成分の位相をクリップごとに独立に引いた「64 因子」の符号と、全てのラグの共分散が一致する。**$q$ や $k$ を変えても、$D$ ではこの 2 つを区別できない。** Fable さんの §8 の 1（多項式で広げた符号）を、上限まで届く形にしたもの
- **同意と反論（Codex さん、コードから）**: 固定の座標だけの符号と厳密な K1 は時間の差が 0 で、採点できない。一方、$t_p = g(x)$ を全ての位置に複製した K3 でも、$g$ の共分散のランクが十分なら高い値を取れる。V18c の射影の後で厳密に複製すればランクは最大 16 で $k = 64$ では採点できないが、`h_mean` や V18b M の 64 次元のトークンには、この防壁が無い
- **白色化の副作用（Codex さん、導いた）**: $z = (g, \epsilon n)$ の独立で小さい成分も、厳密な白色化で単位の分散に持ち上がる。$n$ が白い雑音なら値を下げ、滑らかな成分なら上げうる
- **時間の重なり（Codex さん、導いた）**: 白い入力を 8 フレームで移動平均しただけで $s(d) = \min(d/8, 1)$、$\Delta_{0.25} = 0.2$ 秒、$H = 0.5$（ランダムウォークと同じ値）。いまの `color` はフレームごとの空間の平均なので、この 8 枚の時間の平均は別の対照として作れる
- **修正案（Codex さんの意見）**: K1〜K3 と位置ごとの介入の検査は残す。対照に、無加工の画素、8 枚の平均、時間で重みをつけた画素、合成の K3、上の 1 つの量の展開、OU の混合を入れる。共通ラグの比べには、重ならない $\Delta \ge 0.8$ 秒を使う。情報の幅を見たいなら、離れた時刻・別のクリップでの多尺度の内在次元と、独立な介入が動かす方向の数を並べる（前者は雑音で膨らみ、後者が保証するのは選んだ介入の範囲だけ）

### 1.3 (c) 公平な比べと実装

- **同意と反論（Codex さん、コードから）**: 全次元・正則化なし・フルランクの白色化なら、可逆なアフィン変換に厳密に不変。ところが上位 $k$ の PCA を先にかけると、速い方向だけを定数倍して上位に入れるだけで値が変わる。V-d0b が確かめるのは射影の後の不変性にすぎない。`pca` の実効ランク 52.4 は代数的なランクの上限ではないが、$k = 64$ の下位の方向を信用できる根拠にもならない。`lin_k` は固定ラグ・画素の PCA の中で選んだ基準線で、$H@q$ の天井と読む根拠はない
- **修正案（Codex さんの意見）**: 各モデルの自分の潜在（`mu`・`z`）と、共通の `h_mean` を別々に比べる。位置ごとの符号は、共通の粗い格子でプールした版と、移動に合わせて対応する位置をそろえた版を分けて読む。$k$ ごとに、残る分散の割合・末尾の固有値・正則化への感度を出す。既存の run の比べは記述にとどめる。学習の目的の効果を言うなら、入力・パッチ幅・学習データ・計算の予算・checkpoint の選び方をそろえて学び直す。時間の対の整合を損失に持つ手法は、学習のラグの $D(\Delta)$ に直接かかわる（$D(2\Delta)/D(\Delta)$ はそれだけでは決まらない）。学習に使ったラグと使っていないラグを明記する
- **実装の指摘（Codex さん、コードから。`exp/lib/linear_dyn.py`）**: `copyw_h` は horizon ごとに的の分散で割るので、2 つの値をそのまま割ると分散の比が混ざる。共通の白色化と $V$ を固定して $D$ を直接集計する方が簡単。`dynw_h` は採点のときだけ白色化し、ridge の当てはめは元の座標で行うので、アフィン不変が要るなら白色化してから当てはめる。未来予測で固定係数 $(2, -1)$ の外挿に勝っても、回転のような線形の作用で説明できるので、学習した線形の予測器も対照に置く

### 1.4 (e)(f) 有効性の確かめと解像度

- **反論（Codex さん、導いた。Claude も追った）**: 定常なら、スペクトルの測度についての Jensen の不等式で $\bar\rho(2\Delta) = E[\cos 2\omega\Delta] \ge 2\bar\rho(\Delta)^2 - 1$。交差点 $s(\Delta_q) = q$ では $s(2\Delta_q) \le 2q(2 - q)$ なので、$H@q \le \tfrac12\log_2(4 - 2q)$。**$q = 0.25$ の上限は 0.9037**（1 つの周波数の回転で等号）。Fable さんの表の「上限 1」は誤り。`pca` が V-d3 の (i) の 0.85 でも、上側の余地は約 0.054
- **反論（Codex さん、数値計算）**: V-d2 の (ii)「時間の平滑化の幅とともに $H@q$ が単調に上がる」は偽。周波数 1 と 2 の定常な混合で、平滑化が高い周波数の分散の割合を $0.9999 \to 0.5 \to 0.0001$ と動かすと、$H@0.25$ は $0.90367 \to 0.86783 \to 0.90361$ と上がって下がる。V-d2 の (i) の白い雑音も、固定した白色化の座標で等方に足したときだけ単純な式になり、その場合でも $s_\nu = (s + \nu)/(1 + \nu)$ で交差点が動く
- **修正案（Codex さんの意見）**: V-d0 は実装の検査として残す。V-d2 は、閉じた式で値が決まる単一の帯・2 つの帯・雑音の回収の試験に替える。V-d3 は、最大の平滑化との差や参照の半分での順位だけで合格にしない。**実際に区別したい最小の差 $\Delta_*$ を先に決め**、同じ三つ組の対の差で回収できるかを見る。ブートストラップのブロックの境界をまたぐ三つ組は作らず、$\Delta_q$ もブートストラップの中で推定し直す
- **過去 3 回との関係（Codex さんの意見）**: 旧い評価の失敗（値の幅が狭い・教師の群の一致が低い）のうち、外部の教師への一致の問題はこの量では消える。ただし「符号が細部を捨てて、自分の的を簡単にする」問題は残る（1.1 節の反論 3、1.2 節の展開）

### 1.5 (d) Locatello らとの関係

- **Codex さんの意見（原論文の Theorem 1 にもとづく）**: Locatello らの定理は、観測の周辺分布を保ったまま因子を混ぜる全単射を作る（等方なガウスの回転はその一例）。時系列や介入は追加の構造を与えるが、$H$ はそれを 2 次の統計に縮めてしまう。逆向きの反例もある: 独立な OU の因子をそのまま返す、完全に軸で分かれた符号でも $H@0.25 = 0.404$ と低い。つまり **$H$ の高さは因子の分離の必要条件でも十分条件でもない**
- **言ってよい範囲**: 「指定したラグと計量で、自然な動画の中点・等速外挿の相対誤差が小さい」まで。任意の場面の間の補間や、因子の分離への一般化は、この試験からは導けない

### 1.6 (g) 足し算の直観に近い他の試験

- **Codex さんの最初の案**: 独立に適用できる 2 つの介入 $A$・$B$（例: 離れた 2 領域の移植）で、混合差分 $z_{AB} - z_A - z_B + z_0$ を測る
- **Claude の反論**: 離れた 2 領域の移植では、画素の混合差分が厳密に 0 で満点になる。ユーザーの基準線「画素の足し算は意味がない」が、この試験では天井になり、モデルが画素を上回る余地が無い。これは線形性ではなく局所性・分離（modularity）の試験である
- **Codex さんの返答（同意して修正）**: 移植は局所性・分離の対照として使う。画素を基準にする加法性には、`wide` の平行移動の四つ組を推す。同じ stack から $0, a, b, a+b$ のオフセットを本物で切り出し、
  $$R_{a \to b} = \frac{E\lVert (z_{a+b} - z_a) - (z_b - z_0) \rVert^2}{E\lVert z_{a+b} - z_a \rVert^2}$$
  を測る（分母は $z_a$ をそのまま返す copy の誤差。$R < 1$ なら変位を持ち運ぶ方が当たる。$D(a) + D(b)$ で割ると、大きな $a$ が $b$ の転用の失敗を薄める）。始点側と移動先側の $b$ の応答のエネルギーをそれぞれ $2V_{\mathrm{nat}}$ で割って並べ、事前に決めた最小の応答を下回る条件（平行移動に不変な符号）は採点の外にする。位置の手がかりを抑えるため、開始のオフセットも変える。画面の外から新しい内容が入るので、共通に見える領域と端を分ける。**画素が低い値になる保証は理論には無い**ので、同じオフセットで画素との差を実測する
- **Fable さんの §5.3 への指摘（Codex さん、導いた）**: $H_{\mathrm{tr}} = 1$ と加法性が同値なのは、前半と後半の増分の二乗平均が等しい場合に限る。例えば $z(0), z(a), z(2a) = (0, 1, -2)$ でも $D(a) = 1$、$D(2a) = 4$ で $H_{\mathrm{tr}} = 1$。同じ三つ組で 2 階差分を直接採点すれば塞がる
- **§5.4 への補足（Codex さんの意見）**: $E[\delta] = 0$ が退けるのは、全ての場面に共通する 0 でない加算のベクトルだけ。回転のような作用 $M_a$ は平均の変位が 0 でも別の場面へ転用できる。参照で $M_a$ を学び、使っていない場面で合成則・同じ画像の別の変換を候補にした識別・変換への応答の量を測る方が直接的（ただし Fable さんの §5.6 の指摘どおり、画素と不変な符号は作用素の当てはめで満点に近づくので、応答の量と組で読む）
- **副の指標（Codex さんの意見）**: held-out の SVCCA は seed の間の再現性を測るが、共通の大域の量でも高くなる。局所のアフィン予測は近傍の半径に依存し、滑らかな 1 因子でも通る

## 2. いまの検証項目を減らせるか

**減らせない**（Codex さん・Claude とも同意）。K1〜K3・局所性（移植）・自己同定は残す。1.2 節の展開と複製の K3（`h_mean` の水準）が高い値を取れるので、$H$ はこれらの見張りを代われない。減らせるのは表示の重複だけで、同じ三つ組・同じ copy の分母なら外挿の誤差の比は中点の誤差の比の**厳密に 4 倍**（$z_{t+\Delta} - (2z_t - z_{t-\Delta}) = b - a = -2(z_t - m_t)$、確かめた）なので、どちらか片方を出せば足りる。

## 3. 採る案（Claude と Codex さんの合意。数値を出す前のもの）

1. 全ての符号に共通の物理ラグ（重ならない 0.8 秒以上）での $s(\Delta)$ の曲線と、外挿（または中点）の誤差と copy の誤差の比を、**記述として**並べる。主の合否にはしない
2. 固定ラグでは全ての符号に同じ三つ組を使い、カットの内側とまたぐものを層別し、対の差をブロックのブートストラップの区間で出す（ブロックの境界をまたぐ三つ組は作らない）
3. $H@q$ を並べるなら $\Delta_q$ と届かない割合を併記し、「**0.9037 は定常かつ $s(\Delta_q) = 0.25$ のときの上限**」と明記する
4. 対照は 5 種: 無加工の画素（`pca`）、8 枚の時間の平均、1 つの量のチェビシェフ展開、合成の K3（`h_mean` の水準を含む）、OU の混合
5. 既存の run（V16・V17・V18 系）の比べは記述にとどめる。学習の目的の優劣を言うなら、同じ入力・データ・予算で学び直す
6. 足し算の転用まで主張したいときだけ、`wide` の四つ組の $R_{a \to b}$ を加える（画素との差は実測で、保証は無い）

退けた案: $H@0.25$ を主の指標にすること、2 領域の移植の混合差分で線形性を言うこと（画素が天井）、V-d2 の平滑化の単調性を有効性の確かめにすること、`lin_k` を天井と呼ぶこと。

## 4. 残る論点（ユーザーへ）

- ユーザーの言う disentanglement（因子が分かれていること）は、人のラベルを使わず、2 次の統計だけで測る限り、原理的に確かめられない（1.2 節・1.5 節）。確かめるには、高次の統計か、因子として認める介入（平行移動・拡大・時間など、人が選んだ入力への操作）が要る。どの介入を「因子」とみなすかはユーザーの判断
- 空間のマスクで学んだ V18c の JEPA が、時間について真っすぐになる理論は無い。画素を上回らない結果も十分ありうる（Fable さんの §10 と同じ）。その場合は「空間のマスクの目的は時間の線形性を作らない」と読み、V19 の未来予測で同じ量を測る
