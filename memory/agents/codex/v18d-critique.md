# V18d の設計への Codex さんの批判（2026-11-27、値を出す前）

最優先で直すべき穴は、**短い run の選択に Zurich が入ること**と、**同じ未来の観測をどれだけ当てられるようになったかを H1 が測っていないこと**です。前者は選択と評価の分離を破り、後者は全条件を通っても「内容を保ったまま、予測しやすい成分を足した」解を残します。

1. **致命的｜選択に Zurich が入る。** 短い run の `rank`・`token_r2` は Zurich を使います。S+T の足切りと判定保留に使う `pred_ratio_calib` も、平均だけでなく採点対象が Zurich です。また、内容の「検証の区間」は読み出しに対する未使用区間です。`Units(..., "all")` で学ぶエンコーダには見えています。**直し方**は、選択に使う全指標を Zurich 以外で計算し、manifest と選択スクリプトで分離を検査することです。時間・内容の選択を別動画への汎化として扱うなら、その動画を全腕のエンコーダ学習から外して S も取り直す。既存 S を使うなら、選択は訓練内と明記する。現行の `real3` は Zurich も採点するので、選択段階では `val` だけを出す経路にします。[事前登録](../../../exp/vision/results/v18d/README.md:38) · [jepa_eval.py](../../../exp/vision/jepa_eval.py:496) · [jepa_iid.py](../../../exp/vision/jepa_iid.py:259) · [content_eval.py](../../../exp/vision/content_eval.py:2252)

2. **致命的｜観測の予測改善まで主張するなら、H1 に共通の的が要る。** V18c の内容を担う座標を残し、未利用の座標に歩行位相などの予測できる成分を載せれば、`R_clim` と `R_copy` は両方下がりえます。崩壊指標、現在の観測から読む `E`・`E^d`、真の `z` からの復元はすべて素通りできます。しかも既存の V18c には `E^d` がすでに床に近い設定があります。別動画で予測器を当て直すことには価値がありますが、主範囲の刻みは全て学習範囲内なので、そこで示せるのは未知動画での潜在予測への転移です。**直し方**は、`dyn.md` の V19 案を前倒しし、予測した潜在から**全腕で同じ未来の 32×32 観測**を読む行を登録することです。同じ入力・刻みで、画素の持続予測と `pca`・S を比べる。動きについて主張するなら、未来の変化も共通の的にします。現在の H1 を維持する場合は、仮説名も「潜在の予測比と線形読み出しの非劣性」に絞るのが正確です。[dyn.md](../../../exp/vision/plans/dyn.md:203) · [v3 の探索結果](../../../exp/vision/README.md:6684)

3. **重要｜(a) の閉じた式は、実際の予測器の最適値の下限。** 刻みごとに \(Y=z_+\)、\(X=(z_0,z_-)\) とすると、切片つき線形回帰の最小誤差は \(\operatorname{tr}(\Sigma_{YY}-\Sigma_{YX}\Sigma_{XX}^{\dagger}\Sigma_{XY})/D\) です。実際の \(L_T^*\) には、係数と切片を節間で共有することによる近似誤差が加わります。`R_clim` との一致には、刻みごとの標的分散が \(D\) で、分母が同じ母集団の平均を使う条件も要ります。SFA の導出は copy 固定なら成立します。自由な線形回帰が拾うのは回転や負の相関も含む線形予測可能性です。例えば \(z_u=(-1)^u g\)、\(g\sim N(0,I)\) を系列ごとに引くと、周辺は標準ガウスで、全整数 \(n\) で \(z_{u+n}=z_{u-n}\) です。全節で `C=I` なら誤差ゼロです。**直し方**は、固定符号で「学習済み head／同じ節の最小二乗／刻み別の最小二乗」を同じ座標と組で比べることです。OU の試験も節間を含め、振動を足す。0.8 秒の下限は維持し、25.6〜51.2 秒は log 一様なら全体の約 1/6 を占めるので、帯別に報告します。[v18d.md](../../../exp/vision/plans/v18d.md:22) · [SFA 原論文](https://www.ini.rub.de/PEOPLE/wiskott/Reprints/WiskottSejnowski-2002-NeurComp-LearningInvariances.pdf)

4. **重要｜(c)(d) の排除と、0 初期化の説明が強すぎる。** 0 初期化時、時間項は標的側だけを縮めます。SIGReg がこれを相殺する保証はありません。実装の有限標本 V 統計量は、i.i.d. ガウスでも分散 1 で期待値の微分が正です。また、固定 trace のランク罰をそのまま学習全体へ外挿できません。`W` の特異値は 0.0012〜2.01 で、`WWᵀ` の PR は約 511 でも罰の上乗せは約 0.03 です。低分散の信号を head が増幅することは可能です。さらに、各トークンが同じ少数の場面変数を**異なる非線形関数**で持てば、共分散は高ランクになり、線形の `token_r2` も低くできます。S+T のランク 16 の比較では利得が \(\Delta L_S+w\Delta L_T\) なので、時間項だけの上界では排除できません。**直し方**は、全枝勾配と線形 head を初回の比較として維持し、0 初期化・`1e-3` の妥当性を固定エンコーダでの回帰との差で確認することです。分散・PR・スペクトルを `t` と `z` の両方で取り、K3 の結論は導出した線形ランク16の族に限定する。MLP は非線形な運動を拾えますが、動画・場面ごとの近道も拾えるので、遅さ対策としては根拠がありません。[SIGReg 実装](../../../exp/lib/sigreg.py:90) · [V18c の導出](../../../exp/vision/plans/jepa.md:733) · [V18d の導出](../../../exp/vision/plans/v18d.md:105)

5. **重要｜実データの近道は、指標の組だけでは同定できない。** 照明・構図・場面 ID は `R_clim` を下げ、粗い画素の `E` や復元も良く見せえます。歩行や露出の周期は、崩壊せず両方の比に効きえます。純粋な位置だけなら定数ですが、位置と画像の組で地平線やカメラ揺れを読む解は残ります。動画 ID は訓練時に有効で、Zurich ではほぼ定数になり、複数動画で当てた PCA64 の枠だけを使う場合があります。**直し方**は、動画内・ブロック内の中心化、輝度・大域フロー・歩行位相の読み出し、カット有無の層別を事前に固定することです。堅い比較は共通の未来観測で行う。中心だけの SIGReg は \(N=128\) を揃える選択として妥当ですが、端を除くと役割別・刻み別の分布は異なります。`z_-`・`z_0`・`z_+` の平均・分散を帯別に監査し、差が効くなら各役割に別々に \(N=128\) の SIGReg を掛けて平均する。`pca-mean-W` は長い履歴を見られるため、支配された場合の結論は「この時間平均対照に負けた」までです。[v18d.md](../../../exp/vision/plans/v18d.md:36) · [dyn.md](../../../exp/vision/plans/dyn.md:69)

6. **重要｜27 本より先に、時間対応を壊した対照を確保する。** 最優先は同じ三つ組・stack・step・head・損失重みを使い、同じ動画・刻みの中で標的の対応だけを置換した S+T です。動画 ID や周辺分布を保って、正しい時間対応の寄与を問えます。S の 3 倍 step は、更新数と cosine も変わるので、同じ stack 予算での性能が問いなら有用です。因果の切り分けには置換対照が先です。また、固定 \(\lambda\) で \(w\to\infty\) とすると、時間項に対する SIGReg は消えます。T はこの極に当たりません。**直し方**は、S+T を時間項の追加の主比較に据え、T は空間項を外す別の問いとして扱い、予算はグリッドより置換対照に回すことです。[v18d.md](../../../exp/vision/plans/v18d.md:53)

7. **重要｜選択と判定で、未検出を反証に変えない。** 最大学習率の run を基準にした相対足切りは、短期に損失を下げる設定を優遇します。6000 と 60000 の cosine は別で、既存 V18c でも長期に `E^d` が落ちています。93% の点推定は選抜の目安として使えますが、\(E_b^d\) がゼロ付近や負なら比は不安定です。また、2 seed は同じ Zurich と `pca` を共有し、seed 0 は選択にも使うため、誤判定確率を二乗できません。V-p1h の 0/200 は合成の線形に対する結果です。**直し方**は、予測器の未収束と候補の不適格を分け、内容は差 \(D\) と既存の `comparable` を使い、測定不能・候補なし・同点の扱いを固定することです。最終判定は支持／反証／未決に分け、実用差を事前に置くなら「その改善幅を区間で排除した」を反証とする。全条件を要求する腕内の比較に一律補正は不要ですが、「どちらかの腕」で確証を主張するなら、主腕を一つに固定するか、腕間を補正します。現行の 2 seed は探索の再現確認として報告するのが妥当です。[事前登録](../../../exp/vision/results/v18d/README.md:47) · [既存の比較可能性判定](../../../exp/lib/fidelity.py:437) · [V-p1h の結果](../../../exp/vision/results/dyn/README.md:89)

8. **軽微｜「自分の head と PCA64 の差」の解釈を修正する。** 現状の差には、座標・白色化・次元・節共有・再学習・平均との差が混ざります。**直し方**は、同じ組と平均で `own 1024 → 再 fit 1024 → 再 fit PCA64` の順に比較し、差が生まれた段を報告することです。4 節の間は 3 区間なので、ログの「4 つの帯」も境界を明記してください。[v18d.md](../../../exp/vision/plans/v18d.md:140)

どの近道が実際に支配的かは、現時点では分かりません。最小の実験で詰めるなら、Zurich を選択から外し、S+T の正しい対応と置換対応を比較し、両方を同じ未来観測で採点するのが先です。
