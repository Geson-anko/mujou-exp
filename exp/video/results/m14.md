# 合成データで動力学だけを学ぶ（M14、2026-11-03〜）

[README](../README.md) の結果の 1 節。MILESTONES.md の M14。画像のエンコーダを外し、玉の状態から作った観測を `Source`（送るだけのポート）で動力学に見せ、次のフレームの観測を予測する。誤差は観測の上でとり、観測へは credit が流れない（ポートの型で経路が無い）。

実行は fleet（`exp/lib/fleet/README.md`）。run の設定は hydra の preset（`exp/video/conf/experiment/m14/`）、表は `just fleet table`（`exp.lib.runs`）。値はすべて標準化した観測の空間での 1 次元あたりの二乗誤差（標準化は較正のクリップ seed 777 だけで決める）。

## 設定

- **データ**: M13 の物理（$e=1$、抵抗 0、一定の重力 $\gamma_0=1$、`conserve`、引き直しなし）、B=128 のストリーム。段 0 は玉 1 つの $(x, y, v_x, v_y)$、段 1 は玉 1 つの $(x, y)$、段 2 は玉 3 つ（半径 0.06・0.08・0.10）の位置
- **モデル**: `Source` → `Dynamics`（minGRU）→ `DynamicsLayer` ×（ノード数 − 1）→ `Compare`（読み出し $W_o$）。小は $d_s=256$・1 ノード、大は $d_s=512$・3 ノード
- **学習**: PC-ALM（`mujou.pc`、`learn_interval` 25 ms）と BP（`DynamicsBP`、同じ初期値・同じ記憶の近似）。適格度トレース（`dynamics.trace`）は RTRL で入力を固定した BPTT と一致する（テスト）
- **評価**: 評価クリップ（val seed 1001、test seed 12345、256 本 × 4 窓 = 1024 窓）で 16 フレームを観測し、そこから開ループで $h$ フレーム先まで。学習中のストリームから分岐する評価（`fork`）も同じ時刻に測る
- **コード**: snapshot `2ed1815`（mujou `881c4ee`）

## 段 3 の判定基準（回す前に決めた、2026-11-03）

観測は 3 つの玉の 32×32 の灰色の画像（`render`、1024 画素）。標準化は較正のクリップの全画素で 1 つの平均と標準偏差（平均 0.031、標準偏差 0.123）。物差しは画素の上で測る（`exp/video/measure/pixel_baselines.py`、`m14-s3-baselines-v1`）。

| | 平均の画像 5 / 10 / 20 | 写し 5 / 10 / 20 | 等速 5 / 10 / 20 | 等加速度 5 / 10 / 20 |
| -- | -- | -- | -- | -- |
| val | 0.975 / 0.975 / 0.974 | 1.40 / 1.77 / 1.90 | 0.292 / 0.945 / 1.45 | 0.303 / 0.458 / 0.741 |
| test | 0.973 / 0.974 / 0.975 | 1.38 / 1.75 / 1.89 | 0.276 / 0.938 / 1.45 | 0.296 / 0.463 / 0.743 |

平均の画像は較正のクリップの画素ごとの平均。等速・等加速度は状態を外挿してから描いた画像。画素の上では、玉がずれると「元の場所の欠け」と「別の場所の玉」の 2 回分の誤差になるので、外れた外挿の誤差は平均の画像に近づく。そのため等速の外挿は 10 フレーム先で平均の画像とほぼ同じ（0.945）になり、壁を知らない等加速度の外挿（0.458）の方が強い。玉ごとの領域（真の円盤が覆う画素）の 10 フレーム先の誤差は、等加速度で 6.4〜6.1、等速で 14.1〜10.4、平均の画像で 16.1〜15.1（玉 0〜2）。

段 1・2 と同じく、test、30 分、PC-ALM と BP、seed 0/1/2 のすべてで次を満たすこと。設定は BP の探索（seed 100/101、val、目的は `roll/ca` の 5・10 フレーム先の対数の平均）で選ぶ。

1. 発散しない
2. 5・10 フレーム先の誤差が、等速と等加速度の外挿の小さい方の 0.5 倍未満（`roll5 < 0.5 min(cv5, ca5)`、`roll10 < 0.5 min(cv10, ca10)`）。平均の画像と写しはこれより弱いので、同時に下回る
3. 3 つの玉それぞれで、10 フレーム先の領域の誤差が等加速度の外挿を下回る（`roll10@ball{i} < ca10@ball{i}`）。小さい玉を消して全画素の誤差を下げる予測を除くため
4. `viz/<t>/frames.png` で、3 つの玉が正しい向きへ動き、壁で跳ね返り、薄れない
5. 局所性・非同期性を崩さない（ネットワークは段 2 と同じで、観測は `Source` が送るだけ）
