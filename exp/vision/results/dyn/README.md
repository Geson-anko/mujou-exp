## 回す前に決めたこと（2026-11-26）

**V19 の値は見ていない。dyn/copy の値は 1 つも計算していない。** 下の数値は、閉じた式（神託）で出した理論値だけである。

- **主の量**: 白色化した PCA64 の座標で、2 点 $(w_t, w_{t-\Delta})$ から $w_{t+\Delta}$ を当てる予測器の誤差を、copy の誤差で割った $R_{\mathrm{copy}}(\Delta)$。低いほど良い。平均の予測の誤差で割った $R_{\mathrm{clim}}(\Delta)$ を必ず並べる
- **主の 1 つの数**: 0.8〜25.6 秒の $\log R$ の、$\log\Delta$ についての平均 $\overline{\log R}$。半オクターブの格子の 11 点（$n$ = 8・11・16・23・32・45・64・91・128・181・256 stack）で台形で求める。0.1〜0.8 秒は記述
- **族**: 線形（切片つきの ridge。$\alpha$ は検証の組で選ぶ）と、線形 + 残差 MLP（幅 512 の 2 層、出力 0 初期化、3 seed、検証の組で step を選ぶ。step 0 = 線形を含む）。主は MLP。ただし記録の組での MLP の非劣性（V-p2d）を物差しの全てで通ったときだけで、通らなければ線形を主にする。線形を必ず並べる
- **組**: Zurich 以外の 9 本の動画を、seed 4101 の置換で記録 1 本・検証 1 本・訓練 7 本に分け（動画で分ける）、128 秒のブロックに切る。評価は Zurich の共通の中心（約 14100 個）。三つ組は全ての刻みで同じ中心を使う
- **区間**: Zurich の 128 秒・256 秒のブロックの抽出（2000 回、seed 101）の SE の大きいほうと、MLP の seed の揺れ $\sigma_{ab} = \max(\sigma_{\mathrm{rot}}, s_{ab})$ を合わせた $\pm 2\,\mathrm{SE}_{\mathrm{tot}}$
- **判定の言葉**: 「a の予測が b より良いと区別できた」は、$\psi_{\mathrm{copy}}$ と $\psi_{\mathrm{clim}}$ の区間が両方 0 より下のときだけ。向きが逆なら「分母で向きが割れた」。さらに崩壊の指標を通り、内容のガード v3 で水準と変化の両方の非劣性が示されること。v3 の有効性が確かめられるまでは「内容の比べは未確立」と添え、「良い」とは書かない。実用上の余裕は置かない（未決）
- **知っている限界（神託の理論値）**: 時間の平均は 2 つの分母の規則を通る（OU $\tau$ = 3.2 秒を幅 3.2 秒で平均すると $(\psi_{\mathrm{copy}}, \psi_{\mathrm{clim}}) = (-0.078, -0.485)$）。だから内容のガードが要る。白い方向の注入は「分母で向きが割れた」になる（$(-0.157, +0.120)$）。内容を保ったまま予測できる成分（時計）を足す符号は、どの規則でも捕まらない場合がある（`clock` で大きさを記録する）
- **確かめ**: V-p1（合成。推定量と神託の一致、恒等式、MLP の陰性・陽性の対照、判定の規則、区間の被覆、帰無の対の誤った判定）と V-p2（実データの物差し。`rot` 対 `pca` の線形の不変性と実装の保証が合否、MLP の非劣性で主の族を決める、値は記録）。外れたら止める。通る条件を探して規則を変えない
- **再現性**: mujou は `5aa37738dd04`。コードの snapshot は回すときに書く。出力は `/nas/geson/mujou-exp/runs/v18c-dyn/`

## 実装（2026-11-26、値を計算する前）

計画のとおりに実装した。置き場所は次のとおりである。

- `exp/lib/dynpred.py`: 族、比、主の数、神託
- `exp/lib/synth_series.py`: S3・S7・S8 の系列と自己共分散、箱で平均した AR(1)
- `exp/vision/dyn_eval.py`: 組、符号化、行、V-p1、V-p2、CLI
- `exp/vision/results/dyn/judge_dyn.py`: 区間、判定の言葉、段

`exp/lib/linear_dyn.py` には `fit_scales` を足した。これはモーメントを 1 回だけ数え、全ての $\alpha$ で解く関数である。また、入力と出力の幅が違う組（128 → 64）も解けるようにした。これまでは同じ幅の組しか解けなかった。

テストのオラクルは次のとおりである。

- 1 次元の OU で、神託が $(1 + r)/2$ と $1 - r^2$ になること。
- 1 次元の閉じた FVU。
- 決定論的な回転で 0 になること。
- 固定した係数の誤差を、手計算と照合した。
- ridge の正規方程式。
- 等速の系列を、族が 0 で当てること。
- 直交変換をしても、線形の比と選んだ $\alpha$ が変わらないこと（ridge を含む）。
- MLP の step 0 が、線形とビットで一致すること。
- 早期終了の選択（同点なら早い時点を選ぶ）。
- 並べた学習と、1 本だけの学習が一致すること。
- $\overline{\log R}$ の台形を、手計算と照合した。
- フレームの番号を値にした動画で、符号化の時刻を照合した。
- 確かめを分けて回して合わせた行と、一括の行がバイトで一致すること。

計画の文面から、実装で決めた点は次のとおりである（値を見る前に決めた）。

1. **神託の登録値を再現した。** 実装の神託で、計画の V-p1e の 5 つの値を 3 桁まで再現した（S10: $(-1.112, -1.285)$、S6 対 S4: $(-0.157, +0.120)$、S5 の幅 3.2 秒: $(-0.078, -0.485)$、12.8 秒: $(-0.201, -1.538)$）。S5 の「過去の箱」は、直近の $W$ 個（$x_{t-W+1} .. x_t$）の平均である。$W + 1$ 個の平均では値が合わない（3.2 秒で $(-0.083, -0.503)$）。
2. **`clock` の速い方向は、訓練の組で選ぶ。** 計画には「参照の組の 0.8 秒の $s_i$」と書いてあった。しかし参照の組は、訓練の流れから飛び飛びに取った stack であり、時系列ではない。そのため $s_i$ を測れない。そこで、計画が同じ箇所で挙げた「V-h2 と同じ方向の選び方」（訓練の動画で測る）に従う。dyn の訓練の組の共通の中心で、0.8 秒の $s_i$ を測る。
3. **V-p1a' の $R^*$ は、評価の組の重みの神託の最良とした。** $R(\hat M)$ は、評価の組の重みのモーメントで採点する。同じ関数の最小でなければ、$R(\hat M) \ge R^*$ は保証されない。S7 の「訓練の重みで作った最良の係数を評価で採点した値」は、`trainbest` として記録する。
4. **MLP の初期値とバッチは seed ごとに 1 つ。** 同じ seed の MLP は、全ての刻みで同じ初期値から始まり、同じ中心のバッチを引く。刻みごとに独立に学ぶことは変わらない。step 0 の値は、線形の和そのものを使う（$g \equiv 0$ なので厳密である）。
5. **行の和の形。** `rec` と `zurich` はブロックの和を持つ。`train` と `val` は合計だけを持つ。これは V-p2b と記述に足りる。また、256 刻みの行を小さくできる。
6. **合成の乱数。** 符号は「族」ごとに、実現の seed と族の番号から作った生成器で引く。族とは、同じ乱数から作る符号の組である。OU 系は S4・S5・S6・S9-S4、回転系は S1・S10 である。こうすれば、どの単位を分けて回しても値は変わらない。V-p1h の S4' は、別の族の乱数で引く。
