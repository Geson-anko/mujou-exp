1. **主の 1 つの数の範囲は 0.8〜25.6 秒。** 0.8 秒未満は、8 枚の stack の重なりだけで滑らかになる（Fable さんの結論 6）。そのため、符号器の手柄が混ざる。0.1〜0.8 秒は記述として並べる（線形の幅の主の範囲とそろう）
2. **「良い」と言うのは、2 つの分母の対の比の区間が同じ向きに 0 を超え、かつ崩壊の指標と内容のガードを通るときだけ。** 2 つの分母は copy（$R_{\mathrm{copy}}$）と平均の予測（$R_{\mathrm{clim}}$）である（下の「ずるとガード」）。内容のガード v3 の有効性が確かめられるまでは、「内容の比べは未確立」と書く
3. **訓練の組は、Δ = 25.6 秒に足りる長さで新しく作る。** 訓練の動画を動画ごとに訓練・検証・記録に分け、128 秒のブロックに切る（下の「組」）。いまの `width_guard.train_intervals`（512 stack = 51.2 秒の区間）では、25.6 秒の三つ組の中心が 1 つも残らない（$u - 256 \ge 0$ と $u + 256 \le 511$ を同時に満たせない）。内容のガード v3 の組とは共有しない。v3 は並行して開発中で、組の規則が違う（512 stack の区間）。後で揃えられるなら揃える
4. **MLP は幅 512 の 2 層の残差。刻みは半オクターブの格子（16 点）。線形は 0.1 秒刻みの全格子（256 点）も出す**

設計メモから改めた点:

- **半オクターブの格子は 17 点ではなく 16 点**（設計メモ §3.5 の改め）。刻みは stack の整数でなければならない。$2^{k/2}$（$k = 0..16$）を四捨五入すると、$k = 0$ と $k = 1$（1.41）がどちらも 1 になる。格子は $n \in \{1, 2, 3, 4, 6, 8, 11, 16, 23, 32, 45, 64, 91, 128, 181, 256\}$ とする。主の範囲は $n \ge 8$ の 11 点である。積分は丸めた後の実際の $\log n$ で行う
- **白色化の不変性は、直交変換について厳密で、一般の可逆な線形変換については成り立たない**（設計メモ §3.4 の改め）。符号の次元が 64 を超えると、可逆な線形変換は PCA64 の部分空間そのものを変える。直交変換なら上位の部分空間と固有値は変わらず（64 番目と 65 番目の固有値が縮退していなければ。近いと数値的に敏感になる。Codex さんの指摘）、白色化した座標は直交行列 $Q$ で写り合う。このとき、線形モデルは $M \mapsto (Q) M (Q \oplus Q)^\top$ で同変である。ridge の罰 $\lVert M \rVert_F^2$ も直交変換で変わらない。だから、**ridge を含めて線形の $R$ は厳密に不変**である（設計メモは「ridge を除く」としていたが、白色化した座標の直交変換では ridge も不変）
- **つないだ回転（S7）の真値は、一般の神託で出す**（設計メモ §5 の改め）。設計メモの式は、対称な形 $2Cw_t - w_{t-\Delta}$ の族の最良である。2 点入力の線形の族はそれより広い。回転に向きがあると、2 次のモーメントに歪対称の項 $J$ が入り、対称な形では使えない。どんな定常過程でも、**最良の線形予測の誤差は自己共分散だけで決まる**。だから、混合の自己共分散 $\Gamma(\Delta) = \sum_b \pi_b \Gamma_b(\Delta)$ を神託に入れれば、ガウスでない S7・S8 の線形の真値も厳密に出る
- **記録の行から「回転だけに制限した対称な形」を外す。** 歪対称の $A$ の上の非凸な当てはめが要るが、主の評価にも判定にも使わない（シンプルさを優先）。半群の整合性（0.1 秒のモデルを繰り返す rollout）も、判定に使わない記述なので今回は実装しない（設計メモ §2.4 の注意 2）
- **MLP のパラメータ数は約 36.2 万**（設計メモの約 34 万の計算違い）。$128 \cdot 512 + 512 + 512 \cdot 512 + 512 + 512 \cdot 64 + 64 = 361536$
- **確かめの名前は V-p1・V-p2 にする。** V-d1〜V-d3 は、時間の線形性の確かめ（plans/jepa.md）で既に使っている

## 定義

### 座標

- 符号は、読む場所（自分の潜在。`h_mean` は記述）を、参照の組で当てた `midpoint.Whitener`（PCA64、$c_\epsilon = 10^{-6}$）で白色化した座標 $w$ である。線形の幅と同じ白色化を、同じ参照で 1 回当てて固定する
- 白色化は、全ての方向をほぼ同じ重みにする（`Whitener` は参照の分散を $\lambda/(\lambda + \epsilon)$ にするので、厳密に 1 ではなく、参照に依存する）。白色化しないと、分散の大きい（PCA の上位の、遅い）方向が支配する（`linear_dyn` の docstring の `dyn_h` と `dynw_h` の違い）
- 刻みは stack の数 $n$（$\Delta = n/10$ 秒）で数える

### 予測器と 2 つの比

刻み $\Delta$ ごとに、予測器 $\hat w_{t+\Delta} = f_\Delta(w_t, w_{t-\Delta})$ を学ぶ（刻みごとに直接学ぶ）。評価の組の和で

$$
R_{\mathrm{copy}}(\Delta) = \frac{\sum_t \lVert \hat w_{t+\Delta} - w_{t+\Delta} \rVert^2}{\sum_t \lVert w_t - w_{t+\Delta} \rVert^2},
\qquad
R_{\mathrm{clim}}(\Delta) = \frac{\sum_t \lVert \hat w_{t+\Delta} - w_{t+\Delta} \rVert^2}{\sum_t \lVert \bar w - w_{t+\Delta} \rVert^2}
$$

とする。$\bar w$ は訓練の組の平均である。

- **$R_{\mathrm{copy}}$ が主**（ユーザーの決定）。低いほど良い。copy は $R_{\mathrm{copy}} = 1$ である
- 分子は共通なので、$R_{\mathrm{copy}} / R_{\mathrm{clim}} = V/D(\Delta)$（$V = \sum\lVert \bar w - w_{t+\Delta}\rVert^2$、$D = \sum\lVert w_t - w_{t+\Delta}\rVert^2$）は、モデルによらない符号の性質である。定常なら $1/(2(1 - r(\Delta)))$ になる（$r$ は自己相関）
- 予報の分野の「持続（persistence）に対する技量」と「気候値（climatology）に対する技量」に当たる

### モデルの族

全ての符号で、同じ形・同じ容量・同じ学習の規則を使う。

- **線形**: $\hat w = M_1 w_t + M_2 w_{t-\Delta} + b$。入力を $[w_t, w_{t-\Delta}]$（128 次元）に並べ、`linear_dyn.fit`（切片つきの ridge、モーメントからの閉じた式、float64）でそのまま解く。ridge の $\alpha = c\,\mathrm{tr}(C_{00})/128$ の $c$ は `linear_dyn.ALPHA_SCALES`（$10^{-8} .. 1$）から、**検証の組**の分子の和が最小のものを選ぶ（同点は小さい $c$）。刻みごとに選ぶ
  - この族は copy（$M_1 = I$）、等速（$2I, -I$）、前向きの作用素 $\exp(\Delta A)$（$M_2 = 0$）、対称な形 $2\cosh(\Delta A)$・$-I$、平均の予測（$M = 0$）を全て含む（設計メモ §2.2）。だから、回転・減衰振動など全ての線形の流れを含む
  - 訓練の組の最小二乗（$c \to 0$）では $R_{\mathrm{copy}} \le 1$ かつ $R_{\mathrm{clim}} \le 1$ が保証される（族が copy と平均を含む）。検証の組・記録の組・Zurich では保証されない
- **残差 MLP**: $\hat w = \hat w^{\mathrm{lin}} + g_\theta(w_t, w_{t-\Delta})$。$\hat w^{\mathrm{lin}}$ は上で選んだ線形（固定）。$g$ は 128 → 512 → 512 → 64、GELU、出力層の重みと bias を 0 で初期化する。Adam（学習率 $10^{-3}$、重みの減衰なし）、batch 256、20000 step、二乗誤差。seed は 3（5001・5002・5003）
  - **早期終了**: 500 step ごとの 41 個の時点（step 0 を含む）から、検証の組の分子の和の 3 seed の平均が最小の時点を、刻みごとに 1 つ選ぶ（3 seed で共有。同点は早い時点）。step 0 は線形そのものなので、**検証の組で MLP が線形より悪くなることはない**（族の包含を手続きでも保つ。設計メモ §3.1）
  - 値は 3 seed の分子のブロック和の平均で作る（内容のガード v3 と同じ束ね方）。step 0 が選ばれたら、seed による揺れは 0 である
  - V-h4b（内容のガード v2）は、相関の強い区間を何十周もした MLP が区間を覚え、同じ分布の外の区間で最小二乗に負けた。検証の組での早期終了と、step 0 を候補に含めることは、この外れ方を直接に防ぐ（ホールドアウトの選択の不等式。plans/jepa.md の v3 の「選択が何を保証するか」と同じ）
  - 16 刻み × 3 seed = 48 本を `torch.func.vmap` で 1 GPU に並べる
- **記録の行**（学ばない、または閉じた式）: copy（$R_{\mathrm{copy}} = 1$）、等速の外挿 $2w_t - w_{t-\Delta}$（$R_{\mathrm{vel}}$）、平均の予測（$R_{\mathrm{copy}} = V/D$）、倍率 1 つの線形 $\hat w = c\,w_t + (1 - c)\bar w$（$c$ は訓練の組の閉じた式）、**1 点入力の線形** $\hat w = M w_t + b$（同じ ridge と選択。2 つ目の入力 $w_{t-\Delta}$ の寄与を測る。Codex さんの指摘）。V19 の判定では V19 の予測器の行を足す
- 刻みごとに独立に学ぶので、言えるのは「直接の予測」についてである。一貫した 1 つのダイナミクス（半群）については言わない（rollout の確かめをしないため）
- $R_{\mathrm{vel}}$ と線形の幅の関係（設計メモ §1.2）: 三つ組で $a = w_t - w_{t-\Delta}$、$b = w_{t+\Delta} - w_t$ とすると $R_{\mathrm{vel}} = \sum\lVert a - b\rVert^2 / \sum\lVert b\rVert^2 = 2G_{\mathrm{mid}} (\sum\lVert a\rVert^2 + \sum\lVert b\rVert^2)/\sum\lVert b\rVert^2$（恒等式）。定常では $R_{\mathrm{vel}} \approx 4G_{\mathrm{mid}}$ で、境 1/4 が $R_{\mathrm{vel}} = 1$ に当たる。線形の幅は、$R$ の曲線の「固定した 1 つのモデル（等速）」の行として読める

### 組

- **訓練・検証・記録の組**（新しく作る）: Zurich 以外の 9 本の訓練の動画（479350 フレーム）を、名前の順に並べて seed 4101 の置換で並べ替え、1 本目を**記録**、2 本目を**検証**、残り 7 本を**訓練**にする（**動画で分ける**）。各動画を頭から 128 秒（1280 フレーム）のブロックに切る（尾の端数は使わない）。ブロックはブートストラップの単位である
  - 動画で分ける理由（Codex さんの指摘、同意）: 同じ動画の別のブロックは、近い場面を共有する。検証の組が訓練と同じ動画から来ると、早期終了は「近い場面を覚えた残差」を選びうる（V-h4b の外れ方の一般形）。評価の Zurich は別の動画なので、選択も別の動画で行うのが、評価の汎化の形にそろう。記録の組も別の動画にすると、そこでの値は「選択に使っていない別の動画」での推定になる
  - 代償: 検証と記録はそれぞれ 1 本の動画の場面に偏る。どの動画が選ばれたかを README に書く
  - ブロックの中の三つ組 $(u - n, u, u + n)$ は、全ての stack のフレームが同じブロックに入るものだけを使う。**共通の中心**（$n = 256$ の三つ組が入る中心。1 ブロックあたり $1280 - 2 \cdot 256 - \mathrm{span}$ 個）を、全ての刻みで使う（C1 と同じ理由: 刻みで母集団を変えない）
  - 訓練の動画にはカットの検出が無い。ブロックの中のカットは除かない（内容のガード v2・v3 の区間と同じ）。Zurich は `in`（カットをまたがない）なので、カットの扱いが組の間で揃っていない。これは既知の違いとして書く（Codex さんの指摘。訓練の動画にカットの検出を当てるのは、今回はしない）
  - 記録の組は、当てはめにも選択にも使わない
  - 見込み（推測）: ブロックは 1 本あたり 40 個前後、訓練は約 280 ブロック × 約 760 中心 ≈ 21 万の三つ組
- **評価の組**: Zurich の共通の中心（線形の幅と同じ約 14100 個、128 秒のブロック、カットをまたがない `in`）。`width_eval.WidthSets` をそのまま使う
- 0.1〜25.6 秒の全格子（線形だけ）も、同じ共通の中心で出す

### 主の 1 つの数

$$
\overline{\log R} = \frac{1}{\log(256/8)} \int_{\log 8}^{\log 256} \log R(n)\, d\log n
$$

を、半オクターブの格子の主の範囲の 11 点（$n$ = 8・11・16・23・32・45・64・91・128・181・256）で、$\log n$ について台形で求める。$R_{\mathrm{copy}}$ と $R_{\mathrm{clim}}$ の両方で、族（線形・MLP）ごとに出す。

- 主の族は **MLP**（早期終了の step 0 を含むので、線形を候補に含んだ選択になる）。**ただし V-p2d（記録の組での MLP の非劣性）を物差しの全てで通ったときだけ。** 通らなければ、主の族を線形に替える（この切り替えは値を見る前に決めた規則で、通る条件を探す操作ではない）。step 0 の包含は検証の組での不等式しか保証せず、選択の後の別の動画での非劣性は保証しないからである（Codex さんの指摘、同意）。線形の行は必ず並べる。線形は seed の揺れが無く、直交変換で厳密に不変である。2 つの族で判定が食い違えば、両方を書く
- **0 と対数**: 分子が厳密に 0 の刻み（合成の決定論的な回転）があれば、$\overline{\log R}$ は出さず「予測が厳密」と書く（V-p1a は $R$ そのもので比べる）。ブロックの抽出で、ある刻みの分母が 0 になった抽出は無効とし、無効な抽出が 2.5% を超えたら区間を出さない
- 0.1〜0.8 秒（$n$ = 1・2・3・4・6・8）でも同じ形の数を記述として出し、`mean8` と並べる
- 曲線（0.1〜25.6 秒、線形は 256 点、MLP は 16 点）は記述である
- 同じ分布の記録の組の値・検証の組の値・訓練の組の値を、Zurich の値と並べる。Zurich で $R_{\mathrm{lin}} > 1$ になった刻みは、分布のずれの印として書く

### 測れない符号

- `Whitener` が採点できない（参照の固有値が `DEGENERATE` を下回る）符号、または共通の中心で $\sum\lVert w_t - w_{t+\Delta}\rVert^2 = 0$ の刻みを持つ符号は「測れない」とし、数を出さない（$R = 0/0$。定数の符号）。前者は `dyn_eval` が `part = unmeasurable` の行を出す。後者は `judge_dyn.unmeasurable` が Zurich の線形の行の copy の分母から見つける。どちらでも、`summary` は理由だけを返し、`pair` は区間を出さず、V-p2d には入れない
- 符号の実効の次元を記録する。参照の組の固有値（白色化の前）の participation ratio $(\sum\lambda)^2/\sum\lambda^2$ と、$c_\epsilon$ の床で引き上げられた方向の数である（下の「予測できない方向を混ぜる」）

## 区間

- **ブロックの抽出**: 線形の幅と同じ（`metrics.block_counts`、2000 回、seed 101、Zurich の 128 秒と 256 秒のブロック）。行には、刻み・族（seed）ごとに、分子・copy の分母・平均の分母のブロック和を残す。各抽出で $R$ を全ての刻みで作り直し、$\overline{\log R}$ を求め直す。全ての符号で同じ抽出を使うので、符号の対は同じ抽出で対になる
- **対の比**: $\psi_{\mathrm{copy}} = \overline{\log R_{\mathrm{copy},a}} - \overline{\log R_{\mathrm{copy},b}}$、$\psi_{\mathrm{clim}}$ も同じ（自然対数）。区間は $\hat\psi \pm 2\,\mathrm{SE}_{\mathrm{tot}}$、$\mathrm{SE}_{\mathrm{tot}} = \sqrt{\mathrm{SE}^{*2} + \sigma_{ab}^2}$。$\mathrm{SE}^*$ は 128 秒と 256 秒の抽出の標準偏差の大きいほうである（内容のガード v3 と同じ形）
- **$\sigma_{ab}$**（MLP の学習の揺れ）: $\sigma_{ab} = \max(\sigma_{\mathrm{rot}}, s_{ab})$。$\sigma_{\mathrm{rot}}$ は `rot` 対 `pca` の 3 seed の $\psi_s$ の標本標準偏差、$s_{ab}$ はその対自身の 3 seed の $\psi_s$ の標本標準偏差である（v3 と同じ理由: 符号ごとに選ぶ時点が違いうるので、`rot` 対 `pca` だけでは過小になりうる）。$\psi_{\mathrm{copy}}$ と $\psi_{\mathrm{clim}}$ で別々に求める。線形は $\sigma_{ab} = 0$
- 区間は、参照の白色化・訓練の組・学んだ予測器を固定した条件つきである。的は「学んだ予測器を固定した、評価の母集団での $\psi$」であり、神託の最良の $\psi^*$ ではない。訓練の有限さによる超過誤差は符号ごとに違うので、$\psi$ の差で打ち消し合わない。Zurich のブロックが 30 個・15 個と少ないので、95% の被覆は V-p1f・V-p1h で確かめた範囲（線形）でだけ主張する。MLP の $\sigma_{ab}$ は 3 seed（自由度 2）からの感度の余裕で、被覆の保証は無い（そう書く）
- **線形の区間には、訓練の揺れが入らない。** 線形は $\sigma_{ab} = 0$ である。だから、実データの線形の区間は「この訓練の組で学んだ 2 つの線形の予測器を、Zurich で比べた」ときの評価の揺れだけを表す。訓練の組を引き直したときの揺れ（$\hat M$ の揺れ）は含まない
- 感度（記述）: ブロックの起点を 64 秒ずらした抽出の区間を並べる（線形の幅と同じ。`judge_dyn.pair` の `shifted`。同じ $\sigma_{ab}$ を使う）

## 判定の言葉

対 $(a, b)$（同じ読む場所・同じ白色化・同じ抽出）について:

| $\psi_{\mathrm{copy}}$ の区間 | $\psi_{\mathrm{clim}}$ の区間 | 言葉 |
| -- | -- | -- |
| 0 より下 | 0 より下 | **a の予測が b より良いと区別できた** |
| 0 より上 | 0 より上 | b の予測が a より良いと区別できた |
| 0 を挟まず、向きが逆 | （同左） | **分母で向きが割れた**（どちらのずるの形かを書く。下の表） |
| それ以外 | | 区別できない |

- 「良い」と書けるのは、さらに (i) a が崩壊の指標（K1〜K3・`token_r2`。plans/jepa.md の V19 の判定の手順の 3 の (iii)）で崩壊でなく、(ii) 内容のガード v3 で、b に対する a の内容の非劣性が**水準 $E$ と変化 $E^d$ の両方で示された**ときだけである。「解像度が足りない」「比べられない」は、主張を控える側に倒す（Codex さんの指摘で、「落とした」にならなければよい、から強めた。内容を保ったまま予測できる成分を足す符号を、少なくとも内容の側で弱くは通さないため）。v3 の有効性が確かめられるまでは「内容の比べは未確立」と添え、「良い」とは書かない
- 実用上の大きさの余裕（線形の幅の $\Delta_*$ に当たるもの）は置かない（Claude の決定 2）。線形の族は seed の揺れが無いので、小さな差でも「区別できた」になりうる。だから、$\psi$ の点推定と区間を必ず数で書き、「大きい」とは書かない。余裕を置くかは、V-p2 の物差しの値を見る前のユーザーの判断に残す（下の「未決」）
- 言える範囲は、Zurich の 1 本の動画の中での、その checkpoint の比べ（PCA64 の計量）までである。学習法の効果には対にした独立な seed が要る

## ずるとガード

分子が共通なので、本物の改善（同じ分母のまま誤差が減る）は 2 つの比を両方下げる。2 つのずるは、2 つの分母で逆向きに出る（設計メモ §3.2・§3.3、導いた）。

| 操作 | $R_{\mathrm{copy}}$ | $R_{\mathrm{clim}}$ | 捕まえるもの |
| -- | -- | -- | -- |
| 遅くする（時間の平均） | 短い刻みで下がり、刻みが平均の幅の 1〜2 倍で上がる | 全ての刻みで下がる | **2 つの分母の規則では捕まらない**（OU $\tau$ = 3.2 秒を幅 3.2・12.8 秒で平均すると、主の範囲の $\overline{\log R_{\mathrm{copy}}}$ も 0.078・0.201 下がる。神託の理論値）。内容のガード v3 で捕まえる |
| 予測できない方向を混ぜる（白い雑音の方向、白色化で数値の雑音を持ち上げる） | 1/2 へ寄る（$R_{\mathrm{copy}} > 1/2$ の符号では下がる） | 1 へ寄る（上がる） | 2 つの分母の規則（「分母で向きが割れた」）。実効の次元の記録 |
| 内容の無い時計（入力によらない振動、予測できる成分） | 下がる | 下がる | **どの規則でも捕まらない場合がある。** 内容を保つ座標を残し、雑音の座標を予測できる振動に置き換えると、内容のガードの読み出しは振動を無視でき、$E$・$E^d$ は変わらず、2 つの比は両方下がる（Codex さんの反例、同意）。対処は記述だけ: V-p2 の `clock` の符号で大きさを示す、方向ごとの線形の分子を記録する、V19 では未来の観測の予測（下の「V19 で確証する手順」の 4）を並べる |
| 過適合 | — | — | 訓練・検証・記録・評価の分離、検証の組での早期終了と ridge の選択、全ての符号で同じ容量 |

- 例（OU、$\tau$ = 1、$\Delta$ = 1、導いた）: $R_{\mathrm{copy}} = (1 + r)/2 = 0.684$、$R_{\mathrm{clim}} = 1 - r^2 = 0.865$。64 方向の半分を白い雑音に置き換えると、$R_{\mathrm{copy}} = 0.571$（下がる）、$R_{\mathrm{clim}} = 0.933$（上がる）
- OU の時間の平均の表（設計メモ §3.2、自己共分散の数値積分）は V-p1 で神託と照らす
- 崩壊（定数の符号）は「測れない」で先に落とす

## 有効性の確かめ（外れたら止める）

合否は閉じた式（神託）と、真値の分かる対にだけ置く。外れたら止めて報告し、刻み・格子・seed・強さを変えて通る条件を探さない。

### 神託

定常で平均 0 の過程の自己共分散 $\Gamma(\ell) = E[w_{t+\ell} w_t^\top]$ が分かれば、2 点入力の最良の線形予測の誤差は

$$
E^* = \mathrm{tr}\left(\Gamma(0) - K \Sigma^{-1} K^\top\right),\quad
K = \begin{bmatrix}\Gamma(\Delta) & \Gamma(2\Delta)\end{bmatrix},\quad
\Sigma = \begin{bmatrix}\Gamma(0) & \Gamma(\Delta)\\ \Gamma(\Delta)^\top & \Gamma(0)\end{bmatrix}
$$

で厳密に出る（入力 $[w_t, w_{t-\Delta}]$、$K = E[w_{t+\Delta}[w_t; w_{t-\Delta}]^\top]$）。$\Sigma$ が特異（決定論的な回転など）なら擬似逆で、$E^* = 0$ を含む。分母は $\mathrm{tr}(2\Gamma(0) - \Gamma(\Delta) - \Gamma(\Delta)^\top)$（copy）と $\mathrm{tr}\,\Gamma(0)$（平均）である。**この式は 2 次のモーメントだけで決まるので、ガウスでない過程の線形の真値にも使える。** ガウスなら条件つき期待値が線形なので、MLP を含むどの予測器の母集団の誤差もこれを下回らない。1 次元の OU では $R_{\mathrm{copy}} = (1 + r)/2$、$R_{\mathrm{clim}} = 1 - r^2$ に戻る。

## V19 で確証する手順

V19 の checkpoint の値を見る前に、次を固定する（この節と results/dyn/README.md）。

1. **固定するもの**: 定義（$R_{\mathrm{copy}}$・$R_{\mathrm{clim}}$、白色化、組、族と学習の規則、seed、半オクターブの格子、主の範囲 0.8〜25.6 秒、$\overline{\log R}$）、区間の作り方、$\sigma_{ab}$ の規則、判定の言葉。V19 の計画で、run の本数と seed、seed の束ね方、step、再帰なら状態の初期化とウォームアップ（訓練・検証・記録・評価の全ての組で揃える。ブロックの頭から順に回す）、欠けた値の扱いを書く
2. **主の比べ**: V19 と、同じ batch・FIFO・更新の数・入力の集合で順序だけをシャッフルした腕（V19 の計画の対照）。主の族（MLP）の $\psi_{\mathrm{copy}}$・$\psi_{\mathrm{clim}}$
3. **副の族**: (a) V19 と同じ設定の i.i.d. の V18c（学習率 $10^{-4}$・$\lambda$ = 0.5 の 2 seed）、(b) V19 と `pca`・`mean8`・自分の学習前、(c) 線形の族での主の比べ。副の族で「区別できた」と言うには、族の比べの数 $m$ で割った $1 - 0.05/m$ の区間（Bonferroni。倍率 2 を $z_{1 - 0.025/m} = \Phi^{-1}(1 - 0.025/m)$ に替える）を使う
4. **判定**: 上の「判定の言葉」（2 つの分母、崩壊の指標、内容のガード v3 の両方の量での非劣性）。V19 の予測器の行（V19 自身の予測器の $R$）を並べる。線形の幅（副）と、拡散のデコーダの復元（定性）を並べる。**未来の観測の予測**（記述）: 予測した符号 $\hat w_{t+\Delta}$ を内容のガード v3 の水準の読み出しに通し、同じ未来の観測（32×32 の画素）に対する誤差を、全ての符号で同じ的として並べる。符号の座標に依存しない比べなので、時計のような「予測できるが内容の無い成分」で下がらない（Codex さんの指摘）。v3 の読み出しが確かめられてから実装する
5. **再帰の注意**: 状態を持つモデルは、入力と無関係な滑らかさ（OU の積分）や時計を持てる。C25（入力の差し替えと状態の初期化の対）を残す

## 実装のテスト（理論のオラクル）

- `dynpred`: 神託が 1 次元の OU で $(1 + r)/2$・$1 - r^2$、1 次元のガウス過程で設計メモ §3.2 の FVU の式に一致。決定論的な回転で $E^* = 0$（擬似逆）。線形の当てはめの勾配（正規方程式の残差）が 0。族が copy・等速を含む（$w_{t+\Delta} = 2w_t - w_{t-\Delta}$ の系列で $R = 0$、静止した系列で $D = 0$ を「測れない」と返す）。$R_{\mathrm{copy}}/R_{\mathrm{clim}} = V/D$。直交変換で線形の $R$ が不変（ridge を含む）。残差 MLP の step 0 の予測が線形と一致し、早期終了が検証の誤差の最小（同点は早い時点）を選ぶ。vmap した学習が 1 本ずつの学習と一致する。$\overline{\log R}$ の台形を手計算と照合
- `synth_series`: S3 の自己共分散が閉じた式に、S8 の混合の $\Gamma$ が数値に、箱で平均した AR(1) の自己共分散が有限和に、標準誤差の範囲で一致
- `dyn_eval`: 訓練のブロックが重ならず、組の大きさが置換と一致。三つ組の全ての stack が 1 つのブロックに入る。時刻の取り違え（フレームの番号を値にした系列で、入力の端・正解・copy の添字を手計算と照合。V-h0l と同じ）
- `judge_dyn`: 判定の表（手で置いた区間で 4 つの言葉）、$\sigma_{ab}$ の規則、Bonferroni の倍率。$\psi_s$ が分かっている対（seed $s$ の分子を $e^{c_s}$ 倍）で、MLP の区間が $\hat\psi \pm 2\max(\sigma_{\mathrm{rot}}, s_{ab})$ になり、$s_{ab} > \sigma_{\mathrm{rot}}$ なら広がること（分母ごとに別々）。線形は広がらないこと。ずらしたブロックの区間。copy の分母が 0 の刻みで「測れない」。V-p2d が無効な抽出の割合で SE を出さないこと

## Codex さんの批判を受けた直し（値を計算する前、2026-11-26）

詳細は [memory/agents/codex/dyn-critique.md](../../../memory/agents/codex/dyn-critique.md)。同意して入れたもの:

1. 合成の回転の位相をブロックごとに引き直す（固定だと当てはめが 2 次元の平面しか見ない）。V-p1a を「推定量 対 学んだ係数の母集団の誤差」（合否）と「学んだ係数 対 神託の最良」（記録）に分けた。S7 は係数を固定して評価のモーメントで採点する
2. 内容を保ったまま予測できる成分を足す符号は、どの規則でも捕まらない場合がある、と明記した。内容のガードの条件を「落とした」にならない、から「水準と変化の両方で非劣性が示された」に強め、`clock` の記録と、V19 の未来の観測の予測（記述）を足した
3. 区間の被覆は線形の範囲でだけ主張し、MLP の $\sigma_{ab}$ は保証の無い余裕と書いた。帰無の対の誤った判定（V-p1h）を足した
4. 訓練・検証・記録を動画で分けた。主の族を MLP にするのは、記録の組での非劣性（V-p2d）を通ったときだけにした。カットの扱いの違いと、ブロックの起点をずらした感度を書いた
5. 白色化の不変性の条件（固有値の縮退）、`Whitener` の $\lambda/(\lambda + \epsilon)$、ridge の copy への上界（$D + 64\alpha$）を直した
6. 1 点入力の線形の行、0 と対数の扱い、Bonferroni の倍率 $z_{1-0.025/m}$、「直接の予測」についてだけ言うこと、を足した

入れなかったもの: 「256 点の全格子と MLP を、確かめが通るまで後回しにする」。全格子は線形だけで計算が数分であり、確かめは計算の順ではなく判定の順（V-p1 が外れたら V-p2 の値を捨てる）で守るので、先回りして回しても結果は変わらない。
